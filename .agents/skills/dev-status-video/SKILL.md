# 视频进展回顾

读取[完整视频方法](references/status-video.md)和[分镜模板](assets/storyboard.md)。确定视频范围与主线，用已有真实证据解释变化，制作字幕、渲染成片并实查画面和每页停留时间。用户没有要求视频时用 `dev-status`；只查询进展不启动应用补截图。

从用户提出视频请求前的最后一条用户消息起算，按显式指定的时间或任务范围调整。证据核对、待决事项和书面表达可调用 `dev-status`；独立安装本技能时，仍按视频方法据原始记录确认完成、失败、仍在运行和未验证的事项，并逐项交代需要用户决定的内容。制作过程保存到目标项目根 `temp/dev/`，按约定位置交付成片。缺少素材、渲染或检查能力时如实报告实际交付和未验证项。
