# 用专业术语重述问题

教授操作者描述其正在构建之物的专业词汇。从其自己的文件、代码和描述出发，而不是从摘要出发。

如果描述可能指向不止一种问题，先列出可能的两三种问题，每种都给出对应的术语，以及将它与其他问题区分开的特征。然后教授最可能那种问题的相关词汇，并说明选择理由。

1. 给出 8 到 12 个术语，按它们会在多大程度上改变最终构建内容排序。每个术语都包括：用一句通俗的话说明词语及含义，它对应描述中的哪一部分，一个以此含义使用它的真实项目、论文或系统及链接，以及掌握这个词后可以向代理提出什么要求。
2. 选择 2 或 3 个相邻领域，它们以其他名称解决过结构相同的问题。对每个领域说明哪些内容可以迁移、类比在哪些地方不成立，以及哪些术语可以借回来。
3. 指出操作者没有提到却应当关注的事项。
4. 用这些新词汇改写其描述。

打开每个链接，确认它确实以该含义使用术语。删除无法确认的引用。不要凑数。

用原始需求核对重述中的每个约束。新词引出的能力属于可选方向，用户原意和已经确定的验收条件继续有效。
