# 回忆工作上下文

按照[上下文回忆方法](references/context-recall.md)确定项目、主题与时间窗，以会话记录找到工作线索，结合共享记录和当前事实核验。交付状态胶囊、各工作线索的实际状态、反复问题和一个具体下一步。

仅在确有背景缺口时检索。用户已提供足够的状态、路径、分支和改动时，直接使用已有材料。需要定位或读原生记录时调用 `dev-session-history`，提供实际主机、工作区、时间、主题和已知会话标识；未安装时用宿主已提供的记录和项目材料，注明缺口。

指定任务或旧会话的恢复点交给 `dev-handoff`，当前机制解释交给 `dev-learn`，历史设计理由交给 `dev-why`，稳定个人方式交给 `dev-personalize`。
