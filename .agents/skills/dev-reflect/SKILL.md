# 从会话改进开发方法

按[会话反思方法](references/reflection-method.md)审阅当前或指定会话，读取相关技能，定位能改变以后行为的改进。交付接受项（Accepted）、拒绝项（Rejected）和待办（Backlog），有明确编辑授权时同时落实接受项。

需要定位或读原始会话时使用 `dev-session-history`。原始记录不可用时用现有对话、用户提供材料与已核实的产物，指出未覆盖范围。将项目长期事实交给 `dev-archive`，稳定个人惯例交给 `dev-personalize`，机械防错交给 `dev-guardrails`。复盘可在任务进行中完成，随后回到原任务。
