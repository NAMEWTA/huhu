## 当前执行建议

同一资源池内，主会话按一个活跃会话计入总数；新增名额只计算额外会话。主会话亲自构建或测试时，按执行主机计入相应的重任务预算。

一句话说明包含主会话的 Agent 建议总数、可同时运行的重任务与每项内部 worker、当前还能增加几个；缺少成本时直接说明哪些数字尚不能确认。

| 保留 worktree | | | | 纯源码/已初始化等指定状态、所在卷、共享缓存与集成树预留 |

“当前可确认新增”填写在所声明推荐组合下有依据的资源额度，不改成“本次计划/需要新增”。计划新增为 0 时仍分别报告容量；证据不足就写“暂无可确认名额（准入数值 0）”及具体原因。仅有磁盘保留估算时，在首表注明带条件的数量/上界与未确认的创建或初始化条件，不能藏在后文或直接当作启动许可。

同一组合共用预算，各行不能独立同时用满。保留 worktree 数量不增加重任务或 Agent 名额。多资源池分别给表，另列共享父宿主/卷的约束。本次实际选择新增的会话、重任务和工作树数量另写一行即可。
