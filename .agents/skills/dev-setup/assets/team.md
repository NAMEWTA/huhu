## 协作约定

用项目自己的话写分工，可按阶段自由组合。例如主会话实现时按需请人探索；方案未定时由多人并行取证，再由约定的人比较；接口确定后可交给下一位接手实现。派出子任务时写明交回什么、交给谁。移交后续工作时写明谁接手、所需上下文和下一步。采用评审与修订循环时写明验收条件和停止时机。现有规格、验收和资源记录用指针引用，不复制另一份规则或固定主机容量。

用户选择允许多个 task 复用会话时，可采用以下约定，并按实际要求调整：

> 本次任务要求与执行 Agent 会话分开。主会话根据已选规则和实际情况，可将多个 task 依次派给同一 worker session，每项分别交付和验收，同一 worker 同时仅有一项活动派发。主会话与 worker 均可使用当前 CLI 实际支持的压缩能力后继续。同一已授权批次沿用本次选择；需要并行、独立评审或独立候选时使用符合要求的其他执行者。
