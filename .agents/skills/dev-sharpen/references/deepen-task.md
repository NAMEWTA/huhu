适用：把已有任务表达得更深入而不扩大范围，再改写提示词。结果是请求文本；仅改写不运行调查或开发，不把建议写成已确认决定。

1. 说出这个领域的顶尖专业人士会做、但我还没有要求的事情。
2. 指出他们会从什么最原始的材料开始，而不是从已经替我消化过的内容开始。
3. 指出他们会使用的具体方法和工具。
4. 说明除了你或我之外，什么能证明结果正确。

然后改写我的提示词，准确要求上述内容。

让改写后的提示词要求执行者先用实际探针或可运行原型核对可通过实验判定的选择，再根据观察结果推荐做法。只有在原任务确实需要可见体验确认时才绑定正式原型确认。

属于我来作出的产品或偏好选择保持开放，不替我决定。这里只起草提示词，实验由收到该提示词的执行者开展。
