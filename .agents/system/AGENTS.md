# 系统维护资料

- 按真实主机标识建立 `./<主机标识>/` 子目录，保存对应设备的诊断、配置、操作与验证。
- 不跨主机混用事实；跨领域只引用已有记录，不复制竞争版本。
- 主机诊断原件按需放项目根 `temp/system/hosts/<host>/<Change-或主题>/<run-id>/`，由 `/temp/` 规则排除。Herdr 派发回执不另存验收正文。
- 持久验收写所属 Change 的 `evidences/`，只含与 `tasks/` 完全同名的 `.md` 报告。整体验收完成后在 Change 根写 `evidence.md`。
- 不保存密码、令牌或私钥，只记录真实安全存储引用；系统资料不嵌入 `../dev/`。
