# 开发资料导航

- `./changes/` 保存活跃任务，其 `source/` 跟踪完整需求来源；规格、设计讨论、计划、原型和正式结论随 Change 保存。`./notes/` 保存长期知识。
- `./deploy/` 保存环境与发布证据；`./archive/` 保存历史，不代表当前实现。
- `./project/` 保存项目非秘密配置；`./context/` 保存开发环境、资源预算、能力限制与任务上下文。
- `./worktree/` 放忽略的 Git 检出。执行日志、调试截图等过程原件放项目根 `temp/dev/<change-id>/`，任务和组合验证按 dev-verify 取证方法细分，不入 Git。
- 路径相对于本文件所在目录；按任务读取相关子目录的 `AGENTS.md` 和少量记录，不整库加载。
- 项目资料不写入 `../skills/`；系统维护资料独立放在 `../system/`。
