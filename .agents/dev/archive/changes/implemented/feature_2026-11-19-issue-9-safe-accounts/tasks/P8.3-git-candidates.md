# P8.3 验证 Git 暂存只包含可同步资料

Versioning 以实际暂存与对象字节验证白名单，仅纳入一致 Safe 加密材料和允许的模块定义，冲突保留双方密文版本。

**前置产物**　[P1.2](P1.2-save-entry.md)、[P2.1](P2.1-manage-tags.md)；模块配置归属按 P4 至 P7 接入。

**代码入口**　[plugins/versioning/src/engine/sync.ts](../../../../../../../plugins/versioning/src/engine/sync.ts)、[plugins/versioning/test/sync.test.ts](../../../../../../../plugins/versioning/test/sync.test.ts)、[packages/vault/src/write.ts](../../../../../../../packages/vault/src/write.ts)。

## 原型与确认范围

[Safe 原型](../prototype/index.html)的待确认场景为「同步预览的文件范围，具体暂存与字节需在 Git 验证」。此处仅用于对照可见结果。服务行为由下列验证判定。 [版本与用户确认范围](../prototype-review.md)

定位到[保险箱演示区域](../prototype/index.html#main)，核对settingsPage 的 Git 同步入口；实际 Git 暂存和冲突另验。

## 验收

- [ ] 在临时 Git 仓库生成合成资料，调用同步预览并检查实际暂存内容，包含匹配的 keyring/密文，查不到个人字段或机器钥匙。
- [ ] 并发改标签或出现不同加密版本的冲突时不拼接密文；临时 ASKPASS、规则执行环境和缓存始终排除。同机备份按 P8.1 独立检查。

使用新建隔离 Vault 和无价值的合成字段，记录测试入口、平台、操作结果及脱敏标识。实际结果回填本任务。
