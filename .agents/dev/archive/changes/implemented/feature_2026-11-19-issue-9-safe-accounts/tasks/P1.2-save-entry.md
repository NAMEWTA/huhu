# P1.2 一次保存网站及其多个账号

[验收报告](../evidences/P1.2-save-entry.md)

所属交付 P1。本项承接 [Issue S1、A01、A03–A04、B01](../source.md)，行为规则见[个人多账号操作](../spec.md#personal)，设计见[Safe 新格式](../design.md#model)。

## 交付与依赖

Safe 管理 entryId 和独立 accountId，在同一次提交写公共名称、可空网址与多个账号五字段；正常回执仅含 ID、版本与状态。

**前置产物**　[P1.1](P1.1-master-session.md)。

**代码入口**　[plugins/safe/src/engine/safe.ts](../../../../../../../plugins/safe/src/engine/safe.ts)、[plugins/safe/src/engine/crypto.ts](../../../../../../../plugins/safe/src/engine/crypto.ts)、[packages/vault/src/write.ts](../../../../../../../packages/vault/src/write.ts)。

## 原型与确认范围

[Safe 原型](../prototype/index.html)的待确认场景为「新建 Google → 添加三个账号 → 保存 → 重开详情」。此项界面实施前，在记录中核对该场景对应的用户确认、版本及范围。尚未演示的状态须另列，模拟操作仅作体验依据。 [版本与用户确认范围](../prototype-review.md)

定位到[保险箱演示区域](../prototype/index.html#modal)，核对openEdit / showEdit，在新建条目内逐个添加账号。

## 验收

- [ ] 用两个同名账号、一个空密码、前导零手机号及长备注创建 Google，重启解锁逐项对照五字段、三个稳定 ID 与公共信息。
- [ ] 零账号、空必填、无效非空邮箱/网址或磁盘写失败时保留可修正内容，无半个新条目。检查合成明文未出现在清单、日志、幂等回执和全局 FTS。

使用新建隔离 Vault 和无价值的合成字段，记录测试入口、平台、操作结果及脱敏标识。实际结果回填本任务。
