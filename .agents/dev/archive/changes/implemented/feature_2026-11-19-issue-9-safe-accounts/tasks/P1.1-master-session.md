## 原型与确认范围

[Safe 原型](../prototype/index.html)的待确认场景为「初次设置 → 锁屏 → 错误/冷却 → 解锁 → 手动/离开锁定」。此项界面实施前，在记录中核对该场景对应的用户确认、版本及范围。尚未演示的状态须另列，模拟操作仅作体验依据。 [版本与用户确认范围](../prototype-review.md)

定位到[保险箱演示区域](../prototype/index.html#main)，核对lockedPage / enterSafe，演示控制含清洁安装、模拟重启和自动锁定。

## 验收

- [ ] 用合成主密码初始化、重启、解锁后触发手动和设置的自动锁定，状态与会话代可观察；切换回原库需要按其状态解锁。
- [ ] 重复错误主密码得到冷却；损坏 keyring 或清单时提示损坏，原字节不变；锁定后迟到读写拒绝且不回填 UI。

使用新建隔离 Vault 和无价值的合成字段，记录测试入口、平台、操作结果及脱敏标识。实际结果回填本任务。
