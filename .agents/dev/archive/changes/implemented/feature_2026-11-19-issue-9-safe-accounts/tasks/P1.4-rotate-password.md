# P1.4 改主密码后按对应版本解锁

[验收报告](../evidences/P1.4-rotate-password.md)

所属交付 P1。本项承接 [Issue S1、B03–B04](../source.md)，行为规则见[个人多账号操作](../spec.md#personal)，设计见[Safe 新格式](../design.md#model)。

## 交付与依赖

Safe 原子更新与一致数据代匹配的包装 keyring，条目与账号 ID 保持，所属模块的机器认证独立。

**前置产物**　[P1.2](P1.2-save-entry.md)。

**代码入口**　[plugins/safe/src/engine/safe.ts](../../../../../../../plugins/safe/src/engine/safe.ts)、[plugins/safe/src/engine/crypto.ts](../../../../../../../plugins/safe/src/engine/crypto.ts)、[plugins/safe/src/ui/SafeSettingsPage.tsx](../../../../../../../plugins/safe/src/ui/SafeSettingsPage.tsx)。

## 原型与确认范围

[Safe 原型](../prototype/index.html)的待确认场景为「Safe 设置 → 更改主密码 → 锁定再解锁/错误」。此项界面实施前，在记录中核对该场景对应的用户确认、版本及范围。尚未演示的状态须另列，模拟操作仅作体验依据。 [版本与用户确认范围](../prototype-review.md)

定位到[保险箱演示区域](../prototype/index.html#main)，核对settingsPage 的「更改主密码」「创建演示备份」。

## 验收

- [ ] 建含合成账号的加密库，改密码后重启，用新密码读取原值，用旧密码明确失败；变更前保持的快照仍配原密码。
- [ ] 在切换 keyring 前中断或输错原密码，原版本仍可解锁。模拟损坏显示故障，不能重新初始化覆盖。

使用新建隔离 Vault 和无价值的合成字段，记录测试入口、平台、操作结果及脱敏标识。实际结果回填本任务。
