# P3.1 从列表进入多账号表单并保存

所属交付 P3。本项承接 [Issue S2、A01–A04、A07](../source.md)，行为规则见[个人多账号操作](../spec.md#personal)，设计见[两端宿主约束](../design.md#hosts)。

## 交付与依赖

Safe 页面在列表显示摘要与账号数，详情共同编辑公共字段和各账号。处理新增/取消、长内容、窄窗返回与保存反馈。

**前置产物**　[P1.2](P1.2-save-entry.md)、[P1.3](P1.3-edit-account.md)；标签选择用 [P2.1](P2.1-manage-tags.md)。

**代码入口**　[plugins/safe/src/ui/SafeModule.tsx](../../../../../../../plugins/safe/src/ui/SafeModule.tsx)、[packages/workbench/src/contributions.ts](../../../../../../../packages/workbench/src/contributions.ts)、[packages/workbench/src/engine-client/query.ts](../../../../../../../packages/workbench/src/engine-client/query.ts)。

## 原型与确认范围

[Safe 原型](../prototype/index.html)的待确认场景为「列表 → 新建/详情 → 添加账号 → 保存/放弃/冲突 → 返回」。此项界面实施前，在记录中核对该场景对应的用户确认、版本及范围。尚未演示的状态须另列，模拟操作仅作体验依据。 [版本与用户确认范围](../prototype-review.md)

定位到[保险箱演示区域](../prototype/index.html#modal)，核对showEdit 的条目及账号编辑，保存后查看 renderDetail。

## 验收

- [ ] 在桌面和窄窗用键盘创建三账号，切换多标签、长名称/URL、长备注；只改公共信息后保存，重开核对账号数和值。
- [ ] 校验或保存冲突保留输入并定位错误；放弃前可返回继续。锁定/换 Vault 时清除明文草稿和焦点中的私密内容。

使用新建隔离 Vault 和无价值的合成字段，记录测试入口、平台、操作结果及脱敏标识。实际结果回填本任务。
