## 原型与确认范围

[Safe 原型](../prototype/index.html)的待确认场景为「锁定/工具关闭/显式显示；工具目录设置沿 #6 对照」。此处仅用于对照可见结果。服务行为由下列验证判定。 [版本与用户确认范围](../prototype-review.md)

定位到[保险箱演示区域](../prototype/index.html#main)，核对renderDetail 的显隐和锁定状态；外部授权开关与调用归 #6。

## 验收

- [ ] 用 UI、MCP、CLI 和通用 API 对同一合成条目改名并查询，在单独开放后显式读取目标账号；CLI 的敏感输入走受控输入。
- [ ] 关闭敏感读取、锁定或切 Vault 后重放同 key，既不可读旧值亦不进入日志/缓存；关闭外部目录权限不妨碍内部模块认证。

使用新建隔离 Vault 和无价值的合成字段，记录测试入口、平台、操作结果及脱敏标识。实际结果回填本任务。
