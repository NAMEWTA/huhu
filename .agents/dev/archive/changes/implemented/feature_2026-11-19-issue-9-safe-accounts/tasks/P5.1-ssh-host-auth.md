## 交付与依赖

SSH 唯一维护主机、用户名、密码/私钥及口令、agent 或身份文件设置，代理/跳板按 #7 合同解析；#9 负责证实已解除实际 Safe 依赖。

**前置产物**　[P0.2](P0.2-credential-replacement.md)；[#7](../../../../../changes/2026-11-19-issue-7-ssh-module/plan.md) 的 hostId/认证合同。

**代码入口**　[plugins/ssh/src/engine/hosts.ts](../../../../../../../plugins/ssh/src/engine/hosts.ts)、[plugins/ssh/src/engine/index.ts](../../../../../../../plugins/ssh/src/engine/index.ts)、[plugins/ssh/src/ui/SshModule.tsx](../../../../../../../plugins/ssh/src/ui/SshModule.tsx)。

## 原型与确认范围

[Safe 原型](../prototype/index.html)的待确认场景为「SSH 主机设置 → 保存 → 连接/修复」。#9 原型核对凭据归属与独立配置提示。所属模块的完整表单、授权和连接体验由相关 change 的原型或实际入口补验。 [版本与用户确认范围](../prototype-review.md)

定位到[保险箱演示区域](../prototype/index.html#modal)，核对openOwner 的 SSH 主机认证；主机连接须在 #7 真实入口走查。

## 验收

- [ ] 在隔离 SSH 测试服务分别保存密码和私钥主机，按 hostId 连接。在 Safe 未初始化、锁定、停用三种状态复验。
- [ ] 坏口令、替换失败、删除和取消只影响目标主机，普通查询无秘密；主机信任失败按 SSH 流程显示原因。

使用新建隔离 Vault 和无价值的合成字段，记录测试入口、平台、操作结果及脱敏标识。实际结果回填本任务。
