## 交付与依赖

Safe 以稳定 tagId 保存名称、色标及引用，删除/改名/换色跨条目作为一致更新；UI 颜色同时有可读文字。

**前置产物**　[P1.2](P1.2-save-entry.md)。

**代码入口**　[plugins/safe/src/engine/safe.ts](../../../../../../../plugins/safe/src/engine/safe.ts)、[packages/vault/src/write.ts](../../../../../../../packages/vault/src/write.ts)、[plugins/safe/src/ui/SafeModule.tsx](../../../../../../../plugins/safe/src/ui/SafeModule.tsx)。

## 原型与确认范围

[Safe 原型](../prototype/index.html)的待确认场景为「标签管理 → 新建/复用 → 编辑颜色 → 删除/取消」。此项界面实施前，在记录中核对该场景对应的用户确认、版本及范围。尚未演示的状态须另列，模拟操作仅作体验依据。 [版本与用户确认范围](../prototype-review.md)

定位到[保险箱演示区域](../prototype/index.html#modal)，核对openTags / openTag 的标签管理及条目引用。
