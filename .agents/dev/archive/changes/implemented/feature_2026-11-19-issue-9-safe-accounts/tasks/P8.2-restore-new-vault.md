# P8.2 把新格式保险箱恢复到新目录

[验收报告](../evidences/P8.2-restore-new-vault.md)

所属交付 P8。本项承接 [Issue S4、B03–B05、D02](../source.md)，行为规则见[数据、权限与清洁安装](../spec.md#installation)，设计见[Git 与数据包](../design.md#backup)。

## 交付与依赖

Vault 包所有者收录恢复结果，Safe 用备份生成时的主密码打开；各模块重新设置机器认证。所有演练均用本轮创建的新格式隔离资料。

**前置产物**　[P8.1](P8.1-backup-contents.md)、[P1.4](P1.4-rotate-password.md)。

**代码入口**　[packages/vault/src/package/package.ts](../../../../../../../packages/vault/src/package/package.ts)、[plugins/safe/src/engine/crypto.ts](../../../../../../../plugins/safe/src/engine/crypto.ts)、[packages/vault/test/package.test.ts](../../../../../../../packages/vault/test/package.test.ts)。

## 原型与确认范围

[Safe 原型](../prototype/index.html)的待确认场景为「恢复 → 新空目录 → 原快照密码解锁 → 账号与标签/需配置」。此项界面实施前，在记录中核对该场景对应的用户确认、版本及范围。尚未演示的状态须另列，模拟操作仅作体验依据。 [版本与用户确认范围](../prototype-review.md)

定位到[保险箱演示区域](../prototype/index.html#modal)，核对settingsPage 的「恢复演示备份」和 restore-form，选快照后输入当时主密码。

## 验收

- [ ] 备份改密前后各一份并恢复到另一个目录含新 VaultId，用各自密码逐项核对 Google 三账号与标签；机器认证绑定不可随包复用。
- [ ] 分别测试忘记密码、损坏包、缺 keyring、目标非空；返回真实错误并保全原件，不把无法解密的资料报成空库或成功。

使用新建隔离 Vault 和无价值的合成字段，记录测试入口、平台、操作结果及脱敏标识。实际结果回填本任务。
