# S0.1 Mail 使用的源码基线

[任务票据](../tasks/S0.1-source-baseline.md)。下文记录当时的验证范围与结果。

比对 Huhu `bf3942e456c03cd7a4a4070e230557bb45e1ca9c` 和 one-mail `main@d1be24d5bb83c2da7123b167f119d5abd169b0af`。one-mail 为 `zhihui-hu/one-mail` 的本地默认分支检出，提交署名字段为 `i`。其 README 第 223 行明确标注 AGPL-3.0-only，当前提交未跟踪独立 LICENSE 或 COPYING。本次以行为和测试样本对照，产品代码与界面素材引用待采用项确认及许可核对。

| 行为 | one-mail 中核对到的入口 | Huhu 实施和取证入口 |
| --- | --- | --- |
| 18+1 账号预设、厂商图标与认证方式 | `src/shared/provider-metadata.ts` 中 `normalizeProviderKey` 和 `getProviderLogoMetadata` 处理展示归一化。授权提供商在 `src-tauri/src/oauth/provider.rs`，区分 Gmail 和 IMAP。 | S1a.1 核对合成地址、预设主机与自定义设置。状态和账号归 Mail，秘密引用接 #9。配置参数与当前提供商文档分别核对。现有图标满足同样导航语义。 |
| 聚合、搜索与正文定位 | `src/lib/desktop-api.ts` 触发 `conversations_list`、`conversations_find_message`。Tauri `src-tauri/src/commands/data/conversations.rs` 有 `global_search_finds_body_across_accounts_and_uses_account_timeline_offset` 测试。 `commands/data/messages/mod.rs` 的 `messages_load_body` 与 `mail/body/mod.rs` 的 `load_message_body` 处理本机消息 ID 对应的正文。API 同步分别见 `mail/sync/gmail_api.rs` 与 `mail/sync/mod.rs`。 | S0.2 使用相同 RFC822 ID、不同账号的 IMAP UID 和 API nativeId 对照。S2.2、S2.3 核对本地 ID 和正文定位以及账号隔离。 |
| 发件与本地结果 | `commands/data/compose.rs` 的 `compose_send` 调用 `mail/smtp.rs` 的 `send_message` 与 `send_once`。 | S0.2 比较传输取消和 ACK 丢失的窗口。S1b.3、S1b.4 由 Huhu 冻结草稿和 operationId，复测并发认领与重启对账。 |
| 本机备份与远端实现边界 | `commands/backup/native.rs` 有 create/validate/open。 `commands/backup/mod.rs` 有 `native_backup_keeps_required_metadata_and_schema`。 `commands/data/settings.rs` 第 138–164 行的 WebDAV/S3 测试、上传、下载、远端导入返回未迁移错误。 | S6a 验证当前 Vault 新格式备份。S6b 的账号子集冲突及同地址策略等待产品决定。现有远端占位函数不能作为可复用实现。 |
| AI 与提供商 | `src-tauri/src/ai/settings_store.rs`、`context.rs`、`provider.rs`、`tests.rs` 分别对应设置、选中内容、调用与测试。 | S7 的模块凭据和内容授权沿用 Huhu 宿主与 Dispatcher。合成邮箱正文和选中邮件附件用于后续夹具。 |

厂商素材另有 `src/assets/provider-icons/README.md`，不随这份源码对照采用。采用的文件或翻译需注明作者、提交及来源声明，实际引入后再更新 [上游台账](../../../../../../../docs/upstream/ledger.md)。本项尚未执行 S0.2 的协议收发样本，也未访问真实邮箱。

`src/components/account/account-form-types.ts` 的 `accountKinds` 列出 18 个厂商种类与 `custom`。抽查其 `providerPresets` 中 QQ 为 `app_password`，IMAP `imap.qq.com:993`、SMTP `smtp.qq.com:465`。这些值是上游快照证据，接入前另查提供商现行参数。
