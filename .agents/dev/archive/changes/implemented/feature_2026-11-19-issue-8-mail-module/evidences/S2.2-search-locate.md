## 接线

| 接线点 | 行为 |
| --- | --- |
| `plugins/mail/src/engine/conversations.ts` | 从 S2.1 的账号、当前可见目录及公开消息去重规则派生查询，按工作台时区的自然日过滤。跨账号搜索已取回的主题、发件人、公开参与者与正文，返回有限长度摘要。搜索期间账号定义变化会撤掉该账号的旧结果。 |
| `plugins/mail/src/engine/search-text.ts` | 复用 MIME 正文解析及 Mail HTML 文本规则。HTML 查询只提取文本，忽略嵌入脚本、样式、资源 URL 和附件字节。按源内容指纹缓存可重建文本，最多 512 条、600 万余字符。摘要按目录投影，检索期间无需保留全部目录的 EML 副本。 |
| `mail.conversations.search`、`mail.conversations.findMessage` | 搜索结果携带原账号和 IMAP 的目录、UIDVALIDITY、UID、本地消息 ID，或本机已发操作 ID。定位重算原账号联系人及消息页，复核目标仍属于当前公开缓存。读取仍走公开 MailReader，单账号普通原文入口独立保留。 |
| `MailSearch.tsx`、`MailModule.tsx` | 250ms 防抖，按输入和页码标识响应，改词取消在途工作并回到第一页。支持上下键、回车及 Esc。定位切换目标账号和全部时间，居中高亮并交接焦点，窄屏返回可聚焦目标邮件条目。 |
| `plugins/mail/src/ui/index.tsx` | 注册 Workbench `mail.search` 命令。Ctrl/Cmd+K 走宿主命令面板，选择后打开同一个 Mail 搜索。宿主装配可将打开 Mail 的函数传给 `createMailContributions`，从其他模块直接打开同一入口。 |

本地 one-mail 固定在 `d1be24d5bb83c2da7123b167f119d5abd169b0af`，README 声明 AGPL-3.0-only。参考 `src-tauri/src/commands/data/conversations.rs` L51 的定位、L61 的搜索、L77–142 的正文和摘要匹配，`src/components/conversations/use-conversations.ts` L13–31 的自然日筛选、L65–89 的定位跳转，以及同目录 `conversation-workspace/global-search-dialog.tsx` L52–65 的防抖和分页、L101–117 的结果高亮及账号来源。Huhu 使用本机缓存、项目原生 Dialog、既有命令面板及公开阅读器完成接线。

## 验收

| 场景 | 可复查观察 |
| --- | --- |
| A 今天到 B 旧信 | 实际 Edge 工作台从 A 的「今天」打开搜索。B 的十封旧信分为 8、2 两页，显示邮件来源和正文匹配高亮。上下键在后一页移动，输入法确认回车保持搜索，正式回车切至 B 的「全部时间」，焦点进入带短时高亮的原正文。窄屏返回落在该邮件行。 搜索结果（本机原件 `temp/dev/feature_2026-11-19-issue-8-mail-module/integration/legacy-7984bff4/S1-workbench/mail-search-results-390.png`） · 定位正文（本机原件 `temp/dev/feature_2026-11-19-issue-8-mail-module/integration/legacy-7984bff4/S1-workbench/mail-search-located-390.png`） |
| 防抖、回页与取消 | 两次连续输入仅发起最终词请求，探针核对防抖时长。拦住真实 Engine 已返回的第二页，改词后释放旧页，旧结果未进入新搜索。Esc 关闭并返回搜索按钮。通过 Workbench 命令进入后，重复 Ctrl+K 不会叠开命令面板。 |
| 空缓存和无匹配 | 空 Vault 显示没有可搜索缓存，装载缓存后无匹配显示本地未找到。搜索标题持续说明只覆盖已同步历史。 |
| 时间和权限 | 实际工作台核对今天、昨天、近三天及全部时间。Engine 使用台北和洛杉矶自然日、同 UID 和 Message-ID 的不同账号、旧格式快照、HTML 正文、发件人显示名及失效代，核对排序和定位。Bcc、隐藏目录及 HTML 脚本关键字均无结果。 |
| 副作用 | 查询、改词、翻页与复核定位只读本机缓存。Engine 的 IMAP 命令无增量，SMTP 连接、认证、DATA 为 0。工作台用已读合成旧信定位，IMAP、标读 RPC 和 SMTP DATA 计数均无增量。 |

查询范围为当前 Vault 已缓存的可见消息和公开本机已发，沿用 S2.1 的缓存容量与同步范围。缺少可用邮件日期时使用已存在的缓存记录时间。完整首次历史扫描和服务端旧信对账由同步切片接续，S5.2 通知 UI 可复用定位目标和能力。组合桌面装配及 Vault ZIP 由 Lead 接续。

Windows 固定 pnpm 12.10.1、Node 24.21.0、Vitest 3.2.7、Edge 157.0.4341.60。使用真实临时 Engine、实际 Workbench 组件和合成本机回环邮箱。复跑沿用 [Mail 证据脚本](S2.1-contacts.md#复跑)。Modern Web Guidance 核对原生 Dialog 的焦点与关闭、IME 回车处理以及搜索状态播报。
