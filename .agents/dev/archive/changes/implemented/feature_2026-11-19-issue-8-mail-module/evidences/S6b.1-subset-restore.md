# S6b.1 Huhu Mail 子集恢复

[任务票据](../tasks/S6b.1-subset-restore.md)。下文记录当时的验证范围与结果。

邮件设置可导出所选邮箱，再从 ZIP 预检并勾选可恢复项。归档使用 Vault 的 Huhu v1 清单和 SHA 校验，Mail 子集负载另有类型与版本。入口限 5 MiB 压缩包，Mail 负载限 36 MiB，受管附件合计限 25 MiB。内容包括非秘密邮箱配置、草稿、已读覆盖、受管附件以及发件记录。缺少的附件显示待重新选择，恢复的邮箱需重新配置本机认证。

预检只在临时目录解包，目标 Vault 无写入。保留原账号标识以维持草稿、投递与读状态的引用。预检列出同地址的当前账号，提交重新检查地址与记录标识。已选的无冲突账号按账号分别暂存与发布。账号定义最后发布，重开根据持久账本和该账号的恢复指纹确认已完成项或回滚暂存数据。取消适用于提交前的预检。多选时若后续账号失败，重新预检可区分此前已完成项，可重试其余项。

Windows 隔离 Engine 通过 HTTP 入口验证了双账号合成 ZIP、Huhu 清单导入、密码未打包、错误类型、损坏 ZIP 和压缩目录虚报超限。同地址账号及第三个无关账号的内容和修订保持原样。未确认、取消及混选冲突账号均拒绝写入。注入草稿写入故障回滚暂存附件，提交期间拒绝把取消误报为成功。注入确认记录写入故障后，重开核实已提交账号并补写确认。同一预检再提交、重开后重新预检均保留原恢复结果。附件摘要与字节、原已读覆盖和未知投递状态一致，回环 SMTP DATA 总计仍为源 Vault 的 1 次。

Windows Electron 生产构建使用两个独立临时 Vault，经 Workbench 勾选合成源邮箱，由 Electron 下载事件将真实 ZIP 保存到测试路径。在另一个 Vault 选择该文件，预检结果标题接收焦点，既有同地址账号显示在冲突项下，冲突项不可勾选。取消后原列表一致。重试并仅勾选可恢复项后，原账号及修订保持，新增一条待配置认证的邮箱。Windows 安装器未运行。
