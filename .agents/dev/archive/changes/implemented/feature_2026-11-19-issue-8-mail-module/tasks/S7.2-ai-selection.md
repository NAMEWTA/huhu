# S7.2 只向已选择的 AI 服务提交选定邮件内容

所属交付 S7。本项承接 [Issue M-08、§8.2](../source.md)，行为规则见[工作台操作](../spec.md#workspace)，设计见[调用与失败处理](../design.md#operations)。

## 交付与依赖

Mail 用户主动选择内容与目的地，可总结、提取待办、对话、起草；只有主动采纳才创建可编辑草稿。

**前置产物**　[S7.1](S7.1-ai-settings.md)、[S2.3](S2.3-read-message.md)；采纳草稿需 [S1b.1](S1b.1-compose-draft.md)。

**代码入口**　[one-mail/src/components/conversations/conversation-message-content.tsx](https://github.com/zhihui-hu/one-mail/tree/d1be24d5bb83c2da7123b167f119d5abd169b0af/src/components/conversations/conversation-message-content.tsx)、[one-mail/src/components/mail/mail-composer/index.tsx](https://github.com/zhihui-hu/one-mail/tree/d1be24d5bb83c2da7123b167f119d5abd169b0af/src/components/mail/mail-composer/index.tsx)、[Huhu Engine 注册与插件生命周期](../../../../../../../apps/engine/src/boot.ts)。拟在 `plugins/mail` 的设置流程落地。

## 原型与确认范围

[Mail 原型](../prototype/index.html)的待确认场景为「阅读 → 选择片段 → AI → 采纳/关闭/失败」。此项界面实施前，在记录中核对该场景对应的用户确认、版本及范围。尚未演示的状态须另列，模拟操作仅作体验依据。 [版本与用户确认范围](../prototype-review.md)

定位到[邮件演示区域](../prototype/index.html#fault)，核对单封邮件 AI 操作和「AI 服务暂不可用」。

## 验收

- [ ] 用两封合成邮件只选一段，检查模拟请求的目的地与字段。总结/待办可读，采纳回复后草稿可修改。
- [ ] 服务中断、取消或输出含操作指令时保留原阅读状态；无自动发信、邮件修改或向第二个服务传送。

使用合成邮箱、消息、附件和模拟交付结果，记录测试 Vault、输入、操作前后结果及实际调用次数。实际结果回填本任务。
