# S8.3 从另一台设备跟进同一次 OAuth 授权

[验收报告](../evidences/S8.3-remote-oauth.md)

所属交付 S8。本项承接 [Issue §3.2、§5.4、§8.2](../source.md)，行为规则见[添加与维护账号](../spec.md#accounts)，设计见[两端宿主约束](../design.md#hosts)。

## 交付与依赖

Mail 显示授权发生的机器和可跟进的会话 ID，回调在绑定的 Engine/账号验证，外部工具可查询或取消。

**前置产物**　[#6](../../feature_2026-11-19-issue-6-unified-tools-web/plan.md) Web 会话与系统浏览器宿主；[S3.1](S3.1-google-consent.md) 或 [S4.1](S4.1-microsoft-consent.md)。

**代码入口**　[apps/desktop/src/preload/index.ts](../../../../../../../apps/desktop/src/preload/index.ts)、[packages/kernel/src/server/ingress.ts](../../../../../../../packages/kernel/src/server/ingress.ts)、[apps/cli/src/commands/call.ts](../../../../../../../apps/cli/src/commands/call.ts)。拟在 `plugins/mail` 的能力适配流程落地。

## 原型与确认范围

[Mail 原型](../prototype/index.html)的待确认场景为「Web 添加 OAuth → 查看授权主机 → 状态/取消」。此项界面实施前，在记录中核对该场景对应的用户确认、版本及范围。尚未演示的状态须另列，模拟操作仅作体验依据。 [版本与用户确认范围](../prototype-review.md)

定位到[邮件演示区域](../prototype/index.html#fault)，核对OAuth 状态与「OAuth 授权拒绝」；第二设备和回调主机另行联验。

## 验收

- [ ] 从第二设备发起模拟会话，在 Engine 侧完成受控回调，然后从 Web 及 CLI 读到同一账号的完成状态。
- [ ] 会话超时、切 Vault 或手动取消后，迟到回调不写 token；没有注册客户端时说明缺少条件。

使用合成邮箱、消息、附件和模拟交付结果，记录测试 Vault、输入、操作前后结果及实际调用次数。实际结果回填本任务。
