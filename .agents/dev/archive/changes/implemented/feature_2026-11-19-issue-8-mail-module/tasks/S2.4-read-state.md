## 原型与确认范围

[Mail 原型](../prototype/index.html)的待确认场景为「未读 → 正文可见 → 已读/仅本地/失败」。此项界面实施前，在记录中核对该场景对应的用户确认、版本及范围。尚未演示的状态须另列，模拟操作仅作体验依据。 [版本与用户确认范围](../prototype-review.md)

定位到[邮件演示区域](../prototype/index.html#fault)，核对阅读区与「远端标读失败」反馈。

- [ ] UID 换代、只读或服务端拒绝时显示实际结果；以迟到快照重放，已提交的本地标记不被静默覆盖。
