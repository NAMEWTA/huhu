## 交付与依赖

Mail 负责人以相同的合成消息和中断时点比较 TS Engine 与必要的 Rust 适配，决定协议状态、取消与本地回执由谁持有。

**前置产物**　[S0.1](S0.1-source-baseline.md)。

**代码入口**　[apps/engine/src/boot.ts](../../../../../../../apps/engine/src/boot.ts)、[one-mail/src-tauri/src/mail/smtp.rs](https://github.com/zhihui-hu/one-mail/tree/d1be24d5bb83c2da7123b167f119d5abd169b0af/src-tauri/src/mail/smtp.rs)。本项先交源码对照与可行性结论。
