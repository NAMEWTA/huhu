## 交付与依赖

Mail 处理可见消息的正文、原文、引用和签名折叠及收件附件元数据；系统外链由宿主处理。

**前置产物**　[S1a.2](S1a.2-first-message.md)。

**代码入口**　[one-mail/src/components/conversations/conversation-message-content.tsx](https://github.com/zhihui-hu/one-mail/tree/d1be24d5bb83c2da7123b167f119d5abd169b0af/src/components/conversations/conversation-message-content.tsx)、[apps/desktop/src/preload/index.ts](../../../../../../../apps/desktop/src/preload/index.ts)。拟在 `plugins/mail` 的联系人、阅读与写信流程落地。

## 原型与确认范围

[Mail 原型](../prototype/index.html)的待确认场景为「对话 → 长文、原文、纯文本/HTML → 仅本封加载图片 → 重试」。此项界面实施前，在记录中核对该场景对应的用户确认、版本及范围。尚未演示的状态须另列，模拟操作仅作体验依据。 [版本与用户确认范围](../prototype-review.md)

定位到[邮件演示区域](../prototype/index.html#fault)，核对阅读区和「正文载入失败」，切换两封模拟信复核单封资源状态。

## 验收

- [ ] 合成多封长信，初入到最新，按视口读取并回到底部；查看纯文本/原文、折叠引用再展开，初始网络记录没有外部资源请求。
- [ ] 在隔离环境使用合成富文本夹具，查看原文也不得触发自动联网；主动放行仅影响当前信。读取失败重试保留滚动位置，元数据不显示为已下载。

使用合成邮箱、消息、附件和模拟交付结果，记录测试 Vault、输入、操作前后结果及实际调用次数。实际结果回填本任务。
