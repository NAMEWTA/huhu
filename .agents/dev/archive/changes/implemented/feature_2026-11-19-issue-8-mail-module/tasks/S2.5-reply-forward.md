# S2.5 从原信引用回复或回复全部

所属交付 S2。本项承接 [Issue M-05、M-06](../source.md)，行为规则见[工作台操作](../spec.md#workspace)，设计见[调用与失败处理](../design.md#operations)。

## 交付与依赖

Mail 创建原账号的内联回复草稿，保留 Reply-To、In-Reply-To、References，回复全部排除自己与 Bcc。

**前置产物**　[S1b.1](S1b.1-compose-draft.md)、[S2.3](S2.3-read-message.md)。

**代码入口**　[one-mail/src-tauri/src/commands/data/conversations.rs](https://github.com/zhihui-hu/one-mail/tree/d1be24d5bb83c2da7123b167f119d5abd169b0af/src-tauri/src/commands/data/conversations.rs)、[one-mail/src/components/mail/mail-composer/index.tsx](https://github.com/zhihui-hu/one-mail/tree/d1be24d5bb83c2da7123b167f119d5abd169b0af/src/components/mail/mail-composer/index.tsx)、[Huhu Engine 注册与插件生命周期](../../../../../../../apps/engine/src/boot.ts)。拟在 `plugins/mail` 的联系人、阅读与写信流程落地。

## 原型与确认范围

[Mail 原型](../prototype/index.html)的待确认场景为「正文操作 → 引用回复/回复全部 → 焦点进入编辑器」。此项界面实施前，在记录中核对该场景对应的用户确认、版本及范围。尚未演示的状态须另列，模拟操作仅作体验依据。 [版本与用户确认范围](../prototype-review.md)

定位到[邮件演示区域](../prototype/index.html#main)，核对当前信的内联回复和回复全部。

## 验收

- [x] 对有 Reply-To 和多个自己地址的模拟来信，分别用键盘和右键回复/回复全部；核对发件账号、收件人去重、引用链和焦点。
- [x] 在隐藏密送参与者或收件专用账号上操作，草稿不暴露 Bcc，无法发送时给出原因且无网络投递。

Windows Edge 与实际 Engine 回环验证通过。关闭保存失败后保留编辑内容，再次保存后从草稿列表续编。回复只在明确发送后产生 SMTP DATA，首发与选择性重试均带有原信线程头。 [S2.5 回环证据](../evidence/S2.5-replies.md)
