## 原型与确认范围

[Mail 原型](../prototype/index.html)的待确认场景为「Gmail → 同步状态 → 正文 → 回复及发送结果」。此项界面实施前，在记录中核对该场景对应的用户确认、版本及范围。尚未演示的状态须另列，模拟操作仅作体验依据。 [版本与用户确认范围](../prototype-review.md)

定位到[邮件演示区域](../prototype/index.html#main)，核对Google 邮件的来源、正文和回复结果；history 分页另行联验。

## 验收

- [ ] 合成两个看似相同的数字 UID、不同原生 ID 的消息；多页同步后读对正文并回复原账号，展示实际传输、范围与发送记录。
- [ ] 令 history 失效或第二页中断，仅重扫受影响范围或从已提交游标继续；API 只有本地标读时返回 remoteSynced=false。真实 scope/账号留 S9。

使用合成邮箱、消息、附件和模拟交付结果，记录测试 Vault、输入、操作前后结果及实际调用次数。实际结果回填本任务。
