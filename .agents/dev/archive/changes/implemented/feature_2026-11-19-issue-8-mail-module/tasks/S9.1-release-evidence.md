**代码入口**　[apps/desktop/package.json](../../../../../../../apps/desktop/package.json)、[tests/e2e/packaged/packaged.spec.ts](../../../../../../../tests/e2e/packaged/packaged.spec.ts)、[THIRD_PARTY_NOTICES.md](../../../../../../../THIRD_PARTY_NOTICES.md)。本项复核组合版本与真实平台。

## 原型与确认范围

[Mail 原型](../prototype/index.html)的待确认场景为「桌面与窄屏从选邮箱、搜索、回复到发件结果，再打开设置恢复」。此项界面实施前，在记录中核对该场景对应的用户确认、版本及范围。尚未演示的状态须另列，模拟操作仅作体验依据。 [版本与用户确认范围](../prototype-review.md)

定位到[邮件演示区域](../prototype/index.html#theme)，核对顶部四主题选择、深浅切换及底部「重置演示」。

## 验收

- [ ] 实施版在仓库根执行 pnpm lint、pnpm typecheck、相关 Vitest/Playwright；分别在三平台安装冒烟，核对四主题明暗、键盘、减少动效与已确认原型。
- [ ] 按授权条件另验真实 IMAP/SMTP、Gmail、Outlook，记录日期、scope、实际传输和未测矩阵；遇无注册客户端、未授权账号或缺平台，保留该行缺证，不能从模拟结果推定可用。

使用合成邮箱、消息、附件和模拟交付结果，记录测试 Vault、输入、操作前后结果及实际调用次数。实际结果回填本任务。
