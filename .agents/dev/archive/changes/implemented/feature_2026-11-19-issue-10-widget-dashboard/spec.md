# #10 每个 Vault 的可编排首页

用户可以把两张任务卡设成不同筛选，将 SSH 主机卡移到它们之间，调整大小并保存。重开同一 Vault 时，每张卡的位置、尺寸、配置和操作对象都能恢复。首页只拥有看板的呈现与编排，任务、笔记、连接及其他业务数据仍由所属模块管理。

[完整 Issue 与评论快照](source.md) 已确定一期为一张纵向可延伸的二维网格，面向受控内置贡献。下表补全交互边界。类型、布局与恢复见[设计](design.md)，验收执行入口见[计划](plan.md)。用户尚未确认 HTML 版本。当前开发和验收采用[派发后的用户决定](../../../../../system/herdr-core/2026-11-19-huhu-prototypes-and-slices/topic.md)，下表的 ACC-DASH-12、14、15 已据此更新。无限白板、多看板共享、嵌套容器、云协作、第三方任意 JS UI 及平行布局/权限系统均在范围外。

## 用户验收

| 原验收 ID | 在真实入口执行 | 可观察结果 |
| --- | --- | --- |
| ACC-DASH-01 | 新 Vault 或已有业务数据、尚无布局时进入首页 | 出现来自已启用定义的默认看板，有真实数据或可行动的空态。用户主动移除全部卡片再保存后，显示“添加首个小组件”，重开维持空板。 |
| ACC-DASH-02 | 从编辑把手拖动跨列、跨行，预览碰撞让位并保存，重启 | 放置吸附、允许空位，页面可纵向延伸。保存前后实例 ID、逻辑位置和阅读顺序一致，无重叠。 |
| ACC-DASH-03 | 改变宽高，试到推荐尺寸、最小/最大值、画布边缘 | 看得见合法占位。卡片按容器大小切换内容，而非整体缩小。非法放置回到上次有效草稿并提示。 |
| ACC-DASH-04 | 从查看态点“添加小组件”或“编辑布局”，新增、拖动、改名、改配置、移除或恢复默认后取消 | 所有动作只改变草稿。取消回到进入编辑前的实例及布局，原文件内容一致。恢复默认和恢复单卡推荐尺寸均可在保存前撤销。带未保存改动切换模块或关闭窗口（含退出）时，提供「保存／放弃／继续编辑」。保存成功后才离开；保存失败留在原地并保留草稿。放弃只丢弃本次草稿，继续编辑取消离场。 |
| ACC-DASH-05 | 在可搜索的小组件抽屉按系统/插件筛选。添加两张同类型卡，选择两台 SSH 主机或两组任务筛选 | 类型说明、归属、尺寸预览与配置可用。各自有稳定的 instanceId。单例已存在时解释原因，隐藏的单例可找回。 |
| ACC-DASH-06 | 复制一个可多实例的卡片，再改标题或筛选并保存 | 复制项获得新 ID 和独立配置，原项不变。同一 Vault 重开能按新配置取数。 |
| ACC-DASH-07 | 隐藏/显示、移除一张任务或 SSH 卡 | 显隐可逆，移除仅改变本板实例。业务文件、连接配置和其他实例照常工作。 |
| ACC-DASH-08 | 停用 SSH/Versioning 后再启用 | 查看态不挂载停用组件、不运行查询。编辑态可定位保留的实例。启用后同一 ID、配置和位置恢复。 |
| ACC-DASH-09 | 模拟组件抛错、无数据、请求失败、无权、定义缺失或配置已不合法 | 每卡独立呈现加载、空态、失败/重试、受限或待修复状态，其余卡可用。停用/卸载后只有显式移除才删除实例。修复配置可恢复。 |
| ACC-DASH-10 | A 编辑/保存、切 B，再回 A。附加 A 的请求延迟返回 | B 不出现 A 的实例、业务结果、焦点或缓存。回 A 只见其已提交布局。 |
| ACC-DASH-11 | 只读打开原 Vault，或保存时拒写、磁盘满、回包丢失 | 可读到原布局，存储缺失时给可浏览默认。只读禁用编辑并说明原因。写入失败保留草稿，失联后可核对已提交状态，不假报“已保存”。 |
| ACC-DASH-12 | 用临时 Vault 备份、恢复当前格式，再分别试损坏 JSON、重复/空 ID、越界/重叠及未知版本 | 可核对并恢复一份有效新板。读到损坏内容时提示原因并保全原件，未知版本受保护。产品未发布，取消原 Issue 的 hidden/order 迁移、旧接口与双写。真实旧数据保持原样，实施与验证均使用新建测试目录。 |
| ACC-DASH-13 | 在查看态勾选任务、选文字、滚动列表、点输入框和明确的模块入口 | 业务控件不启动拖动，勾选只完成目标任务。导航只由对应入口触发。 |
| ACC-DASH-14 | 1024×768、1366×768、宽屏、桌面最小窗和更窄 Web 容器，改变系统 DPI、字体缩放、主题 | 无整页横滚/卡片覆盖/控件裁切。宽窄屏共用一份布局。仅缩窗、展开不改已存坐标。窄屏仅提供顺序与尺寸调整；主动调整后保存，桌面重开可见同一实例的新顺序与尺寸。取消则两端恢复原布局。显示与命中一致。 |
| ACC-DASH-15 | 仅用键盘添加、配置、移动、缩放和保存，再开启减少动效 | 桌面键盘与指针可产生相同逻辑布局；窄屏用键盘调顺序与尺寸。焦点可见且有归处，读屏能获知移动结果，减少动效仍显示落点。 |
| ACC-DASH-16 | 快速移动/缩放、多次保存重开、切模块/启停插件 | 同一输入稳定得到同一布局。无重复实例/注册、悬挂监听、持续重绘或布局震荡。 |
| ACC-DASH-17 | 用 manifest 和实际注册快照比对。切换权限/启用状态 | 内置插件声明和实现的类型集合一致，漏报/多报可被检查发现。未启用或无权项不可添加/执行。 |
| ACC-DASH-18 | 逐项从新首页走原总览、今日安排、最近活动、指标、专注、习惯及 Agent CLI | 单一看板保留原功能，今日筛选遵循用户时区，清单/导航、计数与业务模块一致。专注倒计时和习惯数据不随布局迁移。 |

## 一期内容与所有者

| 所有者 | 迁入的真实功能与验收样本 |

| kernel / workbench | 复用 FocusCard、HabitsCard 和独立于首页挂载的 FocusPauseOnClose。活动来源 `health.events`。概览保住任务、笔记、待处理捕获、启用规则四个已有指标与入口，可用现有 `home.summary`。其他卡逐项取数。 |

| agent-cli、automations | 前者提供现有 Agent CLI 的快捷入口，可在能力可用时显示真实状态。后者用现有规则/运行能力显示已启用或最近运行摘要。各自业务演进归 #4/#5。 |
| ssh、versioning | 复用 SshHomeWidget 的主机列表查询，可选单台已保存主机。复用 VersioningHomeWidget 的分支/变更数、未安装 Git/非仓库状态。#7 管 SSH 能力。 |
| 扩展接入 | Mail 在 #8 提供有用途、可授权的真实能力后才可贡献。Safe/MCP 同一规则。卡片不派生 SSH CPU 图表，不复制邮件、密码或完整业务数据进看板文件。#6 负责公共目录和外部授权，#10 提供实际布局读/写契约。 |
