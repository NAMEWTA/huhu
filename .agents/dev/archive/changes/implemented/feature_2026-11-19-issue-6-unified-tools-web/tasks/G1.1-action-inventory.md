## 验收

使用独立测试 Vault。记录所用入口、身份、操作前后版本或状态以及失败实得。

1. 从 Notes 读取、Agent 状态及 SSH 文件动作分别回溯，矩阵能定位 descriptor 或流、owner、schema、真实调用入口和证据位置。
2. 把需要启动 Core 的查询按 read 审核，须标出副作用并退回领域修正；可信回执独立标作内部，不进入开放列表。
