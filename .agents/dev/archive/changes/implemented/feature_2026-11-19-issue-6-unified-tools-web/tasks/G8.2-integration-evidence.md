## 验收

使用独立测试 Vault。记录所用入口、身份、操作前后版本或状态以及失败实得。

1. 未来在同一打包构建串起一次批量授权、四入口读写、LAN 与桌面同步和失效；对照领域任务证据，分别列出各平台实际运行项。
2. 引入一处陈旧策略、一处断流和缺包，结果分别可归因；在同一打包构建复核授权测试主机的 SSH 入口，并引用 #7 对应环境的实测记录。缺少实机条件的项目标记未测。
