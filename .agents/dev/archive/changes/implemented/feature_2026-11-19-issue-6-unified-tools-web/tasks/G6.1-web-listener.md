# G6.1 桌面启停 Web 并看到可用地址

上级交付 **G6 桌面 Web 服务与邀请**。本片承接[规格 · 桌面分享当前工作台](../spec.md#桌面分享当前工作台)与[原 Issue E01、E06、E07](../source.md)。[本组架构及对象归属](../design.md)

**可见结果与边界**　Engine 管理独立 Web listener，桌面展示配置与实际状态；控制及 MCP listener 保持回环。

**前置产物**　可独立开始，使用当前仓库和本片的测试夹具。

**已有代码入口**　[apps/engine/src/boot.ts](../../../../../../../apps/engine/src/boot.ts)、[packages/kernel/src/server/ingress.ts](../../../../../../../packages/kernel/src/server/ingress.ts)、[packages/kernel/src/server/http-app.ts](../../../../../../../packages/kernel/src/server/http-app.ts)、[packages/workbench/src/gateway/GatewayModule.tsx](../../../../../../../packages/workbench/src/gateway/GatewayModule.tsx)。

## 验收

使用独立测试 Vault。记录所用入口、身份、操作前后版本或状态以及失败实得。

1. 用测试 Vault 切本机与 LAN、自动端口与指定端口，比较实际监听和列表；多网卡、IPv6 标明接口与可打开地址。
2. 端口占用或网卡消失时显示原因，列表不再提供不可用地址；停止 Web 后桌面与控制入口继续运行。

## 原型对照与确认范围

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「Web 服务」对照「桌面 Web 服务／关闭、仅本机、局域网、端口错误」。待用户确认该场景的入口、状态反馈以及上述失败后能采取的动作。落地界面前按[原型确认记录](../prototype-review.md)核对具体版本和覆盖范围；演示未覆盖的细节单列待走查。
