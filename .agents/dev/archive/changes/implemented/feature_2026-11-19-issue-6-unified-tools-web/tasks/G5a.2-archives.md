## 验收

使用独立测试 Vault。记录所用入口、身份、操作前后版本或状态以及失败实得。

1. 新建测试类型、建档案、关联文件并查询，再编辑及删除，外部结果逐项与领域查询核对。
2. 引用不存在的类型或文件时返回具体错误，原档案关联和版本保持。
