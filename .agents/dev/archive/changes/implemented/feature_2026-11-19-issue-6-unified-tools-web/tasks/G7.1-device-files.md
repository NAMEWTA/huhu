## 验收

使用独立测试 Vault。记录所用入口、身份、操作前后版本或状态以及失败实得。

1. 在浏览器设备与 Engine 准备同名不同内容的夹具，从设备上传再下载；按大小与摘要识别来源，CLI 客户端另做同名用例。
2. 取消上传或本地保存失败时区分传送与保存状态；不把客户端路径解释为 Engine 路径，旧目标内容保持。

## 原型对照与确认范围

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「浏览器工作台」对照「浏览器工作台／选择文件、传输进度与下载」。文件页只做设备文件交互对照。待用户确认该场景的入口、状态反馈以及上述失败后能采取的动作。落地界面前按[原型确认记录](../prototype-review.md)核对具体版本和覆盖范围；演示未覆盖的细节单列待走查。
