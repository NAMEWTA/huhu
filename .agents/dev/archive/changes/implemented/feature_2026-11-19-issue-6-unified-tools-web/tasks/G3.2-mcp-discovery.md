## Windows 服务开关证据

以固定版 pnpm 启动实际 stdio 子进程并保持连接。默认目录为空。开启服务及 `vault.info` 后可发现该工具，关闭 MCP 后原连接再次查询时目录清空，使用客户端缓存的工具名调用返回 `PERMISSION_DENIED`。同一时刻 CLI 仍可调用 `vault.info`。现有 HTTP 验证覆盖未启用端点及已启用端点的身份检查与工具授权。此轮包含 CLI、工具策略和实际 Core 的 14 条用例。 [stdio 进程测试](../../../../../../../apps/cli/test/cli.test.ts)

在同一 Windows Engine 通过 HTTP 与 stdio 取得相同的 `tasks.list` 数组结构化返回。SDK 按声明的结果 schema 校验标量和数组。工具名保持不变且结果 schema 由字符串改为数组时，连接收到一条 `tools/list_changed` 并能重读声明。旧客户端仍可读 text 内容。CLI 与受控终端回归一起运行，16 项通过。 [测试源码](../../../../../../../apps/cli/test/cli.test.ts)
