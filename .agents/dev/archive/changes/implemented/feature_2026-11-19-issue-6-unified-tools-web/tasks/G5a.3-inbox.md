## 验收

使用独立测试 Vault。记录所用入口、身份、操作前后版本或状态以及失败实得。

1. 从外部采集两条样例，分别走转换/撤销与忽略/恢复，最后删除；界面按业务事件更新对应项。
2. 同一意图重试转换不会产生两个目标，旧版本编辑给出冲突并可重读。
