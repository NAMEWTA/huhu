# G3.1 CLI 与外部 API 发现并调用同一能力

上级交付 **G3 外部适配器**。本片承接[规格 · 目录、身份与调用](../spec.md#目录身份与调用)与[原 Issue C02、C03、C04](../source.md)。[本组架构及对象归属](../design.md)

**可见结果与边界**　CLI 处理 list/describe、文件或 stdin 输入、JSON 输出；通用 API 消费同一投影，不另设权限表。

**前置产物**　[G2.3 检查为何可用并在实际调用时复核](G2.3-effective-access.md)

**已有代码入口**　[apps/cli/src/main.ts](../../../../../../../apps/cli/src/main.ts)、[apps/cli/src/commands/call.ts](../../../../../../../apps/cli/src/commands/call.ts)、[packages/kernel/src/server/http-app.ts](../../../../../../../packages/kernel/src/server/http-app.ts)、[packages/kernel/src/dispatcher.ts](../../../../../../../packages/kernel/src/dispatcher.ts)。

## 验收

使用独立测试 Vault。记录所用入口、身份、操作前后版本或状态以及失败实得。

1. 只开放笔记读，关闭业务 capabilities.list，经 CLI 与 API 发现同一 canonical ID、读取同一夹具，结构和业务版本相符。
2. 类型错误、未授权与未知 ID 分别返回对应错误，CLI JSON 保留 code、retryable、details 和可用的 operationId。
