## 验收

使用独立测试 Vault。记录所用入口、身份、操作前后版本或状态以及失败实得。

1. 通过 MCP、CLI、服务设置进入同一页；用超过 200 行夹具组合筛选并全选、滚动或翻页，验算同维并集、跨维交集及匹配计数。
2. 停用但已选的行继续可辨；空结果的批量按钮不可提交，清空筛选后不把新出现行静默加入已选集合。
