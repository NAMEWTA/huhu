## 验收

使用独立测试 Vault。记录所用入口、身份、操作前后版本或状态以及失败实得。

1. 关开发服务器，从打包资产打开首页、刷新业务深链，核对脚本 MIME 与桌面预览能力；普通 HTTP 下复制可退回选中文本，意图 ID 可稳定复用。
2. 请求缺失 JS/CSS 明确返回资源错误，缺整包提示不可用；普通浏览器无 preload 时保留可用操作。

## 原型对照与确认范围

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「浏览器工作台」对照「浏览器工作台／首次打开、深链刷新」。打包、MIME 和深链须用打包资产另验。待用户确认该场景的入口、状态反馈以及上述失败后能采取的动作。落地界面前按[原型确认记录](../prototype-review.md)核对具体版本和覆盖范围；演示未覆盖的细节单列待走查。
