## 验收

使用独立测试 Vault。记录所用入口、身份、操作前后版本或状态以及失败实得。

1. 安装含两个合成命令的扩展，只开其一，直接入口与代理结果一致；停插件后仍能看说明。
2. 尝试经已开放代理执行关闭的命令或越出扩展自身权限，得到拒绝并核对无业务写入。

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「工具目录」对照「工具目录／扩展命令状态」。逐命令授权须用测试扩展另验。本片验证领域或接口结果，该场景用于对照结果在工作台的解释。可见效果的确认以[原型确认记录](../prototype-review.md)为准；后端合同可独立验证。
