## 验收

使用独立测试 Vault。记录所用入口、身份、操作前后版本或状态以及失败实得。

1. 切换插件、handler、工具选择、入口和业务前置条件，逐一检查原因，再从同一外部身份调用；点击检查时业务计数始终为零。
2. 外部请求自报 desktop 或继续使用撤销前缓存名，调用仍被拒；撤销后已有作业可存续，后续流访问重新判定。
