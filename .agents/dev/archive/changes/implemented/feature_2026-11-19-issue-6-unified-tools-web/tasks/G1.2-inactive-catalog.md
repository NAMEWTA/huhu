## 验收

使用独立测试 Vault。记录所用入口、身份、操作前后版本或状态以及失败实得。

1. 启用、停用、重开样例插件，在管理目录比较名称、输入输出、归属和 risk；停用只解除 handler，描述仍可读。
2. 尝试重复登记同一 ID，绑定被拒；未装插件与已装但停用给出不同结果。
