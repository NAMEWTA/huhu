## 随包复跑条件

- `tests/e2e/workflows/task-journey.spec.ts` 中的「W8.2/W8.3 候选安装包：跨 Space 分栏、原生会话重连、消费 ACK 重交与历史恢复」需 Linux x64、`HUHU_AGENT_WORKSPACE_ACCEPTANCE=1`、`HUHU_PACKAGED_EXE`、`HUHU_TASK_JOURNEY_PACKAGE_ARTIFACT`、`HUHU_TASK_JOURNEY_PACKAGE_SHA` 及 `HUHU_CODEX_DISPATCH_BIN`。Codex 使用仓库已锁定的原生 ELF，provider 配置和合成 Pi transcript 由用例创建，指定 `HUHU_HERDR_BIN` 会被用例清除以使用包内 Core。
- 夹具由用例为该进程设置 `HUHU_E2E_TASK_RECEIPT_ACK_GATE`。先写入该次派遣的 `dispatch-id`，第一次原结果被截断时记录 `held.json`。停用 Tasks 后写入 `release`，重新启用时核对同一回包和原评论。
- 同文件 T7.2 随包定时原生问答另用 `HUHU_TASK_JOURNEY_ACCEPTANCE=1`。用例建立专用测试 HOME 及回环模型夹具，使用同一候选包和 SHA。候选包验收和 #5 回执证据分别记录。 [T7.2 原生夹具复查](../../feature_2026-11-19-issue-5-task-automation/verification/T7-cutover-linux.md#t72-原生夹具复查)
- `tests/e2e/shell.spec.ts` 包含 Claude/Codex 的只读历史与可访问的禁用说明，以及原生 Pi 的恢复、分支与跨 Space 定位。后者需独立 Pi CLI 与本机 Core。
- 本轮未运行 E2E、构建、打包或全仓门禁。未取安装包 SHA、Windows/macOS 实机、Web/SSH、主题、缩放或高输出性能证据。同候选后续验收由 Lead 完成。
