# Windows 工作区文件与 worktree

Windows 桌面定向用例在两个独立 Space 读到两个同名文件，分别核对目录、绝对文件路径和真实内容。关闭文件窗口后焦点回到原触发按钮。

从其中一个授权的实际 Git 仓库选择空的本机目录并创建新分支。Git porcelain 列表出现该 worktree 后，工作台进入新 Space 并读到检出的真实文件。回到原仓库再次选同一 worktree 时复用原 Space。测试采用隔离 Vault、已提交的测试仓库和临时目录，系统选目录接口使用自动化夹具返回指定目录。

通过入口 `pnpm exec playwright test tests/e2e/shell.spec.ts --grep "Agent 文件面板按两个 Space" --workers 1`。文件列表和本机文件打开沿用 Vault 的路径检查，选目录和 Git 操作通过桌面宿主及现有 Engine Git 调用完成。
