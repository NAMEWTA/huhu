# W7.3 Windows 桌面受保护启动

用本机 Windows x64、Electron 44.9.1、Herdr Core 0.1.19 和原生宿主运行 `tests/e2e/shell.spec.ts` 的「Agent 受保护启动」用例。测试启动入口为 Agent CLI 菜单的「使用启动环境」，运行带真实 ConPTY 的离线 Node 入口。合成变量通过 ModuleCredentials 配置，未使用真实账号或 provider 凭据。

- Safe 未初始化、锁定和停用时均完成预览、确认启动、读回遮蔽输出、键盘互动和正常退出。预览期间无子进程；确认后由目标进程验证 stdin/stdout 均为 TTY，并核对收到的合成变量摘要。
- Engine 只在核对原 Core 终端的 PID 和 Windows 创建时间后，从凭据所有者取得本次输入。公开 Core 参数仅包含宿主命令及匹配身份。私有 broker 确认消费和运行分别落盘，领取不明时保留原请求供核对。
- 本机原生宿主使用 Go 1.26.7。加入两项保护值共享前缀的回归后，同轮调试二进制 SHA-256 是 `2a5a8d1598354ce8191a5dbd42c79fb534e5a3ac33d60f642d930daf63dbc5b9`。独立审查的真实 Pi 离线测试仍见 [原生宿主证据](W7.3-native-pty.md)。正式候选包需要再核对随包宿主与资源路径。

复验前运行 `& .\native\agent-pty\build.ps1 -Test` 与 `pnpm build`，随后在临时 Windows Vault 运行 `pnpm exec playwright test tests/e2e/shell.spec.ts --grep "Agent 受保护启动" --workers 1`。
