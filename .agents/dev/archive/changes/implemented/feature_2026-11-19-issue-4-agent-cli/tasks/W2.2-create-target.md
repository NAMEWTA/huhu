# W2.2 从触发处新建 Tab 或填充指定叶子

[验收报告](../evidences/W2.2-create-target.md)

Tab 加号追加到所属 Space，空叶子、快捷键和菜单向各自冻结的目标提交；打开菜单后切页也能找回结果。

归属 W2，对应 [Issue #4 验收矩阵](../source.md) A03、A04、A05、A07、A08、E03、E06。[行为规格 · 工作区中的操作](../spec.md#工作区中的操作) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　[W2.1](W2.1-space-document.md) 的稳定目标树，[W1.2](W1.2-launch-reconcile.md) 的启动凭据，[W0.1](W0.1-source-map.md) 的创建入口对照。
- **职责与边界**　本片拥有新建意图、菜单定位和焦点；四向树插入由 W3.1 实现。目标先关闭时的展示选项见设计末节，只阻塞该状态。
- **现有代码入口**　[agent-cli/ui/AgentCliModule.tsx](../../../../../../../plugins/agent-cli/src/ui/AgentCliModule.tsx) · [agent-cli/ui/LaunchMenu.tsx](../../../../../../../plugins/agent-cli/src/ui/LaunchMenu.tsx) · `agent-cli/ui/SplitView.tsx`（原规划路径，当前已迁移） · [agent-cli/engine/spaces.ts](../../../../../../../plugins/agent-cli/src/engine/spaces.ts) · [orca/src/renderer/src/components/tab-group/landing/SplitPaneLanding.tsx](https://github.com/stablyai/orca/tree/8bc232f5ed8b4b36fec0c5f0f85ab96b4c0ccdf3/src/renderer/src/components/tab-group/landing/SplitPaneLanding.tsx)。
- **原型走查**　[Tab 加号、空 pane、方向菜单 → 取消/目标消失](../prototype/index.html#editor)。失效目标是未决展示选项。确认菜单、迟到反馈和找回方式。该界面范围待用户按版本确认，实施前核对[原型确认记录](../prototype-review.md)中的资源指纹、场景与实际确认范围；未演示的分支单列。

## 验收与取证

1. 从各入口选择 provider、模型和参数，核对 Space/revision、tab/leaf、cwd 和操作 ID；靠边可用、Esc/外点回到触发者。
2. 检测结果迟到和 IME Enter 不误选；在 B 发起后切 A 或关闭 B 的目标，A 焦点/树不变，已启动者在 B 可查。
