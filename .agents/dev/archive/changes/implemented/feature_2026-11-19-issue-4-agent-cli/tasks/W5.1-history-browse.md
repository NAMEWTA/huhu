# W5.1 搜索历史并只读预览

用户按范围、provider 或文字查记录，可固定、分页、预览并看到扫描进度和坏记录原因。

归属 W5，对应 [Issue #4 验收矩阵](../source.md) D01、D05、D06、D07、D08。[行为规格 · 历史、文件与完整界面](../spec.md#历史文件与完整界面) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　[W0.1](W0.1-source-map.md) 的历史入口与测试；已有 Space 公共读取足以验证归属。
- **职责与边界**　身份含机器、来源、provider、原生引用及规范化路径。历史 pin、移除视图、删除源文件的效果独立。
- **现有代码入口**　[agent-cli/ui/history/HistoryPanel.tsx](../../../../../../../plugins/agent-cli/src/ui/history/HistoryPanel.tsx) · [agent-cli/engine/history/scanner.ts](../../../../../../../plugins/agent-cli/src/engine/history/scanner.ts) · [agent-cli/engine/history/transcript.ts](../../../../../../../plugins/agent-cli/src/engine/history/transcript.ts) · [agent-cli/engine/pins.ts](../../../../../../../plugins/agent-cli/src/engine/pins.ts)。
- **原型走查**　[历史 → 搜索、分组、固定、预览](../prototype/index.html#inspect-body)。原型能按范围搜索、固定或加载更多，大规模扫描/损坏另验。确认空态、长记录与错误原因。该界面范围待用户按版本确认，实施前核对[原型确认记录](../prototype-review.md)中的资源指纹、场景与实际确认范围；未演示的分支单列。

## 验收与取证

1. 用重叠目录、同名原生 ID、Unicode 与大历史查询，切范围、分组、排序、pin、键盘选行并加载更多；核对总数、截断与原始文件。
2. 搜索或预览迟到、坏记录、目录消失、空结果时仍显示相应状态。取消固定/预览后源文件字节与进程数保持。若产品提供删除原生历史，只用一次性样本验证取消无写入、确认前揭示确切文件范围。

在仓库根用 `pnpm exec vitest run` 加下方对应的 `.test.ts` 路径执行领域回归，再按上面的实际入口补齐行为证据。 [plugins/agent-cli/test/history.test.ts](../../../../../../../plugins/agent-cli/test/history.test.ts) · [plugins/agent-cli/test/transcript.test.ts](../../../../../../../plugins/agent-cli/test/transcript.test.ts)
