# W7.1 在当前工作区打开文件与变更

切换工作区后，Files/Changes 面板展示该目录的文件与 Git 变更，打开的是选中的真实路径。

归属 W7，对应 [Issue #4 验收矩阵](../source.md) E01、E02、E03。[行为规格 · 历史、文件与完整界面](../spec.md#历史文件与完整界面) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　[W2.1](W2.1-space-document.md) 的机器、Space 目录和归属；桌面使用现有宿主，Web 目录选择需 #6 授权入口。
- **职责与边界**　复用文件和 Git 能力，用户显式选择 Engine 主机目录，Git 短时失联保留已知事实。
- **现有代码入口**　[ui/AgentCliModule.tsx](../../../../../../../plugins/agent-cli/src/ui/AgentCliModule.tsx) · [engine/spaces.ts](../../../../../../../plugins/agent-cli/src/engine/spaces.ts) · [ui/ReviewPanel.tsx](../../../../../../../plugins/agent-cli/src/ui/ReviewPanel.tsx) · [engine/git.ts](../../../../../../../plugins/versioning/src/engine/git.ts) · [preload/index.ts](../../../../../../../apps/desktop/src/preload/index.ts)。
- **原型走查**　[工作区 → Files/Changes、打开文件](../prototype/index.html#agent-inspector)。确认侧栏收放、目录标识及错误。对应体验待用户按[原型确认记录](../prototype-review.md)的指纹和范围确认。

## 验收与取证

1. 在两个已授权的目录放同名文件，仅修改其中一个。从两个 Space 各自打开文件和变更，对照实际路径；窄窗收起侧栏后焦点回到原 pane。
2. 取消目录选择、文件已移动、越权路径或短时 Git 失败时，原 Space 与已知归属保留，原因和重查入口可见。

在仓库根用 `pnpm exec vitest run` 加下方对应的 `.test.ts` 路径执行领域回归，再按上面的实际入口补齐行为证据。 [plugins/agent-cli/test/review.test.ts](../../../../../../../plugins/agent-cli/test/review.test.ts) · [plugins/agent-cli/test/agent.test.ts](../../../../../../../plugins/agent-cli/test/agent.test.ts)
