# W7.2 将评审意见发给原会话

[验收报告](../evidences/W7.2-review-send.md)

评审意见可预览并发送到绑定的原终端，发生争用时可回到该评审核实。

归属 W7，对应 [Issue #4 验收矩阵](../source.md) E02、F01。[行为规格 · 历史、文件与完整界面](../spec.md#历史文件与完整界面) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　[W6.1](W6.1-bound-input.md) 的输入仲裁；复用现有评审记录与送达入口。
- **职责与边界**　review 负责选中意见与回显，Agent CLI 决定是否能输入；评审不占用其他任务的控制权。
- **现有代码入口**　[agent-cli/ui/ReviewPanel.tsx](../../../../../../../plugins/agent-cli/src/ui/ReviewPanel.tsx) · [agent-cli/engine/review.ts](../../../../../../../plugins/agent-cli/src/engine/review.ts) · [agent-cli/engine/sessions.ts](../../../../../../../plugins/agent-cli/src/engine/sessions.ts)。
- **原型走查**　[Files/Changes → 评审发送、待核实](../prototype/index.html#inspect-body)。原型提供模拟评审发送。确认目标提示和重查入口。该界面范围待用户按版本确认，实施前核对[原型确认记录](../prototype-review.md)中的资源指纹、场景与实际确认范围；未演示的分支单列。

## 验收与取证

1. 在两个 Space 各开一会话，从评审选两条意见发送，实际原终端收到一次，另一个无输入。
2. 预览后人工接管或发送回包丢失，再打开评审显示忙/未知；重复点击不造成双发。

在仓库根用 `pnpm exec vitest run` 加下方对应的 `.test.ts` 路径执行领域回归，再按上面的实际入口补齐行为证据。 [plugins/agent-cli/test/review.test.ts](../../../../../../../plugins/agent-cli/test/review.test.ts) · [plugins/agent-cli/test/agent.test.ts](../../../../../../../plugins/agent-cli/test/agent.test.ts)
