# W7.4 建立或打开授权目录的 worktree

[验收报告](../evidences/W7.4-worktree.md)

用户能在指定仓库创建或打开 worktree，在新工作区准确看到它的真实目录。

归属 W7，对应 [Issue #4 验收矩阵](../source.md) E02、F02。[行为规格 · 历史、文件与完整界面](../spec.md#历史文件与完整界面) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　[W7.1](W7.1-files-worktree.md) 的当前目录/文件面板与 [W2.1](W2.1-space-document.md) 的 Space 归属，Web 的主机目录操作取 #6。
- **职责与边界**　工作区管理器用现有 Git/宿主能力，区分交互授权的 Vault 外目录与当前 Vault；归属以规范路径和机器核对。
- **现有代码入口**　[engine/spaces.ts](../../../../../../../plugins/agent-cli/src/engine/spaces.ts) · [ui/AgentCliModule.tsx](../../../../../../../plugins/agent-cli/src/ui/AgentCliModule.tsx) · [engine/git.ts](../../../../../../../plugins/versioning/src/engine/git.ts) · [preload/index.ts](../../../../../../../apps/desktop/src/preload/index.ts)。
- **原型走查**　[文件面板 → 查看可选 worktree、建立/打开](../prototype/index.html#agent-inspector)。确认明确目标、成功落点与失败，模拟列表之外的创建操作仍须走查。对应体验待用户按[原型确认记录](../prototype-review.md)的指纹和范围确认。

## 验收与取证

1. 在一次性测试仓库选择新分支和空目录，建立 worktree、进入 Space，再从另一个 Space 打开同一 worktree；对照 Git 列表、目录与工作区绑定。
2. 目标已占用、路径撤权或 Git 探测暂时失败时保留原工作区；只显示确证状态，禁止以新建同名目录掩盖错误。

在仓库根用 `pnpm exec vitest run` 加下方对应的 `.test.ts` 路径执行领域回归，再按上面的实际入口补齐行为证据。 [plugins/agent-cli/test/review.test.ts](../../../../../../../plugins/agent-cli/test/review.test.ts) · [plugins/agent-cli/test/agent.test.ts](../../../../../../../plugins/agent-cli/test/agent.test.ts)
