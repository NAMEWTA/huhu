# W7.3 保存模块环境并验证实际子进程

命令、模型和环境设置可预览及刷新；在 Safe 未初始化、锁定或停用时，获准的 Agent 仍能使用模块自己的配置。

归属 W7，对应 [Issue #4 验收矩阵](../source.md) C02、C03、C04、C12、C13。[行为规格 · 历史、文件与完整界面](../spec.md#历史文件与完整界面) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　[W1.1](W1.1-launch.md) 的 resolver；持久秘密与备份范围采用 #9 的模块认证合同。
- **职责与边界**　普通项返回可读值；秘密仅暴露已配置状态，单次值只用于该次授权。Core 有环境记录的终端结束后核验清理及失败重试。
- **现有代码入口**　[agent-cli/engine/settings.ts](../../../../../../../plugins/agent-cli/src/engine/settings.ts) · [agent-cli/ui/AgentSettingsPage.tsx](../../../../../../../plugins/agent-cli/src/ui/AgentSettingsPage.tsx) · [agent-cli/engine/detect.ts](../../../../../../../plugins/agent-cli/src/engine/detect.ts) · [agent-cli/engine/launch.ts](../../../../../../../plugins/agent-cli/src/engine/launch.ts) · [agent-cli/engine/sessions.ts](../../../../../../../plugins/agent-cli/src/engine/sessions.ts)。
- **原型走查**　[设置 → 启动预览、环境状态、检测错误](../prototype/index.html#editor)。从现场进入「Agent 启动设置」；密钥轮换与清理留待真实环境。确认遮蔽、刷新与恢复。该界面范围待用户按版本确认，实施前核对[原型确认记录](../prototype-review.md)中的资源指纹、场景与实际确认范围；未演示的分支单列。

## 验收与取证

1. 以假秘密配置/轮换，在三个 Safe 状态分别调用预览和实际安装包，核对预览无副作用、获准的进程能使用输入，结束后无残留。
2. 删配置、密钥不可用或清理失败时，展示补配/重试且不回显值；逐查 UI、诊断、导出、Core 环境记录。

在仓库根用 `pnpm exec vitest run` 加下方对应的 `.test.ts` 路径执行领域回归，再按上面的实际入口补齐行为证据。 [plugins/agent-cli/test/review.test.ts](../../../../../../../plugins/agent-cli/test/review.test.ts) · [plugins/agent-cli/test/agent.test.ts](../../../../../../../plugins/agent-cli/test/agent.test.ts)
