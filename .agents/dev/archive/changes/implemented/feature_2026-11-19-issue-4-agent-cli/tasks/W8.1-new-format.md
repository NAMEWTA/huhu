# W8.1 恢复新格式工作区并核对布局边界

[验收报告](../evidences/W8.1-new-format.md)

新建测试 Vault 备份后可正常恢复约定的数据，用户能辨认本机布局与包内数据的边界。

归属 W8，对应 [Issue #4 验收矩阵](../source.md) B08、F02、F05。[行为规格 · 历史、文件与完整界面](../spec.md#历史文件与完整界面) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　[W2.1](W2.1-space-document.md) 的权威文档及 #9 对机器秘密导出边界的约定。布局是否随包由设计待决项决定，仅阻塞布局快照部分。
- **职责与边界**　在新格式、空白目标和测试数据上核对 package、sync 的写入及排除范围。本片拥有布局快照与恢复边界，工作区调用方在候选包中统一切换。
- **现有代码入口**　[package/package.ts](../../../../../../../packages/vault/src/package/package.ts) · [plugins/versioning/src/engine/sync.ts](../../../../../../../plugins/versioning/src/engine/sync.ts) · [agent-cli/engine/spaces.ts](../../../../../../../plugins/agent-cli/src/engine/spaces.ts) · [agent-cli/engine/index.ts](../../../../../../../plugins/agent-cli/src/engine/index.ts) · [package.json](../../../../../../../package.json)。
- **原型走查**　[备份恢复后的工作区 → 未绑定或仅本机布局](../prototype/index.html#spaces)。原型仅用于回看恢复目的地。数据包操作与布局取舍尚无本页确认。仅此呈现待对应选择确认。该界面范围待用户按版本确认，实施前核对[原型确认记录](../prototype-review.md)中的资源指纹、场景与实际确认范围；未演示的分支单列。

## 验收与取证

1. 从全新 Vault 建两 Space，备份、还原到另一空目录；核对约定业务数据、排除项和恢复后零次隐式启动。纳入布局时核对已接受版本与失效目录；排除时核对说明及同机重开。
2. 模拟包损坏或目标目录不可用，失败保持可见且不破坏目标；查旧写入口及 sync 白名单残留，确认无双写。
