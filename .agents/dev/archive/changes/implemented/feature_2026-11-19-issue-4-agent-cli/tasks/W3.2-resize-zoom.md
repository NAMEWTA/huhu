# W3.2 调整分隔条并放大当前输入目标

鼠标或键盘调宽高，窄窗仍能输入；放大非活动叶子后，键入文字抵达该终端。

归属 W3，对应 [Issue #4 验收矩阵](../source.md) B02、B03、B04、E03、E07。[行为规格 · 工作区中的操作](../spec.md#工作区中的操作) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　[W3.1](W3.1-split-move.md) 的递归布局和稳定叶子。
- **职责与边界**　比例进结构文档，zoom/focus 归当前视图。保持最小尺寸，取消拖动回到先前比例。
- **现有代码入口**　`agent-cli/ui/SplitView.tsx`（原规划路径，当前已迁移） · `agent-cli/ui/split-layout.ts`（原规划路径，当前已迁移） · [components/TerminalView.tsx](../../../../../../../packages/ui/src/components/TerminalView.tsx)。
- **原型走查**　[分隔条 → 调整、取消、放大/还原](../prototype/index.html#pane-tree)。确认窄窗最小尺寸和焦点。该界面范围待用户按版本确认，实施前核对[原型确认记录](../prototype-review.md)中的资源指纹、场景与实际确认范围；未演示的分支单列。

## 验收与取证

1. 两级分栏中拖分隔条、键盘微调，关闭重开核对比例；放大非活动叶键入标记，再还原，原进程只收到一次。
2. 窄窗持续输出时取消拖动、隐藏再显示、尝试放大单叶。核对邻叶的输入、尺寸和 attach 次数。
