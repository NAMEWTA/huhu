# W1.1 在所选目录启动 shell 或 Agent

[验收报告](../evidences/W1.1-launch.md)

同一配置的预览与实际启动得到同一命令、参数、机器和目录；用户能操作已启动的真实 CLI。

归属 W1，对应 [Issue #4 验收矩阵](../source.md) C01、C02、C03、C04、A08。[行为规格 · 启动、断线与持久化](../spec.md#启动断线与持久化) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　[W0.2](W0.2-core-capabilities.md) 的运行协议与可用包。
- **职责与边界**　Agent CLI 负责解析和启动。手工继承实时 cwd，显式目录需授权且有效；任务预先冻结的目录单独传入。
- **现有代码入口**　[agent-cli/engine/detect.ts](../../../../../../../plugins/agent-cli/src/engine/detect.ts) · [agent-cli/engine/launch.ts](../../../../../../../plugins/agent-cli/src/engine/launch.ts) · [agent-cli/engine/sessions.ts](../../../../../../../plugins/agent-cli/src/engine/sessions.ts) · [agent-cli/engine/index.ts](../../../../../../../plugins/agent-cli/src/engine/index.ts) · [agent-cli/ui/AgentSettingsPage.tsx](../../../../../../../plugins/agent-cli/src/ui/AgentSettingsPage.tsx)。
- **原型走查**　[打开 Agent CLI → 新建与启动错误](../prototype/index.html#editor)。shim 与原生登录只可在实机核验。确认选择器、检测与启动状态，真实可运行性另验。该界面范围待用户按版本确认，实施前核对[原型确认记录](../prototype-review.md)中的资源指纹、场景与实际确认范围；未演示的分支单列。

## 验收与取证

1. 安装包从桌面和带 PATH 的 shell 分别启动，在中文及含空格目录逐项测 shell、Claude、Codex、Pi、原生登录、交互返回 shell、受控非交互退出，记录 argv 边界。
2. 试版本探测失败、禁用、cmd/bat、shim、shebang、非法 cwd、Core 缺失，分别记录阶段与可采取动作；显式错目录启动数为零。

在仓库根用 `pnpm exec vitest run` 加下方对应的 `.test.ts` 路径执行领域回归，再按上面的实际入口补齐行为证据。 [plugins/agent-cli/test/sessions.test.ts](../../../../../../../plugins/agent-cli/test/sessions.test.ts) · [plugins/agent-cli/test/agent.test.ts](../../../../../../../plugins/agent-cli/test/agent.test.ts)
