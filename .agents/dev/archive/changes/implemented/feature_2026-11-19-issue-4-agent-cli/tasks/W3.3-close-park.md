# W3.3 关闭 pane、收起视图并重开最近工作区

用户看到关闭影响，能区分中断、收起、终止和离开窗口；关闭最后一个 Tab 后可从最近位置重开工作区。

归属 W3，对应 [Issue #4 验收矩阵](../source.md) B04、B05、B06、F01。[行为规格 · 工作区中的操作](../spec.md#工作区中的操作) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　[W2.1](W2.1-space-document.md) 的空间归属、[W3.1](W3.1-split-move.md) 的折叠树及 [W0.2](W0.2-core-capabilities.md) 的六种父子存活结果。
- **职责与边界**　进程终态归 Core。仅在真实退出后清理绑定；收纳、关窗与 kill 后的行为分别服从实测。任务完成由用户控制。
- **现有代码入口**　[agent-cli/ui/AgentCliModule.tsx](../../../../../../../plugins/agent-cli/src/ui/AgentCliModule.tsx) · [agent-cli/engine/sessions.ts](../../../../../../../plugins/agent-cli/src/engine/sessions.ts) · [agent-cli/engine/spaces.ts](../../../../../../../plugins/agent-cli/src/engine/spaces.ts) · [agent-cli/engine/herdr-core.ts](../../../../../../../plugins/agent-cli/src/engine/herdr-core.ts) · [herdr-app/src/model.rs](../../../../../../../temp/sources/herdr-app/src/model.rs)。
- **原型走查**　[关闭确认 → 影响范围、取消、收起、最近 Space](../prototype/index.html#pane-bar)。最近工作区与关闭确认可走查；真实杀进程/子终端证据归 W0.2。确认按钮后果和失败找回。该界面范围待用户按版本确认，实施前核对[原型确认记录](../prototype-review.md)中的资源指纹、场景与实际确认范围；未演示的分支单列。

## 验收与取证

1. 关闭中间叶、最后 Tab，再从最近列表打开；分别收起子终端、关闭窗口、发 interrupt/kill，记录子进程、焦点和树折叠。
2. 取消确认、kill 在途或失败时仍可找到原绑定并查看原因。检查 keep 恢复 shell 时旧 Agent 的已失效标识。
