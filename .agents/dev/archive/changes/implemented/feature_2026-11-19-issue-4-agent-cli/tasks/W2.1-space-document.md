# W2.1 在多个工作区切换并恢复各自布局

打开三个 Space，离开再返回能恢复每个 Tab、叶子、比例和窗口焦点。

归属 W2，对应 [Issue #4 验收矩阵](../source.md) A01、A02、B08、E01、F02。[行为规格 · 工作区中的操作](../spec.md#工作区中的操作) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　[W0.2](W0.2-core-capabilities.md) 的 doc 读写/版本协议，[W1.1](W1.1-launch.md) 的真实 session。
- **职责与边界**　工作区服务独占 Vault/machine 的文档写入。焦点按窗口保存，目录 revision 与布局 version 分开，复用公共 Space 入口。
- **现有代码入口**　[agent-cli/engine/spaces.ts](../../../../../../../plugins/agent-cli/src/engine/spaces.ts) · [agent-cli/ui/AgentCliModule.tsx](../../../../../../../plugins/agent-cli/src/ui/AgentCliModule.tsx) · [agent-cli/engine/sessions.ts](../../../../../../../plugins/agent-cli/src/engine/sessions.ts) · [herdr-app/src/mirror_sync.rs](../../../../../../../temp/sources/herdr-app/src/mirror_sync.rs)。
- **原型走查**　[Spaces → 打开目录、切换、恢复](../prototype/index.html#spaces)。用「模拟布局版本冲突」走查冲突提示，损坏、超限另验。确认左栏与 Tab/叶焦点及保存失败提示。该界面范围待用户按版本确认，实施前核对[原型确认记录](../prototype-review.md)中的资源指纹、场景与实际确认范围；未演示的分支单列。

## 验收与取证

1. 用两个窗口打开三个真实目录（含同名目录和获准的 Vault 外目录），新建、重命名、排序并切换；重开核对归属、进程数及布局版本。
2. 并发 CAS、重连漏事件、文档损坏/超限、只读、退出有在途保存和切 Vault 的迟到响应逐一注入；保留最后确认状态，给出保存结果。

在仓库根用 `pnpm exec vitest run` 加下方对应的 `.test.ts` 路径执行领域回归，再按上面的实际入口补齐行为证据。 [plugins/agent-cli/test/sessions.test.ts](../../../../../../../plugins/agent-cli/test/sessions.test.ts) · [tests/e2e](../../../../../../../tests/e2e)
