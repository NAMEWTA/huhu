# W3.1 在任意叶子向四个方向分栏

用户能从任意叶子搭出六个不对称的 pane，既有终端留在各自位置。

归属 W3，对应 [Issue #4 验收矩阵](../source.md) A03、B01、B03。[行为规格 · 工作区中的操作](../spec.md#工作区中的操作) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　[W2.2](W2.2-create-target.md) 的目标意图与 [W0.1](W0.1-source-map.md) 的上游树语义。
- **职责与边界**　每 Tab 一棵树。用稳定 leafId 将四个方向映射到选定子树，分栏后核对既有叶子的身份、顺序和进程。
- **现有代码入口**　`ui/SplitView.tsx`（原规划路径，当前已迁移） · `ui/split-layout.ts`（原规划路径，当前已迁移） · [ui/AgentCliModule.tsx](../../../../../../../plugins/agent-cli/src/ui/AgentCliModule.tsx) · [terminal-topology/terminal-pane-tree.ts](https://github.com/stablyai/orca/tree/8bc232f5ed8b4b36fec0c5f0f85ab96b4c0ccdf3/src/shared/workspace-layout/terminal-topology/terminal-pane-tree.ts)。
- **原型走查**　[pane 方向菜单 → 六叶嵌套](../prototype/index.html#pane-tree)。确认四向落点与取消。对应体验待用户按[原型确认记录](../prototype-review.md)的指纹和范围确认。

## 验收与取证

1. 在不同深度的叶子依次向上、下、左、右分栏，记录六个叶子的屏幕位置、原进程地址和稳定 ID。
2. 在目标分栏过程中取消或从另一窗口关闭目标，原叶序、进程数和 attach 次数保持，冲突可见。

在仓库根用 `pnpm exec vitest run` 加下方对应的 `.test.ts` 路径执行领域回归，再按上面的实际入口补齐行为证据。 [plugins/agent-cli/test/split-layout.test.ts](../../../../../../../plugins/agent-cli/test/split-layout.test.ts) · [tests/e2e](../../../../../../../tests/e2e)
