归属 W0，对应 [Issue #4 验收矩阵](../source.md) B05、C05、F04、F06。[行为规格 · 启动、断线与持久化](../spec.md#启动断线与持久化) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　无。需对应平台的实际包和专用 Core 测试会话。
- **职责与边界**　当前打包锁与调度本任务的 hc 分开记录；支持矩阵逐项写包 SHA、hello/generation、feature 和实测结果。
- **现有代码入口**　[scripts/herdr.lock.json](../../../../../../../scripts/herdr.lock.json) · [scripts/fetch-herdr.mjs](../../../../../../../scripts/fetch-herdr.mjs) · [agent-cli/engine/herdr-core.ts](../../../../../../../plugins/agent-cli/src/engine/herdr-core.ts) · [client.ts](../../../../../../../packages/herdr-client/src/client.ts) · [herdr-core/schema/hc.openrpc.json](../../../../../../../temp/sources/herdr-core/schema/hc.openrpc.json)。
- **原型走查**　[终端详情 → 子终端、只读观察](../prototype/index.html#connection)。生命周期六组实测留在协议验证。这里只验证协议事实。本片的协议或来源核验可先执行。涉及状态呈现时按同一版本的[确认记录](../prototype-review.md)核对。

## 验收与取证

1. 在隔离 Core 建默认子终端、启动时 outlive_parent 的子终端、收纳后的默认子终端，分别让父自然退出及显式 kill；核对六组原进程身份和存活。
2. 注入不支持的 feature 或校验不符的包，启动返回可诊断原因。对自动输入和 provider 代次缺证的能力标未知。
