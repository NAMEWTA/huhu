- **职责与边界**　记录源提交、符号、依赖、目标、许可与测试；第三方界面只作行为对照，样式、图标与文案沿用 Huhu。

## 验收与取证

1. 在同一目录依次开两个 Tab、从右侧发起分栏、打开历史，对照当前 Huhu 与上游的稳定目标和截图，记录复现条件。
2. 旧路径已移动时按符号找对应测试。若某一行为无等价源码，列缺口和受影响项，不登记已迁入。
