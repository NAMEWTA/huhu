## task01 扫描基线

运行 `xvfb-run -a pnpm e2e tests/e2e/knowledge/i18n-zh-hans.spec.ts`。测试在真实 Electron 打开一篇中文样本，逐屏读取可见文字和 `aria-label`、`placeholder`、`title`、`alt`、`data-placeholder`，并遍历文件树的开放 Shadow DOM。断言要求白名单之外无纯拉丁字母界面标签。该探针覆盖所列样本状态，混合中英文的短语和未打开的命令子菜单未计入。

| 界面 | 白名单以外的观察值 |
| --- | --- |
| 文档编辑区、顶部工具栏、批注页、右键菜单、属性页 | 无 |
| 文件树 | `Options` |
| 气泡菜单 | `bold`、`code`、`highlight`、`italic`、`strikethrough`、`underline` |

白名单允许格式、编码与扩展名（`Markdown`、`HTML`、`PDF`、`CSV`、`JSON`、`YAML`、`UTF-8`、`.md`）、系统目录名（`.agents`、`.huhu`）、按键名（`Esc`、`Enter`、`Tab`）和专有名称（`Excalidraw`、`Mermaid`）。完整列表由测试维护。

气泡菜单的读屏名称来自 `InlineFormatButtons.tsx` 的 `action.name`，斜杠菜单的标题来自 `slash-command.ts`、内置组件注册表和嵌入模板常量。上述英文值在对应渲染路径上绕过 Lingui。文件树的 `Options` 来自 `@pierre/trees`。需要扩展写入范围到这些文案来源才能修复。单独增加 PO 条目无法改变扫描结果。

当前 `packages/contracts/src/settings.ts` 无界面语言项。知识库编辑器、文件树、批注宿主分别传入固定的 `zh-Hans`。切换界面语言需要修改设置契约和设置页，再联通宿主的 locale，超出本任务范围。语言即时切换未执行。H03 未通过。

## task03 · 实际插入与语言设置

Lead 撤回即时切换不适用的旧判定。本轮在「设置 → 编辑器」新增知识库编辑器语言，沿用当前 Vault 的 `settings.get` / `settings.update` 和 `editor.knowledgeLocale`。旧设置和非法值回退简体中文。English 与简体中文均由已发布的 Lingui 目录提供。设置页在当前知识库打开期间保留同一编辑器、文件树与详情栏实例。切换立即通知当前查询订阅者。

块的显示名称、属性名、属性值和占位共享消息，序列化的 JSX 名、属性键和已保存正文沿用原格式。补齐 Embed 的空占位、无效地址和属性读屏名称，并扫描了图片、视频、音频缺少扩展名的错误。已有文件使用检测样本，不把用户正文或代码当成界面文案。

逐块测试按斜杠命令 ID 点击，使用源码视图在两次操作间恢复同一份中文样本。逐次扫描结果、属性浮层和媒体错误，按明确的文件格式、快捷键、技术样本和值过滤英文词。中英混合文本参与扫描。HTML 模板验证实际插入的中文代码样本和预览控件，当前集成输出未包含预览内页 `assets/preview-frame.html`，未取得该 iframe 内文渲染证据。表情条目属于插入选择器的非块命令，选择器由并行交付负责。

## task05 · 编辑器通知区

Sonner 的通知区通过 `containerAriaLabel` 接收知识库当前 Lingui 语言的名称，快捷键提示由 Sonner 自行拼接。简体中文读屏名称为「通知 alt+T」，English 为「Notifications alt+T」。E2E 用区域角色和完整名称定位通知区，并在「设置 → 编辑器」切换语言时核对原编辑器通知区的名称。通知区即使没有 toast 也单独纳入中文扫描，避免仅扫描有可见布局的节点而漏掉它。

逐命令复验同时发现表情选择器加载英文词库。经授权，选择器按当前编辑器语言加载离线数据。简体中文使用中文分类与表情读屏名称，英文数据里的搜索词仍作为别名。测试等待真实分类「笑脸」与表情「嘿嘿」后再扫描。另两条离线验证用英文词检索并按中文读屏名称操作，覆盖鼠标、键盘插入，焦点归还、保存重开与源码模式下的属性图标。打包的词库从本地工作台资产加载，监听器未收到其他请求。

最终 Electron 的两个中文扫描覆盖 9 个界面区域、36 个斜杠命令和 4 个错误状态，原白名单外为 0。语言切换核对了同一编辑器通知区和未保存草稿。扫描原始结果（本机原件 `temp/dev/2026-11-18-issue2-closeout/integration/legacy-7984bff4/layout/h03-task05-scan.json`）
