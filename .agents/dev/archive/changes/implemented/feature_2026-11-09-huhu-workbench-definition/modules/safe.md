# 保险箱

插件：`safe`。原型依据：`system.jsx`（`Safe`）、`credential-refs.js`。复用：R-44、R-45。数据：[data-model](../data-model.md) §6 keyring。安全：[security](../security.md) §4。

## 1. 规则

1. 秘密值只以密文存在于 `<Vault>/.huhu/safe/sealed/`，用用户设定的主密码解锁；不使用操作系统钥匙串（brief 约束 4）。
2. 其他模块只保存引用 `safe://<itemId>`，在真正使用时向 safe 请求明文（Engine 进程内服务 `SecretUse.resolve(ref, {plugin, purpose})`），用完即弃；明文不写日志、不进入 Markdown、不出现在能力结果中（`safe.items.reveal` 除外，且只对桌面调用者）。
3. 每个条目声明“允许引用的模块”；不在列表中的模块解析该引用 → `SECRET_REF_INVALID`。
4. 忘记主密码无法恢复秘密；设置流程必须明确告知。

## 3. 界面

- **模块侧栏**：凭据（数量）、访问记录、锁定设置；锁定状态在侧栏标题旁显示锁图标。
- **未设置**：居中卡片“设置保险箱主密码”：主密码、确认主密码、强度提示（长度 ≥ 10 才可提交）、警告“忘记主密码将无法恢复任何已保存的秘密”、勾选“我已了解”后“创建保险箱”。
- **已锁定**：居中卡片锁图标、“保险箱已锁定”、主密码输入、“解锁保险箱”；错误时就地显示“主密码不正确”，连续 5 次后 30 秒内禁用。
- **凭据**（已解锁）：左列列表（搜索；项：类型图标、名称、账户）；右侧详情：名称、类型、账户、秘密值（默认遮罩，“显示”“复制”）、凭据引用（`safe://id`，“复制引用”）、允许引用的模块（chips）、更新时间；页头“新增凭据”“手动锁定”。
- **访问记录**：DataTable（时间、动作 解锁/锁定/查看/复制/使用/修改、条目、主体 桌面用户/模块名、结果）。
- **锁定设置**：自动锁定时间（1/5/15/30 分钟）、“离开保险箱页面时锁定”开关、“修改主密码”。

## 4. 行为

- 设置（`safe.setup`）：生成 32 字节数据密钥 DK；`salt` 16 字节；`KEK = scrypt(password, salt, 32, {N: 2^17, r: 8, p: 1, maxmem: 256 MiB})`；`wrappedKey = seal(KEK, DK)`（R-44 格式）；`keyCheck = HMAC-SHA256(DK, "huhu-safe/check")`；写 `keyring.json`。
- 解锁（`safe.unlock`）：派生 KEK → 解封 DK（GCM 认证失败即密码错误）→ DK 保存在 Engine 内存的解锁会话中；记录审计；发布状态事件。
- 条目保存：元数据写 `items/<id>.json`；值 `seal(DK, value)` 写 `sealed/<id>.bin`（AAD 包含 itemId，防止密文互换）。
- 锁定：清零并丢弃 DK；触发条件：手动、自动锁定计时（任何保险箱操作或 SecretUse 都会重置计时）、离开页面（若开启）、Vault 关闭、插件停用、系统休眠/锁屏（Main 监听 `powerMonitor` 的 `suspend`、`lock-screen` 并通知 Engine）。
- 修改主密码：验证旧密码 → 新 salt 与 KEK → 重新封装 DK；秘密文件不变。
- SecretUse：safe 已锁定 → 调用方得到 `SAFE_LOCKED`；SSH 连接与脚本运行在界面提示“需要解锁保险箱”并提供跳转。
- 复制：`huhuHost.copyText(value, {clearAfterMs: 30000})`。

## 5. 验收

| ID | Given | When | Then |
| --- | --- | --- | --- |
| ACC-SF-01 | 新 Vault | 设置主密码并新增一条 Token 值为唯一标记 `HUHU-MARKER-7f3a` | `.huhu/safe/` 下任何文件、整个 Vault、日志、导出的数据包中搜索不到该标记明文 |
| ACC-SF-02 | 已锁定 | 输入错误密码 5 次 | 显示错误；第 5 次后 30 秒内解锁按钮禁用 |
| ACC-SF-03 | 修改主密码 | 用新密码解锁 | 全部条目可读；旧密码无法解锁 |
| ACC-SF-04 | 条目只允许 ssh 模块引用 | 在脚本环境变量中引用它并运行脚本 | 运行失败 `SECRET_REF_INVALID`，访问记录有拒绝记录 |
| ACC-SF-05 | 自动锁定 1 分钟 | 解锁后 1 分钟无操作 | 自动锁定；之后 SSH 连接提示需要解锁 |
| ACC-SF-06 | MCP 客户端 | 调用 `safe.items.reveal` | `CAPABILITY_NOT_EXPOSED`，且网关设置中无法开放该能力 |
| ACC-SF-07 | 复制秘密值后 30 秒内用户又复制了别的文本 | 30 秒到 | 剪贴板保持用户后来复制的文本 |
