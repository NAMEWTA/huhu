## 2. 健康中心

- **模块侧栏**：系统状态、事件日志、通知。
- **系统状态**：页头“健康中心”+“导出诊断”“运行诊断”；总状态卡片（良好/需处理 n 项/检查中/尚未检查）；检查项列表（图标、名称、结果说明、状态徽标 正常/需处理/未检查/检查失败、右侧跳转或修复动作）。
- **检查项**（每项由所属插件注册 `healthChecks`，结果带 `checkedAt` 与证据摘要）：

| 检查 | 所属 | 证据 | 修复动作 |
| --- | --- | --- | --- |
| Vault 可写 | kernel | 写入并删除 `.huhu/runtime/<m>/probe` | 以只读模式说明 |
| 写者锁 | kernel | 锁持有者为本 Engine | — |
| 未完成操作 | kernel | `operations/` 中 prepared/needs_attention 数 | 逐条：保留当前 / 恢复备份 |
| 文件解析问题 | kernel | 解析失败与 id 冲突文件列表 | 打开文件；为冲突文件生成新 id |
| 索引 | kernel | 文件数、构建耗时 | 重建索引 |
| 插件 | kernel | failed 插件与错误 | 重试启动 |
| Herdr Core | agent-cli | `server.status` 版本与协议 generation | 重启 Core |
| Agent CLI | agent-cli | 检测结果 | 重新检测 |
| 自动化 | automations | unknown/长时间 queued 的运行数 | 打开运行记录 |
| Git 与同步 | versioning | 仓库状态、最近同步结果、冲突数 | 打开版本页 |
| 保险箱 | safe | 是否已设置、keyring 可读 | 打开保险箱 |
| 指南 | agent-guide | 三文件状态 | 打开 Agent 接入 |

  运行诊断可取消；取消后结果为“已取消”，旧结果不再显示为当前。修复动作调用所属插件能力，健康中心本身不写其他插件数据。
- **事件日志**：DataTable（时间、来源模块、事件、状态 成功/记录/故障），搜索与来源筛选。
- **通知**：列表（未读加粗），操作：标为已读、删除、全部标为已读、清除已读（确认；未读保留）。

## 3. 设置

模块侧栏：外观、当前 Vault、Agent 接入（agent-guide 贡献，见 [plugins](plugins.md) §4）、编辑器、日期与时间、快捷键、数据与存储、关于与来源。所有设置即时生效并写 `settings.json`（失败回滚并提示）。

| 页 | 内容 |
| --- | --- |
| 外观 | 主题三选卡片（Pearl 清晰·中性 / SuliWorld 温暖·自然 / Soft 柔和·蓝灰，带缩略预览）；明暗（浅色/深色/跟随系统）；界面字号滑块 12–18；紧凑显示开关；动态效果（跟随系统/标准/减少）；导航宽度滑块 200–360 |
| 当前 Vault | 名称、描述（可编辑，不移动目录）；根目录（只读，“在文件管理器中显示”）；Vault 标识（只读，可复制）；概况（Markdown 文件、目录、任务、档案数量） |
| 编辑器 | 正文字号 14–20；行高 1.4–2.0；正文宽度 680/760/880/全宽；自动保存；显示行号；拼写检查（Chromium 拼写检查，跟随系统语言） |
| 日期与时间 | 显示时区（IANA 列表搜索，默认系统时区）；一周起始（周一/周日）；三个组件示例（日期、日期时间、时间）可实际操作 |
| 快捷键 | 只读表格（design-system §5 的同一数据源） |
| 数据与存储 | 见 §4 |
| 关于与来源 | 版本、平台/架构、Electron 与 Herdr Core 版本；“使用的开源项目”列表（由 `THIRD_PARTY_NOTICES.md` 生成，名称、许可、链接） |

## 4. 数据与存储

分段：文件结构 · 索引与恢复 · 导出与迁移 · 存储规则。

- **文件结构**：按领域筛选（笔记、任务、档案、收件箱、自动化、运行记录、批注、配置、指南）+ 路径搜索；左侧 HUHU 管理的文件树（实际文件，由 kernel 按 kind 注册表列出），右侧原文预览（Markdown/JSON，只读）+“复制内容”“在文件管理器中显示”。
- **索引与恢复**：索引状态（文件数、条目数、构建时间）；“从文件重建索引”（进度、取消；取消后旧索引保留）；未完成操作列表（同健康中心）。
- **导出与迁移**：“导出受管数据包”：对话框显示包含内容（Markdown、配置、保险箱密文）与可选附件（总大小），选择保存位置；生成完成后显示文件路径、大小、SHA-256；说明“数据包不包含文件历史与运行状态；完整备份请直接复制整个 Vault 文件夹（含隐藏目录）”。导入在启动页（[workbench](workbench.md)）。
- **存储规则**：只读表格，内容即 [data-model](../data-model.md) §1 的分类表（谁拥有、位置、能否删除）。

### 关闭前备份（原型 `backup-dialog-v6.jsx`）

“关闭 Vault”“切换 Vault”在存在“未完成操作”或用户在设置中开启“关闭前提示导出数据包”时，先显示对话框：导出数据包 → 勾选“我已确认备份文件可用” → 继续。默认关闭此提示（真实文件已在磁盘）。
