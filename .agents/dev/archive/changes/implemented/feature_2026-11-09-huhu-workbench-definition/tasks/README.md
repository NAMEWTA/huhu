# 任务说明

每个工作包一个文件，任务编号 `Wxx.n`。每个任务都是可独立验收的垂直切片：完成后能演示一个行为或给出一个可验证的契约。

## 任务字段

- **目标**：完成后用户或调用者能做到什么。
- **依据**：对应的模块验收（ACC）、原型位置。
- **前置**：真实阻塞的任务；未列出的任务可并行。
- **位置**：主要新增或修改的目录与文件（实施时可细分文件，不改变模块归属）。
- **复用**：[reuse](../reuse.md) 编号；具体源路径只看 reuse。
- **实现要点**：必须做到的行为与关键做法。
- **异常**：必须处理的失败、取消、并发与恢复情形。
- **测试**：需要新增的自动化测试。
- **完成**：可检查的完成条件。

## 所有任务共同遵守

1. 规格以 `modules/*.md`、`data-model.md`、`interfaces.md`、`design-system.md` 为准；发现规格错误或缺口，先修改对应规格文件再实现，不在代码中自行决定。
2. 复制上游代码时按 [reuse](../reuse.md) §1 记录来源；能复制的不重写。
3. 满足 [quality](../quality.md) §4 的质量门槛；遵守 [engineering](../engineering.md) 规范。
4. 新能力在 `contracts` 定义输入输出模式，在插件中 `defineCapability` 注册，并有契约测试。
5. 界面只用 `packages/ui` 组件与 token；新文案进 i18n 文件。
