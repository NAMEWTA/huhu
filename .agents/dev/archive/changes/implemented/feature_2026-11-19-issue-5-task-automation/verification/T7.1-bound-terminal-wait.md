# 任务绑定终端的等待信号

在 Windows、固定 pnpm 12.10.1 和真实 Herdr Core 0.1.19 上启动合成行协议 provider。保留其活动派遣回执并让该终端发出纯 OSC 7501 blocked，接着发出 working。

- 读回的等待记录显示原会话、原 taskId、原 runId 及同一等待发生编号。两次状态都触发会话查询更新，working 后等待结束。
- 注入首次进程绑定核对返回不可用，终端只发一次 blocked。等待观察者以同一发生编号重查，恢复后关联原 taskId 和 runId。若期间原派遣释放或发生结束，不会改绑或另建 Human 任务。 [重试日志](/D:/Document/code/huhu/temp/issue-baseline/task-bound-waiting-retry.log)
- 启用独立等待任务设置时，绑定会话没有调用创建 Human 任务或写等待评论。受控会话缺少可核对任务绑定时也不进入独立任务路径。
- 原任务详情和自动化运行抽屉复用运行详情。只有同 session、task 和 run 都匹配且仍在运行时才显示终端等待提示，定位按钮仍使用派遣的原会话。

独立会话现有的等待任务流程由原有回归约束。执行回执、结构化问题和答案仍走已有持久协议。 [真实 Core 夹具](../../../../../../../plugins/agent-cli/test/dispatch.live.test.ts) · [运行日志](/D:/Document/code/huhu/temp/issue-baseline/task-bound-waiting.log)
