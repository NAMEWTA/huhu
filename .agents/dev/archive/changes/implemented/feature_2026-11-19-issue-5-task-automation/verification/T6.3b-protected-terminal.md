# T6.3b Windows 终端规则受保护环境

在临时 Vault 通过固定 pnpm 12.10.1 运行 Electron 44.9.1、Windows Credential Manager 和随桌面发布的 Herdr Core 0.1.19。规则命令、变量值及保险箱密码均为测试夹具。

- Safe 尚未初始化时在规则详情添加受保护变量。停用 Safe 后运行同一规则，工作台显示退出成功、公开输出及被遮盖的变量回显。清除后规则继续记录需要的变量名并显示本机未配置，再运行返回失败。
- Safe 锁定时的真实 Core 回归丢弃第一次启动回包。同一请求仍只创建一个终端，重查原地址，正文中的分段值被遮盖。二次提交已消耗的启动票据失败。普通查询与新格式 ZIP 未出现测试值。还原后的规则要求本机补配。
- 旧含环境引用规则可以读出补配状态。生产规则列表和运行入口不解析旧引用，测试读取确认原规则字节保持。显式编辑替换时移除旧引用并暂停规则。
- Windows 控制台中继经独立实验覆盖含空格 helper 路径、stdout、stderr、退出码及同 Core 地址。该中继仅承载现有一次性票据和已处理的终端字节。Desktop 外的已授权规则运行仍需取证。
