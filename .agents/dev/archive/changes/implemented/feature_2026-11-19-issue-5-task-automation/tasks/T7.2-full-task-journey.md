# T7.2 用真实 CLI 签收从明日任务到人工完成

同一个 taskId 从明天到期、后台指定会话接手、原问题获答与同会话继续，到一次结果和人工关闭。

归属 T7，对应 [Issue #5 验收矩阵](../source.md) A01、A02、A03、A04、A07、A08、B02、C01、C08、D04、E06。[行为规格 · 界面、权限与数据范围](../spec.md#界面权限与数据范围) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 验收与取证

1. 用测试时钟走“今天创建、明天执行”，在真实安装包和至少一个支持完整闭环的 CLI 上操作。记录 occurrence、task、run、attempt、session、request、receipt 和 message ID；再验人工立即派及新模板。
2. 在真实 Agent 已保存结果而 Tasks 尚未接收时停用 Tasks，再启用并丢弃一次 Tasks 的 ACK。核对 Agent 重交相同 receiptId，Tasks 已持久保存原 payload 并可重建 delivery，原评论仅一条，Agent 收到匹配 ACK 后停止重交，CLI 工作次数为一。另核中文长输入、原生恢复、窄窗抽屉与前台焦点。
