# T5.2 停用或删除规则并保留入队任务

[验收报告](../evidences/T5.2-manage-rule.md)

用户停用或删除规则，未来触发立即停止；已入队未发任务保留，可从原任务单独取消。

归属 T5，对应 [Issue #5 验收矩阵](../source.md) A08、B01、B07、D08。[行为规格 · 何时自动派遣](../spec.md#何时自动派遣) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　[T1.2](T1.2-accept.md) 的待派身份与 [T1.3](T1.3-cancel-pending.md) 的单项取消；直接复用现有规则开关、删除与调度入口。
- **职责与边界**　规则只拥有未来触发；取消既有任务由 Tasks 接受独立意图。已发送运行、待回答及待投递结果继续有出处。
- **现有代码入口**　[ui/AutomationsModule.tsx](../../../../../../../plugins/automations/src/ui/AutomationsModule.tsx) · [ui/RuleEditor.tsx](../../../../../../../plugins/automations/src/ui/RuleEditor.tsx) · [ui/RunsPanel.tsx](../../../../../../../plugins/automations/src/ui/RunsPanel.tsx) · [engine/service.ts](../../../../../../../plugins/automations/src/engine/service.ts) · [engine/scheduler.ts](../../../../../../../plugins/automations/src/engine/scheduler.ts)。
- **原型走查**　[规则列表 → Switch/删除 → 排队任务 → 单项取消](../prototype/index.html#main-content)。确认影响提示、右侧抽屉和剩余数量。对应体验待用户按[原型确认记录](../prototype-review.md)的指纹和范围确认。

## 验收与取证

1. 各建一条规则并入队两个未发项，分别停用和删除，推进两个周期再重启；未来新增数为零，原 ID 均可查，单独取消一个后另一个仍可领取。
2. 令规则、另一条规则和人工同时命中，停用与领取交错；量出停用生效后的触发、领取和取消，不因停用吞掉已接受输入或中断现场。
