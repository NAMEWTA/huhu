## 实际走查

2026-11-19 使用本机 Microsoft Edge 157.0.4341.60，由 Playwright 操作 `file://` 页面。桌面 1440 × 920 为 Claude 浅色，窄窗 390 × 844 为 Claude 深色。桌面切换 Vercel 并返回 Claude。浏览器启用断网、减少动效及 Europe/London 设备时区，3 份样式及 Huhu 品牌图加载，未见脚本、控制台、资源加载错误或 HTTP(S) 请求。

- 新建表单默认为 Human，取消后看板未新增。新建 Agent 任务并填好目标，保存后在未开始列；派遣后移入进行中。注入普通问题、保存答复，查看两轮记录；提交结果后原任务时间线出现一条结果，现场显示该运行绑定。
- 注入发送未知时看板仍在未开始，核对原发送后才进入进行中。注入结果已存但评论写入失败，补送再重交同一结果，时间线始终只有一条结果。明确未发送后修改正文再重试，执行快照保留原正文；原生暂停答复后仍只有一轮。
- 默认规则改为「未来七天」，预览显示 11 月 15 日至 22 日的半开窗口，同时排除次日才可派的任务。强制忙后手动跑一次，停用和删除各保留三项待派。模拟重启没有自动恢复删除的规则，从原任务取消其中一项后，另一项仍可继续发送。同一时刻重复触发只记录一次。
- 新建模板规则并启用，手动运行创建独立任务；下次日程未跳变。注入只读后人工派遣被拒，任务没有新运行。未来任务的提前派遣确认可取消。
- 390 像素窄窗由看板进入详情，焦点移到详情。纽约春季跳时输入被拒，秋季回拨提示两个 UTC 候选，选较晚后保存为纽约墙钟 01:30。页面宽度没有溢出。

没有在浏览器逐项走完所有窗口、一次性跟进、补充、独立提醒与终端规则的组合。模拟重启演示回执补投和保留规则选择。真实 Engine 重启、持久化写入、授权、CLI、Croner 及并发重放由后续生产验收负责。
