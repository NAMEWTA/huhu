| CLI | 命令与状态 | 实际观察 | 仍需验证 |
| --- | --- | --- | --- |
| Codex 0.171.0 | `codex -a never -s read-only exec --ephemeral --skip-git-repo-check --output-schema response.schema.json --json`，Core `t26` 退出 0 | JSONL 含 `thread.started.thread_id`、`turn.started`、一条 `item.completed` 的 `agent_message` 与 `turn.completed`。结果正文解析成 `{"result":"huhu-provider-probe"}`，与预设 JSON Schema 匹配。另有本机 hook timeout 限制的诊断事件。 | 原生交互问题、后续回复、重新连接、取消、显式现有会话及持久任务结果。ephemeral 运行无法证明重启后恢复。 |
