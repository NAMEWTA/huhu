# H03 简体中文知识库

运行 `xvfb-run -a pnpm e2e tests/e2e/knowledge/i18n-zh-hans.spec.ts`。测试在真实 Electron 打开一篇中文样本，逐屏读取可见文字和 `aria-label`、`placeholder`、`title`、`alt`、`data-placeholder`，并遍历文件树的开放 Shadow DOM。断言要求白名单之外无纯拉丁字母界面标签。该探针覆盖所列样本状态，混合中英文的短语和未打开的命令子菜单未计入。

| 界面 | 白名单以外的观察值 |
| --- | --- |
| 文档编辑区、顶部工具栏、批注页、右键菜单、属性页 | 无 |
| 文件树 | `Options` |
| 气泡菜单 | `bold`、`code`、`highlight`、`italic`、`strikethrough`、`underline` |
| 斜杠菜单 | `Accordion`、`Align block`、`Audio`、`Basic blocks`、`Callout`、`Chart`、`Components`、`Custom SVG`、`Embed`、`Embeds`、`Image`、`Insert`、`Interactive control`、`Math`、`Media`、`Mirror`、`Mirror Source`、`Stat cards`、`Tabs`、`Toggle`、`Video` |

白名单允许格式、编码与扩展名（`Markdown`、`HTML`、`PDF`、`CSV`、`JSON`、`YAML`、`UTF-8`、`.md`）、系统目录名（`.agents`、`.huhu`）、按键名（`Esc`、`Enter`、`Tab`）和专有名称（`Excalidraw`、`Mermaid`）。完整列表由测试维护。

气泡菜单的读屏名称来自 `InlineFormatButtons.tsx` 的 `action.name`，斜杠菜单的标题来自 `slash-command.ts`、内置组件注册表和嵌入模板常量。上述英文值在对应渲染路径上绕过 Lingui。文件树的 `Options` 来自 `@pierre/trees`。需要扩展写入范围到这些文案来源才能修复。单独增加 PO 条目无法改变扫描结果。

当前 `packages/contracts/src/settings.ts` 无界面语言项。知识库编辑器、文件树、批注宿主分别传入固定的 `zh-Hans`。切换界面语言需要修改设置契约和设置页，再联通宿主的 locale，超出本任务范围。语言即时切换未执行。H03 未通过。
