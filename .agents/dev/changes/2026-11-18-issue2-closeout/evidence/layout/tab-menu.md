# B01 标签页右键

作为入口，右键只打开指向该标签的菜单。Shift+F10 和 ContextMenu 键打开同一份命令，方向键与 Home / End 在可用菜单项之间移动，Esc 恢复原标签焦点。菜单复用了 `NoteContextMenu` 的容器和样式，通过原生 Popover 进入顶层并在视口内定位。

关闭、关闭其他与关闭右侧共用既有标签 reducer。关闭集合含当前编辑标签时先等待它的 flush 结果。flush 失败、Vault 切换或当前编辑标签在等待期间变化都会停止这次关闭。复制的是 Vault 相对路径。定位使用当前文件树的选中路径和父目录展开行为，再滚动并聚焦目标行。

参考上游 `EditorTabs.tsx` 的就地关闭、关闭其他与目标命令。Huhu 的知识库标签没有上游临时预览、固定标签、云端分享或编辑器分屏的状态或入口，因此这些命令不在菜单中。档案首页与类型的路径可以复制，定位应用于具有实际文件路径的标签。

## Electron 回归

`tests/e2e/knowledge/layout-tab-menu.spec.ts` 通过真实菜单验证按键、焦点、边界、剪贴板、文件树及关闭前磁盘内容。测试关掉自动保存，确认点击关闭之前原文件字节未变，关闭并重开之后可读取刚才输入的草稿。

交付工作树 `b8bafc9` 的专项验证通过，用例同时覆盖关闭、关闭其他和关闭右侧。按 Esc 后原标签重新获得焦点，复制路径实际读取 Electron 剪贴板，定位后树项获得焦点。
