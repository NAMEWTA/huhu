# 当前变更

- 活跃 Change 放 `./<YYYY-MM-DD-slug>/`。brief 记背景，`decisions.md` 或 `questions/` 记访谈，`spec.md` 定行为，`plan.md` 汇总 `tasks/`。
- 远端 Issue 先关联 Change，正文、可取得的讨论与附件归 `source/`，保留来源版本。
- 出票即建 `evidences/` 下完全同名的普通 `.md`，标「未验证」。失败和复验更新原报告，整体验收写根 `evidence.md`。
- 原型归 `prototype/`，版本与确认范围归 `prototype-review.md`。过程原件归项目根 `temp/dev/`。
- 关闭时由 `dev-archive` 提炼知识到 `../notes/`，来源和正式资料归 `../archive/changes/`。
