## 验收

使用独立测试 Vault。记录所用入口、身份、操作前后版本或状态以及失败实得。

1. 从公共入口新建、编辑、启用并预览测试规则；排入一个任务后分别演示停用和删除，未来触发停止，已入队未发送项仍可单独取消。
2. 重复立即运行意图不重复派发；取消已结束项读取其终态，规则停用不伪报任务取消。
