## 验收

使用独立测试 Vault。记录所用入口、身份、操作前后版本或状态以及失败实得。

1. 在临时 Vault 改指南、选保留，检查后建立备份，再按 ID 恢复，核对实际文本与返回版本。
2. 不存在或损坏的测试备份返回失败，用户当前指南可读；关闭恢复项后原发现缓存不能执行它。
