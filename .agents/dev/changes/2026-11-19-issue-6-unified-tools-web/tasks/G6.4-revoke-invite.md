# G6.4 撤销邀请并断开它建立的会话

上级交付 **G6 桌面 Web 服务与邀请**。本片承接[规格 · 桌面分享当前工作台](../spec.md#桌面分享当前工作台)与[原 Issue E06、E07](../source.md)。[本组架构及对象归属](../design.md)

**可见结果与边界**　邀请撤销与服务启停分开。按邀请 ID 归属注销既有会话并关闭流；停服务及换 Vault 则结束整代会话。

**前置产物**　[G6.3 重取同一邀请并让两台设备分别加入](G6.3-repeatable-invite.md)

**已有代码入口**　[apps/engine/src/boot.ts](../../../../../apps/engine/src/boot.ts)、[packages/kernel/src/server/ingress.ts](../../../../../packages/kernel/src/server/ingress.ts)、[packages/workbench/src/gateway/GatewayModule.tsx](../../../../../packages/workbench/src/gateway/GatewayModule.tsx)。

## 验收

使用独立测试 Vault。记录所用入口、身份、操作前后版本或状态以及失败实得。

1. 保持服务运行，撤销邀请后第三个浏览器使用旧链接被拒；新发邀请可进入，旧值仍无效。通过旧邀请建立的两个会话立即断开，HTTP 与活动流均不能继续。独立有效邀请的会话和桌面、CLI、MCP 继续工作。
2. 对撤销和兑换并发，以撤销生效点判断新建会话；另测停服务、重启与切 Vault，旧邀请、旧请求和旧流均失效。

## 原型对照与确认范围

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「Web 服务、浏览器工作台」对照「桌面 Web 服务／撤销、已撤销、重新邀请；旧页失效」。待用户确认该场景的入口、状态反馈以及上述失败后能采取的动作。落地界面前按[原型确认记录](../prototype-review.md)核对具体版本和覆盖范围；演示未覆盖的细节单列待走查。

## Windows 桌面与浏览器验证

从本机构建的 Electron 打开「能力网关 → 服务端 → Web 分享」。本机模式启动前显示已停止，运行后显示端口。创建两份邀请，取回第一份得到相同链接。用 Microsoft Edge 157.0.4341.60 的三个独立浏览器上下文分别打开 A、A、B，建立会话后链接片段被清除。B 保存看板布局，A 的页面收到更新。撤销 A 前展示受影响的两个会话，撤销后两个页面均显示会话不可用，A 的旧链接不能再次登录。B 刷新后仍可读已保存布局，磁盘布局版本保持一致。停止服务后桌面清空邀请列表。本次端到端入口使用回环地址，跨设备局域网连接为单独的未测项。 [Playwright 用例](../../../../../tests/e2e/workflows/web-share.spec.ts)
