# G6.3 重取同一邀请并让两台设备分别加入

上级交付 **G6 桌面 Web 服务与邀请**。本片承接[规格 · 桌面分享当前工作台](../spec.md#桌面分享当前工作台)与[原 Issue E01、E02](../source.md)。[本组架构及对象归属](../design.md)

**可见结果与边界**　Web 服务拥有绑定 listener 与 Vault 代次的邀请及独立用户会话；有效邀请可反复建会话。

**前置产物**　[G6.1 桌面启停 Web 并看到可用地址](G6.1-web-listener.md)；[G6.2 打包工作台可在普通浏览器打开深链](G6.2-host-bootstrap.md)

**已有代码入口**　[apps/engine/src/boot.ts](../../../../../apps/engine/src/boot.ts)、[packages/kernel/src/server/ingress.ts](../../../../../packages/kernel/src/server/ingress.ts)、[packages/workbench/src/gateway/GatewayModule.tsx](../../../../../packages/workbench/src/gateway/GatewayModule.tsx)。

## 验收

使用独立测试 Vault。记录所用入口、身份、操作前后版本或状态以及失败实得。

1. 两次重取当前地址并分别在两个干净浏览器打开，均进入同一测试 Vault，各有独立会话；清理浏览器地址中邀请值。
2. 无效邀请、过期服务代次或错 Vault 的同源引导均失败；静态包不包含桌面 token，日志不记录有效邀请。
