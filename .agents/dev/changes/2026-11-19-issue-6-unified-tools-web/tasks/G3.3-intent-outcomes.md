## 验收

使用独立测试 Vault。记录所用入口、身份、操作前后版本或状态以及失败实得。

1. 对合成创建保持同 key 重发，查询到同一 operationId、一次写入；不同用户或 Vault 不共享重试结果。
2. 同 key 改输入须报冲突；完成后模拟响应丢失或输出不符合 schema，通过句柄对账，未证实时显示 unknown，无二次创建。
