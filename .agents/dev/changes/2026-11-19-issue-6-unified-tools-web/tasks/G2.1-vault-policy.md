# G2.1 干净安装零开放，重启可读回用户选择

上级交付 **G2 策略和实际调用判定**。本片承接[规格 · 同一批选择怎样生效](../spec.md#同一批选择怎样生效)与[原 Issue A02、A05、B04](../source.md)。[本组架构及对象归属](../design.md)

**可见结果与边界**　每个 Vault 独享选择与版本，初始化、已明确关闭和后来新增的未配置可以区分，损坏单独报错。

**前置产物**　[G1.2 插件停用后仍能查看工具说明](G1.2-inactive-catalog.md)

**已有代码入口**　[packages/kernel/src/exposure.ts](../../../../../packages/kernel/src/exposure.ts)、[packages/kernel/src/capabilities/system.ts](../../../../../packages/kernel/src/capabilities/system.ts)、[packages/vault/src/write.ts](../../../../../packages/vault/src/write.ts)。

## 验收

使用独立测试 Vault。记录所用入口、身份、操作前后版本或状态以及失败实得。

1. 在空测试 Vault 启用插件，外部可用工具为零；明确开启一项后重启，只恢复该项。新增工具显示未配置，另一个 Vault 仍为零。
2. 用损坏的合成策略文件重开，显示错误并拒绝依赖该策略的外部调用；原文件保留，不当作首次初始化。
