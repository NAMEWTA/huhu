## 验收

使用独立测试 Vault。记录所用入口、身份、操作前后版本或状态以及失败实得。

1. 用含 high/read 与 normal/write 的夹具比较添加只读、仅保留常规只读、插件全部、启停匹配集及全目录；提交后逐项核对差集。
2. 预览后另一端改策略或目录删项，保留草稿、展示差异并可重算；取消预览不写入，不隐式启用插件。
