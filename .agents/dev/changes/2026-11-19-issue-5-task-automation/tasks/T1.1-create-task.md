# T1.1 创建并重开 Human 或 Agent 任务

任务可先保存再配目标；重开仍有原正文、类型、配置和引用，单纯保存不会启动进程。

归属 T1，对应 [Issue #5 验收矩阵](../source.md) A01、A02、A04、E01。[行为规格 · 用户可以做什么](../spec.md#用户可以做什么) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　无。复用 Tasks 的 Markdown、两类型三状态和现有写权限。
- **职责与边界**　Tasks 拥有 taskId、目标、模型、参数、资料引用；默认 Human，Agent 默认 new，existing 必须明确选择。
- **现有代码入口**　[tasks/ui/TaskEditor.tsx](../../../../../plugins/tasks/src/ui/TaskEditor.tsx) · [tasks/ui/TaskDetail.tsx](../../../../../plugins/tasks/src/ui/TaskDetail.tsx) · [tasks/ui/TaskViews.tsx](../../../../../plugins/tasks/src/ui/TaskViews.tsx) · [kinds/task.ts](../../../../../packages/contracts/src/kinds/task.ts) · [tasks/engine/service.ts](../../../../../plugins/tasks/src/engine/service.ts) · [tasks/engine/index.ts](../../../../../plugins/tasks/src/engine/index.ts) · [markdown/regions.ts](../../../../../packages/vault/src/markdown/regions.ts)。
- **原型走查**　[任务列表 → 新建、编辑、保存与目标](../prototype/index.html#editor)。确认类型、配置不足提示及看板。该界面范围待用户按版本确认，实施前核对[原型确认记录](../prototype-review.md)中的资源指纹、场景与实际确认范围；未演示的分支单列。

## 验收与取证

1. 人工建 Human，再建缺部分配置的 Agent，添加路径引用并重开，核对三列看板、完成删除线、原始区段外字节和零次 CLI。
2. 无执行授权的外部来源不能通过创建请求或评论触发派遣；模拟外部改原文件，条件写保留原内容并返回冲突。

在仓库根用 `pnpm exec vitest run` 加下方对应的 `.test.ts` 路径执行领域回归，再按上面的实际入口补齐行为证据。 [plugins/tasks/test/service.test.ts](../../../../../plugins/tasks/test/service.test.ts) · [plugins/tasks/test/shared.test.ts](../../../../../plugins/tasks/test/shared.test.ts)
