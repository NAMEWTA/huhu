# T3.1 在原任务识别问题并处理原生暂停

运行概要显示问题数，详情列出可答的真实请求。用户能分辨业务问题、原生暂停、只能前往现场和已处理问题。

归属 T3，对应 [Issue #5 验收矩阵](../source.md) A03、A05、C03、C04、E02。[行为规格 · 用户可以做什么](../spec.md#用户可以做什么) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　[T1.2](T1.2-accept.md) 的任务轮次和 [W6.0](../../2026-11-19-issue-4-agent-cli/tasks/W6.0-receipt-contract.md) 的固定问题回执样例。用样例驱动 Tasks 展示和请求状态转换。
- **职责与边界**　Tasks 维护 requestId/version、run/session 绑定及状态。普通问题允许该轮结束；原生 deferred 保留原轮，只有 blocked 信号时按能力提供现场入口。
- **现有代码入口**　[dto/task.ts](../../../../../packages/contracts/src/dto/task.ts) · [kinds/task-run.ts](../../../../../packages/contracts/src/kinds/task-run.ts) · [tasks/ui/TaskDetail.tsx](../../../../../plugins/tasks/src/ui/TaskDetail.tsx) · [automations/ui/RunsPanel.tsx](../../../../../plugins/automations/src/ui/RunsPanel.tsx) · [agent-cli/engine/waiting.ts](../../../../../plugins/agent-cli/src/engine/waiting.ts)。
- **原型走查**　[原任务 → 待回答卡、原生请求、前往现场](../prototype/index.html#event-mode)。在独立后台选择普通问题、原生暂停及只能现场处理。确认仅有效问题可答。该界面范围待用户按版本确认，实施前核对[原型确认记录](../prototype-review.md)中的资源指纹、场景与实际确认范围；未演示的分支单列。

## 验收与取证

1. 向原任务投入普通问题与可验证原生请求，核对 questionCount、Question[]、原问题、已解决状态和待答入口；独立终端保留已有等待任务兜底。
2. 重复回执、过期或跨 run 的请求不能新增可答卡；已绑定任务收到多次 blocked 时不得另生 Human 任务。

在仓库根用 `pnpm exec vitest run` 加下方对应的 `.test.ts` 路径执行领域回归，再按上面的实际入口补齐行为证据。 [plugins/tasks/test/service.test.ts](../../../../../plugins/tasks/test/service.test.ts) · [plugins/automations/test/service.test.ts](../../../../../plugins/automations/test/service.test.ts)
