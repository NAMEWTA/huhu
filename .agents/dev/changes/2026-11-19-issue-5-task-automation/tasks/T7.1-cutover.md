## 验收与取证

1. 查找旧符号并逐消费者复核。以干净安装验证 MCP/CLI 工具默认全关，受信内部回执正常；按明确授权启用指定工具后完成查询/操作，再撤权复测。 撤销局域网邀请后，通过该邀请的页面失去后续操作权限，其他已独立授权的会话与执行回执保留。
2. 新格式备份到全新测试 Vault，还原用户任务、规则与约定可恢复记录；运行按所属机器重查，秘密依模块备份范围补配。损坏包失败，无自动重启 CLI 或跨 Vault 补送。

## Agent 规则已接入 Tasks 的发生记录

生产的规则预览、手工立即运行和定时触发使用同一发生记录服务。激活历史显示由 Tasks 受理和跳过的数量，旧记录保留查询。Windows Engine 的 HTTP 测试对同一立即运行键重交，仍只有一个发生和一个 Tasks 派遣。预览没有写入发生记录，目标不可用时没有创建替代会话或旧 Task Runs 文件。现有终端规则、旧运行恢复和消费者各自还有后续切换工作。 [Engine HTTP 用例](../../../../../apps/engine/test/engine.test.ts)
