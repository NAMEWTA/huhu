# T6.3b 运行带模块配置的终端规则

终端规则在所选目录调用统一 Agent CLI，能显示同一启动的凭据和脱敏的配置状态。

归属 T6，对应 [Issue #5 验收矩阵](../source.md) B06、D08、E07。[行为规格 · 并发与失败的外部语义](../spec.md#并发与失败的外部语义) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　[T5.3](T5.3-scan-occurrence.md) 的发生记录、#4 [W1.2](../../2026-11-19-issue-4-agent-cli/tasks/W1.2-launch-reconcile.md) 的启动对账和 [W7.3](../../2026-11-19-issue-4-agent-cli/tasks/W7.3-agent-settings.md)/#9 的秘密注入合同。
- **职责与边界**　runTerminalAction 用原 requestId 对账。规则专用秘密由 Automations 管，可复用启动环境由 Agent CLI 管，密钥与密文分别保管。
- **现有代码入口**　[automations/engine/service.ts](../../../../../plugins/automations/src/engine/service.ts) · [automations/ui/RuleEditor.tsx](../../../../../plugins/automations/src/ui/RuleEditor.tsx) · [agent-cli/engine/sessions.ts](../../../../../plugins/agent-cli/src/engine/sessions.ts) · [kinds/automation.ts](../../../../../packages/contracts/src/kinds/automation.ts)。
- **原型走查**　[规则编辑 → 终端命令、环境已配置、重查启动](../prototype/index.html#editor)。原型不使用真实命令或秘密，模块设置与清理的实机证据另取。确认遮蔽与失效配置反馈。该界面范围待用户按版本确认，实施前核对[原型确认记录](../prototype-review.md)中的资源指纹、场景与实际确认范围；未演示的分支单列。

## 验收与取证

1. 在 Safe 未初始化、锁定、停用时创建或更新含测试值的规则，分别用授权的 UI/MCP/CLI 操作，验证实际进程收到配置、结束后执行端清理。
2. 断在 terminal.run 成功但未记确认，原动作仅对账。配置轮换/删除时标补配，检查普通查询、任务、日志、Git、导出与重启记录均无测试值。

在仓库根用 `pnpm exec vitest run` 加下方对应的 `.test.ts` 路径执行领域回归，再按上面的实际入口补齐行为证据。 [plugins/automations/test/service.test.ts](../../../../../plugins/automations/test/service.test.ts) · [plugins/tasks/test/service.test.ts](../../../../../plugins/tasks/test/service.test.ts)
