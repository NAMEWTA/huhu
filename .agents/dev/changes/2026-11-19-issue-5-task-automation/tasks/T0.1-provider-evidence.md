# T0.1 核实每个 provider 能走通的任务路径

接手者可以据实选择能走通问答闭环的 provider，也能解释其他目标为什么只能前往现场。

归属 T0，对应 [Issue #5 验收矩阵](../source.md) C01、C04、E05、E06。[行为规格 · 用户可以做什么](../spec.md#用户可以做什么) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　无。可直接检查当批上游检出、实际包与本机 provider，并记录 Core 标识。
- **职责与边界**　针对 Claude、Codex、Pi 逐项核 new/existing/resume、结构化问题/结果、回复、取消及原生绑定；记录许可、入口、输入与证据。
- **现有代码入口**　[agent-autoloop/worker/agents.ts](../../../../../temp/sources/agent-autoloop/worker/agents.ts) · [agent-autoloop/kernel/decide.ts](../../../../../temp/sources/agent-autoloop/kernel/decide.ts) · [agent-autoloop/kernel/query.ts](../../../../../temp/sources/agent-autoloop/kernel/query.ts) · [agent-cli/engine/launch.ts](../../../../../plugins/agent-cli/src/engine/launch.ts) · [agent-cli/engine/sessions.ts](../../../../../plugins/agent-cli/src/engine/sessions.ts) · [automations/engine/worker.ts](../../../../../plugins/automations/src/engine/worker.ts)。
- **原型走查**　[选择执行目标 → 能力或不可用原因](../prototype/index.html#editor)。模拟选项不能证明 provider 能力。仅作能力展示对照。本片的协议或来源核验可先执行。涉及状态呈现时按同一版本的[确认记录](../prototype-review.md)核对。

## 验收与取证

1. 在隔离工作区给每个可取得的 CLI 提交一个无害测试任务，观察原生 ID、结构化问题/结果、可恢复性；为可完整回合的路径留下实际记录。
2. 仅报告 blocked、版本不支持或无法取得二进制时标现场处理/未验证，按源码映射到 Huhu 接收点，不推定全支持。

记录当批本地提交、实机 OS、包/CLI 版本和复现操作，分别标明静态核对与实测结果。 [plugins/agent-cli/test/agent.test.ts](../../../../../plugins/agent-cli/test/agent.test.ts) · [tests/e2e/packaged](../../../../../tests/e2e/packaged)
