# T5.5 编辑启用规则并预览后续日程

用户在原规则编辑器更改频率、时区或说明，可看到保存影响及后续触发时刻。

归属 T5，对应 [Issue #5 验收矩阵](../source.md) A08、B01、B03、B09。[行为规格 · 何时自动派遣](../spec.md#何时自动派遣) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　既有规则可读写；时间预览采用 [T4.2](T4.2-window-preview.md) 的规则时区。启用规则保存后的启停行为待设计末节决定，仅影响提交状态与提示。
- **职责与边界**　已发生或已接受的任务保持原规则快照。停用/删除只影响未来且保留待派项的决定见 [T5.2](T5.2-manage-rule.md)。
- **现有代码入口**　[ui/RuleEditor.tsx](../../../../../plugins/automations/src/ui/RuleEditor.tsx) · [engine/scheduler.ts](../../../../../plugins/automations/src/engine/scheduler.ts) · [ui/cron-presets.ts](../../../../../plugins/automations/src/ui/cron-presets.ts) · [engine/service.ts](../../../../../plugins/automations/src/engine/service.ts)。
- **原型走查**　[规则编辑 → 保存启用规则、触发预览、取消](../prototype/index.html#editor)。两种候选由用户决定，模拟稿的预设不等于确认。对应体验待用户按[原型确认记录](../prototype-review.md)的指纹和范围确认。

## 验收与取证

1. 编辑一条启用规则，核对可视化的后续时间与 Engine 计算的时刻；按用户最终确认的「保持启用」或「保存即暂停」方案验证开关、提示和真实调度。
2. 取消编辑或提交的版本已冲突，既有规则及已接受的发生保持。缺配置/时区无效需显示字段原因，不能写入半份新配置。

在仓库根用 `pnpm exec vitest run` 加下方对应的 `.test.ts` 路径执行领域回归，再按上面的实际入口补齐行为证据。 [plugins/automations/test/service.test.ts](../../../../../plugins/automations/test/service.test.ts) · [plugins/automations/test/scheduler.test.ts](../../../../../plugins/automations/test/scheduler.test.ts)
