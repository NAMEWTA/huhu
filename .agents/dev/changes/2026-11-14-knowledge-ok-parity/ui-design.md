# 界面设计记录（知识库：OK 式编辑器、文件树、评论、档案标签、查看器）

> 方法：`dev-ui-design`——沿用 Huhu 现行设计系统与 OK 的交互，不重新设计视觉；**界面保真优先用上游实现，样式通过 token 映射接入**（[decisions.md](decisions.md) OP-D05）。架构见 [design.md](design.md)，行为契约见 [spec.md](spec.md)。本文记录**布局 / 状态 / 键盘 / 响应式**的约定与验收入口；截图证据在实施时存入 `evidence/ui/`，此处不预填“已通过”。

## 1. 任务与证据

- **用户任务**：在知识库里浏览全部文件、写作（选择 / `/` / 属性 / 评论）、打开 JSON / TXT / PDF / HTML、进入档案视图再切回文件。入口：左侧“知识库”模块；顶部分区；命令面板；`@`。完成信号：磁盘文件与 UI 一致，重开后保持（issue §15.3）。
- **现有代码位置**：`plugins/notes/src/ui/{NotesModule,NoteDocument,NoteExplorer,NoteInspector,CommentsPanel,FileCard}.tsx`、`ui/archives/`、`notes.css`；设计系统 `packages/ui/src/styles/{index,tokens,base}.css`、`components/*.css`；规范 `.agents/dev/notes/context/design-system.md`；视觉验证 `pnpm visual:*` + `tests/visual/`。
- **已确认约束**：四套主题 × 明暗、compact 密度、reduced-motion 都要成立；类名前缀（`hu-` / `shell-` / `notes-` / `editor-`）约束 Huhu 自有代码，vendor 与 `ok-utilities` 层按 OP-D05 / D15 处理；不新增全局无层覆盖与 `!important`；颜色只走 token（`check-ui-colors` 对适配层生效）。
- **会影响方向的假设**：OK 的视觉（Tailwind + shadcn 语言）与 Huhu 现有组件语言不完全一致——**默认策略：编辑器区域（正文、气泡菜单、slash 菜单、块手柄、表格控件、属性面板、评论）保持 OK 的版式与交互，颜色 / 圆角 / 阴影 / 字体通过 token 映射成 Huhu 的；外壳（标签条、顶部分区、侧栏框架、对话框、菜单容器）保持 Huhu 现有组件**。映射后的差异在 S2 / S3 用对照截图审（`evidence/ui/ok-vs-huhu/`），有争议的项交用户决定，不自行取舍视觉。

## 2. 布局约定

```text
┌ 顶部分区：文件 | 星标 | 日记 | 标签 | 回收站 | 档案 ─────────────────────────────────────┐
├ 侧栏（上下文：files | archives）  ┬ 标签条：[file][file][archives-home][archive-record] … ┤
│  ResourceTree（OK 文件树）        │ 文档工具栏（单行，按容器宽度收纳）                     │
│  或 档案树                        ├ 属性区（可折叠，frontmatter）                          │
│  计数：文件 N · 目录 M（可见/总数）│ 正文（OK 富文本 / 源码 / 阅读）                       │
│                                   │ ───────────────────────────────  评论栏 / 详情栏（可开关）│
└───────────────────────────────────┴──────────────────────────────────────────────────────┘
```

- **顶部分区顺序固定**：文件 / 星标 / 日记 / 标签 / 回收站 / 档案（“档案”最右）；档案入口激活唯一的 `archives-home` 标签（已存在则聚焦）。
- **工具栏**：一行；`[面包屑 / 标题] [保存状态] ←弹性中间区→ [视图切换] [主要编辑命令组] [更多 ⋯]`；中间区 `flex:1; min-width:0`；用 `ResizeObserver` 取**真实容器宽度**，按优先级把低频动作收进“更多”（优先级：保存状态 / 视图切换 / 撤销重做 > 标题与加粗 / 链接 / 列表 > 表格 / 引用 / 代码 > 其余）；需要换行时连续排布，**不人为保留一排空白**；收纳后键盘仍可达（“更多”是 menu button，方向键 / Esc / 焦点归还）；长中文标题单行省略，tooltip 给全名。
- **属性区**：正文之前、工具栏之下，默认展开若有 frontmatter；折叠状态每 Vault 记忆（`huhu.ok.properties-collapsed`）；无 frontmatter 时显示“添加属性”入口；文件元信息（路径 / 大小 / 修改时间）在详情抽屉，与用户 YAML 分组。
- **评论 / 详情**：右侧栏开关；窄窗口（< 1100 px）二选一并保证正文最小宽度（≥ 480 px）；评论边距轨随正文滚动。
- **窗口**：以 1440×900 为基准；还要覆盖 1024 / 800 / 480 宽（compact）与 125% / 150% / 200% 缩放（F07）。

## 4. 设计决定

- **复用**：外壳用 Huhu 现有组件（标签条、对话框、菜单容器、Toast、`DataTable` 等）；编辑器区域用 OK 的组件，经 token 映射与 `ok-utilities` 层接入；`FileIcon`、扩展名表为新的共享件（`packages/ui`）。
- **新增项与理由**：`DocTab` 标签条（统一文件 / 档案视图）、隐藏管理面板（issue 要求可恢复）、HTML 预览工具条（拦截计数与源码切换）、PDF 状态存储——都是 issue 明确要求或安全 / 状态必需，不加装饰。
- **视觉方向**：产品 UI（非营销页）；标题字重沿用现有设计系统的一个约定；不引入新字体 / 新配色；OK 的颜色变量不整体搬入。
- **token / 样式落点**：`packages/editor/src/ok/ok-globals.css` 与 `ok/token-map.css`（`ok-theme / ok-utilities` 层）；`editor.css`（modules 层，`editor-` 前缀）；`plugins/notes/src/ui/notes.css`（`notes-` 前缀）；共享部分进 `packages/ui/src/styles/components/*.css`。支持四套主题 × 明暗 / compact / reduced-motion。
