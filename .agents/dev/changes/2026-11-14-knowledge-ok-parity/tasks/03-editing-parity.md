# 03 编辑行为对等、属性区与工具栏（S3）

规格：B01–B08、C01–C05、F07；设计：[design.md](../design.md) §3.3 / §10；界面：[ui-design.md](../ui-design.md) §2–§3；决定：OP-D01 / D17。
交付：用户角度——OK 的 `/` 命令、浮动工具栏、块操作、表格、剪贴板、选区 / 上下行、输入法、撤销、模式切换在 Huhu 里与 OK 行为一致；正文顶部有可折叠的 YAML 属性区，与详情面板同数据；顶部工具栏按真实容器宽度收纳。
依赖：S2b。
边界：写 `packages/editor/src/{rich,host}` 与 vendor 编辑器补丁（`P-S3-xx`）、`plugins/notes/src/ui/documents/{ToolbarLayout,PropertyHost}.tsx`；不写评论（S4）、文件树（S5）。

## 实施要点

3.1 以 `parity-matrix.md` 为清单逐项核对：每一项“直接复制”的确认上游测试在 `test:vendor` 通过；“宿主适配”的项写适配与测试；不适用项保持登记，**缺项是待完成项**。slash 的 `component-items` / `embed-starter-items` 中依赖 OK 工作区 API 的项接 Huhu 能力或在 `OkHost.features` 关闭并登记（不留空按钮）。
3.2 选区 / 上下行 / IME：不另写光标推算；只处理宿主层面的问题——父组件重渲染不重建编辑器、`setContent` 只在三种场景出现、异步结果带 `epoch`、焦点与全局快捷键只由活动视图处理。
3.3 属性区：OK 属性面板接入 `PropertyHost`；按 SP-5 结论统一 YAML 编解码；坏 YAML 诊断与源码修复入口；文件元信息分组到详情。
3.4 工具栏：`ToolbarLayout`（`ResizeObserver` + 优先级收纳 + “更多”菜单），长中文标题省略，侧栏 / 评论 / 详情展开组合下保持单行合理排布。
3.5 对照：同一份样本文档、同一操作序列，在固定 OK 基线（本地运行 `temp/sources/open-knowledge`）与 Huhu 各录一遍，差异逐项登记到 `evidence/parity/`。

## 验收

- [ ] B01：复刻矩阵每项有“源码 → Huhu 实现 → 测试”，无“已有 Tiptap”式概括。
- [ ] B02：标题 / 行内格式 / 嵌套列表与任务列表 / 引用 / 代码 / 链接与双链 / 图片 / 表格 / 数学 / 图表与组件 / 脚注，在编辑 / 阅读 / 重开后语义一致（e2e + 黄金样本）。
- [ ] B03 / B04：`/` 分类、过滤、别名、预览、方向键、Enter / Tab、Esc、鼠标、无结果与定位对照 OK 基线通过；中文组合输入与全角触发字符按上游规则；代码 / URL / 表格上下文不误触发（模拟组合事件的回归；真机列未验证）。
- [ ] B05：一次撤销撤回一个命令事务；撤销 / 重做不被误禁用；没有第二套历史。
- [ ] B06 / B07：真实 Electron 中鼠标正向 / 反向跨段选区、Shift 选择、上下行、长文滚动、块与表格边界无跳失或错误替换；列表回车 / 退格 / 缩进、代码块出入、表格 Tab / Enter、块移动、复制 / 剪切 / 粘贴 / 拖放通过回归。**用户报告问题在 S0 的复现步骤上不再出现**；若仍出现，B06 保持开放并单独定位。
- [ ] B08：自动保存、评论刷新、属性变更、父组件渲染不重建活动编辑器、不打断输入法、不抢焦点（断言编辑器实例标识不变、焦点元素不变）。
- [ ] C01–C05：有 YAML 的 Markdown 顶部显示属性且与详情一致；`false / 0 / 空 / null / 前导零 / 数组 / 嵌套 / 日期类文本 / 未知键 / 注释` 黄金样本；只改正文保留 frontmatter 原文，只改属性不丢其它；正文有未保存修改时改属性（及相反顺序）都落同一文件；坏 YAML 诊断 + 修复入口，不清空。
- [ ] F07：1440 / 1024 / 800 / 480 宽与 125–200% 缩放、长中文标题、多标签、侧栏 / 评论 / 详情展开下，工具栏合理收纳、无大片闲置。
