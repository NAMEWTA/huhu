## 验收

- [ ] 演示： 两个上游提供相同 URI 和提示名，单个 Huhu 连接分别得到正确内容；模板展开后仍路由原来源。证据： A5/A6 的往返与权限测试。
- [ ] A5 资源/模板/提示 · 两个上游给相同 URI/提示名仍可分别访问；精确资源优先，多个模板匹配明确失败。测试多变量、查询表达式、百分号、中文及 URI 往返；结构化工具/提示/资源内容中的 URI 与当前来源一致。现有 Huhu 资源/提示和操作回执继续可用。
- [ ] A6 发现与调用授权一致 · 新工具/资源/模板/提示默认关闭。开放后可用；撤权后用缓存名字/URI/get 参数调用，上游计数不增加。查询策略失败不能放行。开放管理能力不隐式开放来源工具，开放一个工具不变成任意上游调用权限。关闭 MCP 服务后入口不可调用但配置/导入/显式短期检查仍可用；真正停用管理插件后其管理 handler 不可调用，通用插件入口可以重新启用控制面而不自动发布。已授权的远程 mcp.policy.update 可以按授权管理外部发布范围。
