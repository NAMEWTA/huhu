# F29 · 统一 Cron 和 FollowUps 的计划目录

[#13 原单](https://github.com/NAMEWTA/huhu/issues/13) · [本次完整快照](../../../../../temp/dev/2026-11-24-issue-inventory/integration/20261124T094741Z/13.md) · W5a / F29 / P2 · [批次规格](../spec.md)

## 交付

建立同一份可枚举计划目录，以稳定 ID/revision 管理所有来源、时间类型和状态；一次性跟进复用现有冻结输入、归属及回执，不额外复制一条 Cron 规则。当前改期会生成新 followUpId，它属于发生/幂等身份，不能冒充跨编辑稳定的 planId；中心统一计划身份与原发生身份分别维护。所有计划都能从中心编辑、启停和删除，来源入口写同一份配置；启停/删除同样做版本冲突校验、事件失效与跨客户端同步。模板创建/恢复必须是明确动作，用户删过的计划不因重启重新出现；历史可追溯，但不能以保留历史为由禁止删除未来计划。 本票提供 Engine 同一目录与 Cron/FollowUps 贯穿；其余来源逐个消费，中心 UI 在 AW 系列验收。

现有入口为 [plugins/automations/src/engine/index.ts](../../../../../plugins/automations/src/engine/index.ts)。
