[#12 原单](https://github.com/NAMEWTA/huhu/issues/12) · [本次完整快照](../../../../../temp/dev/2026-11-24-issue-inventory/integration/20261124T094741Z/12.md) · §8 P6；§9 · [批次规格](../spec.md)

## 交付

生成并实际使用单条配置；适配至少一个现有交互式 provider 的显式接入与清理。

保留受控派遣默认关闭，任务授权开启时精确限制能力；配置变化不能绕过 provider 指纹与任务边界。

用标准 MCP 客户端跑 CI，验证独立入站令牌、固定 HTTP 地址/隧道、重启重连与令牌撤销；补可复制配置和步骤文档。

现有入口为 [packages/kernel/src/mcp.ts](../../../../../packages/kernel/src/mcp.ts)。

## 验收

- [ ] 演示： 真实交互式 Agent CLI 和真实 CI 各通过一个 Huhu 条目完成内置和外部调用；另由正常 Task 入口派遣真实已配置的 provider，在一次明确的任务授权下实际调用选定工具，检查工具目标的独立结果/调用计数和 Task/Run 证据。使用相同名字的另一来源、另一任务、过期或撤销的授权均不能到达目标。证据： A10；没有异机环境须记录缺项，不提前关闭 Issue。
- [ ] AT-A07 · 受控 Codex 真实模型修改授权工作区、运行命令、调内置和外部工具 → 实际产物和工具效果可核对；不靠 fixture/交互终端替代；未授权目标/撤销拒绝
- [ ] A10 实际接入 · 至少一个真实 Agent CLI provider 和一次真实 CI 各调用内置+外部工具；HTTP 固定地址跨 Engine 重启有效。CI token 撤销即时失效。无任务授权的受控派遣仍无 MCP；由同一 Task/Run 的真实 native provider 执行一次明确获准工具并独立核验效果；越权、已撤权及已结束执行不发到目标。记录生产适配器、配置上下文、执行关联 ID 和脱敏效果。受控夹具只用于可重复故障/协议回归。异机测试记录机器/通道，不能用同机代替。
