## 交付

接入静态 header/token、明确环境引用和模块凭据状态；无钥匙串时保留无凭据/环境方式。

将 P2 的含秘密导入预览接到模块凭据安全转存与一致配置提交，覆盖取消、版本冲突、秘密保存成功但配置发布失败的清理/重试；完成带认证来源的完整导入与脱敏导出。

使用 SDK OAuth，跑通登录、取消、过期、刷新、重授权与目标变化；并发刷新合并，回调绑定配置代次。

配置导出/备份不泄露秘密，多个账号连接互不借用认证；凭据轮换清理旧连接。

现有入口为 [packages/kernel/src/mcp.ts](../../../../../packages/kernel/src/mcp.ts)。
