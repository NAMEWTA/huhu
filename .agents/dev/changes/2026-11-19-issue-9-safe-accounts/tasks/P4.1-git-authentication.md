# P4.1 向指定 Git HTTPS remote 配置与使用认证

所属交付 P4。本项承接 [Issue S3、C03、D03](../source.md)，行为规则见[模块认证责任](../spec.md#modules)，设计见[调用与失败处理](../design.md#operations)。

## 交付与依赖

Versioning 管理规范化协议、主机、端口、仓库的绑定。系统 Git 使用短命 ASKPASS，Git SSH URL 走系统 SSH/agent。

**前置产物**　[P0.2](P0.2-credential-replacement.md)。

**代码入口**　[plugins/versioning/src/engine/sync.ts](../../../../../plugins/versioning/src/engine/sync.ts)、[plugins/versioning/src/ui/sync/SyncSettingsPage.tsx](../../../../../plugins/versioning/src/ui/sync/SyncSettingsPage.tsx)、[plugins/versioning/src/engine/index.ts](../../../../../plugins/versioning/src/engine/index.ts)。

## 原型与确认范围

[Safe 原型](../prototype/index.html)的待确认场景为「Git 同步设置 → 填写该 remote 的认证 → 保存/更换目标」。#9 原型核对凭据归属与独立配置提示。所属模块的完整表单、授权和连接体验由相关 change 的原型或实际入口补验。 [版本与用户确认范围](../prototype-review.md)

定位到[保险箱演示区域](../prototype/index.html#modal)，核对openOwner 的 Git 同步远端认证；模拟配置可见，真实 fetch/push 另验。

## 验收

- [ ] 用两个隔离测试 remote 和无价值凭据执行 fetch/push，在 Safe 未设置/锁定/停用各复核一个请求。普通配置仅显示就绪状态。
- [ ] 改任一绑定目标、取消或远端拒绝时旧认证不会发给新端点；检查 argv、config、helper、临时文件和错误输出没有合成秘密。

使用新建隔离 Vault 和无价值的合成字段，记录测试入口、平台、操作结果及脱敏标识。实际结果回填本任务。
