# P4.2 修复 Git 认证后恢复同步

所属交付 P4。本项承接 [Issue S3、C03、D01](../source.md)，行为规则见[模块认证责任](../spec.md#modules)，设计见[现有消费者](../design.md#current)。

## 交付与依赖

Versioning 按所属 remote 认证状态解释暂停/重试，移除对 safe.unlocked 事件的依赖。

**前置产物**　[P4.1](P4.1-git-authentication.md)。

**代码入口**　[plugins/versioning/src/engine/sync.ts](../../../../../plugins/versioning/src/engine/sync.ts)、[plugins/versioning/src/engine/auto-sync.ts](../../../../../plugins/versioning/src/engine/auto-sync.ts)、[plugins/versioning/src/engine/index.ts](../../../../../plugins/versioning/src/engine/index.ts)。

## 原型与确认范围

[Safe 原型](../prototype/index.html)的待确认场景为「Git 状态 → 认证失败暂停 → 修复 → 恢复」。#9 原型核对凭据归属与独立配置提示。所属模块的完整表单、授权和连接体验由相关 change 的原型或实际入口补验。 [版本与用户确认范围](../prototype-review.md)

定位到[保险箱演示区域](../prototype/index.html#main)，核对settingsPage 的 Git 同步配置状态；暂停及实际恢复另在 Versioning 验。

## 验收

- [ ] 令测试 remote 拒绝一次，回设置修复后以同一配置恢复同步，核对拉取/推送次数及状态。
- [ ] 在暂停时反复锁定/解锁 Safe，既不恢复也不重复发请求；只读或认证仍无效时保留真实原因。

使用新建隔离 Vault 和无价值的合成字段，记录测试入口、平台、操作结果及脱敏标识。实际结果回填本任务。
