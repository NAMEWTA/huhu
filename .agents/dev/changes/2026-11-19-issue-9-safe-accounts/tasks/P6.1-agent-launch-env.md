## 原型与确认范围

[Safe 原型](../prototype/index.html)的待确认场景为「Agent CLI 设置 → 启动/预览/取消」。#9 原型核对凭据归属与独立配置提示。所属模块的完整表单、授权和连接体验由相关 change 的原型或实际入口补验。 [版本与用户确认范围](../prototype-review.md)

定位到[保险箱演示区域](../prototype/index.html#modal)，核对openOwner 的 Agent CLI 启动环境；真正的进程、取消与崩溃从 #4 验。

## 验收

- [ ] 用已配置的模拟 CLI 原生登录及合成环境标记创建会话；目标程序仅返回匹配布尔值，预览与布局脱敏，重投 requestId 返回原运行。
- [ ] 在取消、崩溃、重启后核对实际 Core restart_env、运行文件和输出。保护通路不可用则明确拒绝该次受保护环境启动，无明文回退。

使用新建隔离 Vault 和无价值的合成字段，记录测试入口、平台、操作结果及脱敏标识。实际结果回填本任务。

## 本机配置验收

- Agent CLI 的启动环境按提供方和版本保存，普通变量随定义备份，受保护变量通过共享的本机保护服务保存并要求显式清空。工作台列表只显示普通配置及受保护变量名称和状态。环境变量名在便携定义中按不区分大小写校验重复。 [配置入口](../../../../../plugins/agent-cli/src/engine/launch-environment.ts)
- Windows 经真实 Engine、Credential Manager 和固定 pnpm 验证 Safe 未初始化、锁定及停用时的配置。合成保护值未出现在工作台响应和 ZIP，恢复后状态为待重新配置。受保护变量删除、旧版本冲突和 CLI/Web 权限均已验证。 [Engine 回归](../../../../../apps/engine/test/module-credential-host.test.ts)
- 启动的安全交接继续按本切片验收。固定 Core 的 `api/run.rs` 在派发给终端 holder 前将调用参数 `env` 写入 `restart_env` 并保存快照。启动配置交接需要独立于该持久化字段的单次领取。 [Core 源码与固定版本](https://github.com/herdrdev/herdr-core/blob/c7517808d64f06609e4ecf0db1757005373cc3a3/crates/herdr-core/src/api/run.rs)
