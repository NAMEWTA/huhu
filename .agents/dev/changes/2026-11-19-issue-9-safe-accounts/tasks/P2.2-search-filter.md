# P2.2 组合标签和搜索定位到账号

所属交付 P2。本项承接 [Issue S1/S2、A06、B01–B02](../source.md)，行为规则见[个人多账号操作](../spec.md#personal)，设计见[调用与失败处理](../design.md#operations)。

## 交付与依赖

Safe 仅在解锁内存内检索名称、网址、标签及账号非密码字段。「无标签」与选标签互斥，多选取交集，返回命中账号位置。

**前置产物**　[P1.2](P1.2-save-entry.md)、[P2.1](P2.1-manage-tags.md)。

**代码入口**　[plugins/safe/src/engine/safe.ts](../../../../../plugins/safe/src/engine/safe.ts)、[packages/workbench/src/engine-client/query.ts](../../../../../packages/workbench/src/engine-client/query.ts)、[packages/vault/src/index/vault-index.ts](../../../../../packages/vault/src/index/vault-index.ts)。

## 原型与确认范围

[Safe 原型](../prototype/index.html)的待确认场景为「搜索 → 多标签/无标签 → 选命中账号 → 锁定」。此项界面实施前，在记录中核对该场景对应的用户确认、版本及范围。尚未演示的状态须另列，模拟操作仅作体验依据。 [版本与用户确认范围](../prototype-review.md)

定位到[保险箱演示区域](../prototype/index.html#main)，核对safePage / filteredEntries 的列表筛选与命中账号。

## 验收

- [ ] 准备同名账号、两标签交集、无标签和只在密码中出现的词；查询邮箱/备注定位到正确账号，密码词零结果，清筛选恢复列表。
- [ ] 搜索过程中锁定或切 Vault，迟到响应不显示，清除旧查询和选中项；在全局搜索与持久索引中查无合成私有字段。

使用新建隔离 Vault 和无价值的合成字段，记录测试入口、平台、操作结果及脱敏标识。实际结果回填本任务。
