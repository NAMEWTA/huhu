## 原型与确认范围

[Safe 原型](../prototype/index.html)的待确认场景为「工具配置的 SSH 主机在工作台可见，信任/取消结果一致」。#9 原型核对凭据归属与独立配置提示。所属模块的完整表单、授权和连接体验由相关 change 的原型或实际入口补验。 [版本与用户确认范围](../prototype-review.md)

定位到[保险箱演示区域](../prototype/index.html#modal)，核对openOwner 的 SSH 归属提示；完整信任、挑战与 Exec 使用 #6/#7 场景。

## 验收

- [ ] 在隔离主机，用 CLI 建主机、MCP 跟进同一 attempt、应答并执行无副作用的测试命令；工作台显示相同身份与结果。
- [ ] 用户拒绝主机信任或取消挑战，操作结束且无会话遗留；关闭对应外部权限后拒绝新调用，内部已授权路径可用。

使用新建隔离 Vault 和无价值的合成字段，记录测试入口、平台、操作结果及脱敏标识。实际结果回填本任务。
