# P3.2 安全删除指定账号或整个条目

所属交付 P3。本项承接 [Issue S1/S2、A04、D03](../source.md)，行为规则见[个人多账号操作](../spec.md#personal)，设计见[Safe 新格式](../design.md#model)。

## 交付与依赖

Safe 的确认与 handler 共同区分移除非最后账号、删除整个条目及取消，保留共享标签目录和其他条目。

**前置产物**　[P1.2](P1.2-save-entry.md)。

**代码入口**　[plugins/safe/src/ui/SafeModule.tsx](../../../../../plugins/safe/src/ui/SafeModule.tsx)、[plugins/safe/src/engine/safe.ts](../../../../../plugins/safe/src/engine/safe.ts)、[packages/vault/src/write.ts](../../../../../packages/vault/src/write.ts)。

## 原型与确认范围

[Safe 原型](../prototype/index.html)的待确认场景为「详情 → 移除账号 → 仅剩一个 → 删除条目/取消」。此项界面实施前，在记录中核对该场景对应的用户确认、版本及范围。尚未演示的状态须另列，模拟操作仅作体验依据。 [版本与用户确认范围](../prototype-review.md)

定位到[保险箱演示区域](../prototype/index.html#modal)，核对renderDetail 的「删除账号」「删除条目」及最后一账号的二次选择。

## 验收

- [ ] 创建同名账号的两个合成站点，从一个站点移除指定 ID；最后一个账号触发整条删除确认并展示账号数，取消后仍在。
- [ ] 在确认期间另一端改条目后提交，返回版本冲突；模拟写失败重开原数据完整，另一站点和标签仍可用。

使用新建隔离 Vault 和无价值的合成字段，记录测试入口、平台、操作结果及脱敏标识。实际结果回填本任务。
