# P3.4 复制选中账号并反馈系统结果

所属交付 P3。本项承接 [Issue S2、A07、C06](../source.md)，行为规则见[个人多账号操作](../spec.md#personal)，设计见[两端宿主约束](../design.md#hosts)。

## 交付与依赖

Safe 仅在明确复制时取目标值，经宿主提供的剪贴板能力完成操作；不记值、不把遮罩当密码。

**前置产物**　[P3.3](P3.3-reveal-password.md) 的受控取值合同。

**代码入口**　[plugins/safe/src/ui/SafeModule.tsx](../../../../../plugins/safe/src/ui/SafeModule.tsx)、[packages/workbench/src/settings/host.ts](../../../../../packages/workbench/src/settings/host.ts)、[apps/desktop/src/preload/index.ts](../../../../../apps/desktop/src/preload/index.ts)、[packages/workbench/src/engine-client/query.ts](../../../../../packages/workbench/src/engine-client/query.ts)。

## 原型与确认范围

[Safe 原型](../prototype/index.html)的待确认场景为「账号详情 → 复制成功/拒绝/不可用」。此项界面实施前，在记录中核对该场景对应的用户确认、版本及范围。尚未演示的状态须另列，模拟操作仅作体验依据。 [版本与用户确认范围](../prototype-review.md)

定位到[保险箱演示区域](../prototype/index.html#main)，核对renderDetail 的「复制密码」及演示控制的「复制被拒绝」。

## 验收

- [ ] 在允许复制的桌面或测试浏览器复制第三个账号，粘贴到隔离输入框核对一次；持续遮罩，成功反馈只报告结果，随即清除测试内容。
- [ ] 模拟剪贴板拒绝或普通 LAN HTTP 不可用，显示具体失败和可选择显式显示的路径；锁定时不得执行迟到复制。

使用新建隔离 Vault 和无价值的合成字段，记录测试入口、平台、操作结果及脱敏标识。实际结果回填本任务。
