# P6.2 用规则自有认证派遣一次运行

所属交付 P6。本项承接 [Issue S3、C04、D03](../source.md)，行为规则见[模块认证责任](../spec.md#modules)，设计见[调用与失败处理](../design.md#operations)。

## 交付与依赖

Automations 管理规则/脚本变量，只按规则和执行 ID 在 Engine 解析，经唯一派遣链交给目标子进程；Agent CLI 保有运行身份。

**前置产物**　[P0.2](P0.2-credential-replacement.md)；[#4](../../2026-11-19-issue-4-agent-cli/plan.md)/[#5](../../2026-11-19-issue-5-task-automation/plan.md) 唯一执行链及 [P6.1](P6.1-agent-launch-env.md) 的安全交接合同。

**代码入口**　[plugins/automations/src/engine/service.ts](../../../../../plugins/automations/src/engine/service.ts)、[plugins/automations/src/engine/worker.ts](../../../../../plugins/automations/src/engine/worker.ts)、[packages/contracts/src/kinds/automation.ts](../../../../../packages/contracts/src/kinds/automation.ts)。

## 原型与确认范围

[Safe 原型](../prototype/index.html)的待确认场景为「自动化规则/脚本 → 配置环境 → 派遣 → 取消/恢复」。#9 原型核对凭据归属与独立配置提示。所属模块的完整表单、授权和连接体验由相关 change 的原型或实际入口补验。 [版本与用户确认范围](../prototype-review.md)

定位到[保险箱演示区域](../prototype/index.html#modal)，核对openOwner 的自动化环境；派遣与恢复需接 #4/#5 真实入口。

## 验收

- [ ] 用合成规则派遣两次相同 requestId，只有一个会话；进程核对变量，任务正文、评论、回执、Core 与 launch.json 不含值。
- [ ] 模拟后台执行取消、Core 崩溃或本机保护不可用；恢复意图可查且不会复制秘密至命令行或持久恢复环境。

使用新建隔离 Vault 和无价值的合成字段，记录测试入口、平台、操作结果及脱敏标识。实际结果回填本任务。
