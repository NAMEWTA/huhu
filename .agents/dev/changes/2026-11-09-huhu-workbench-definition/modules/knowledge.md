## 2. 界面

- **模块侧栏**（本模块的侧栏是文件资源管理器）：头部 Vault 名称 + 下拉（切换 Vault）；“文件资源管理器”标题行与按钮（新建笔记、新建文件夹、更多：排序方式 按修改时间/按文件名、显示隐藏文件）；搜索框；五个筛选按钮（文件、星标、日记、标签、回收站）；文件树（R-17）；底部“导入文件”与文件计数。日记筛选显示日期选择器与“打开今天的日记”。标签筛选显示标签列表（含计数）。回收站筛选显示已删除条目，每项可恢复或永久删除。
- **内容区**：文档标签条（R-16）；文档头：路径面包屑、模式分段控件（实时预览/源码/阅读/双栏）、星标、详情面板开关；工具栏：撤销、重做、标题、加粗、斜体、链接、双链、待办、引用、代码块、表格；右侧查找替换、批注、版本历史（跳到版本模块并选中此文件）、导出、更多（复制路径、在文件管理器中显示、复制、移动、重命名、移到回收站）。编辑区下方状态行：保存状态、字数、行数；右侧 文件类型、光标行列、编码、换行符、“保存版本”。
- **详情面板** 页签：属性、大纲、关联（反向链接、关联任务、关联档案）、批注。
- **空状态**：Vault 无文件 → “这个 Vault 还是空的” + “新建笔记”；无打开文档 → “选择一篇笔记，或从空白页开始”；筛选无结果 → “没有匹配文件” + “清除筛选”。

## 3. 文件操作

| 动作 | 成功结果 | 约束与失败 |
| --- | --- | --- |
| 新建笔记 | 对话框：文件名（无需 .md）、文件夹（可输入 `a/b` 建立嵌套）、模板；创建后在新标签打开并聚焦标题 | 同目录同名（大小写不敏感比较）→ 字段错误“这个文件夹中已有同名文件”；名称含 `/\:*?"<>\|` 或为保留名 → 字段错误 |
| 新建文件夹 | 空文件夹登记到 `.huhu/notes/folders.json`，树中保留 | 同名拒绝 |
| 重命名文件 | 只改文件名；id 不变；所有以路径或文件名明确指向它的双链在同一操作中更新；toast“文件名与双链已更新” | 目标存在拒绝；部分文件写失败 → `WRITE_PARTIAL`，健康中心列出 |
| 移动文件/文件夹 | 对话框选目标目录；文件夹移动带后代；路径双链更新 | 禁止移入自身或后代；目标存在同名拒绝（不合并） |
| 复制 | 新文件“<名> · 副本”，新 id；不复制批注与历史 | — |
| 移到回收站 | 树中消失；toast“已移到回收站” + 撤销；打开中的标签关闭（有未保存修改先走关闭流程） | — |
| 恢复 | 回到原路径；原路径有同名文件时对话框要求新文件名 | 不覆盖已有文件 |
| 永久删除 | AlertDialog“永久删除「名称」？” → 删除回收站条目与批注 | 指向它的双链保留为未解析 |
| 删除文件夹 | AlertDialog 列出将移到回收站的文件数；整体移入回收站 | — |
| 拖放 | 文件拖到文件夹 = 移动；外部文件拖入 = 导入复制 | 拖放无法识别的内容 → 提示使用菜单 |
| 导入文件 | 选择文件复制到当前文件夹；Markdown 直接成为笔记 | 同名时自动追加“ (1)” |
| 打开日记 | `notes.openDaily(date)`：`日记/YYYY-MM-DD · 每日笔记.md` 不存在则以每日模板创建 | — |

双链更新只修改 `[[...]]` 目标与标准 Markdown 链接 `](路径)`，不改代码块与行内代码中的文本；裸标题存在多个同名文件时不改写并在结果中列出。

## 4. 文件类型

| 类型 | 打开方式 |
| --- | --- |
| `.md` | MarkdownEditor 四种模式 |
| `.txt .json .yaml .yml .js .ts .tsx .css .html .py .rs .sh .toml` | CodeMirror 源码模式（按扩展名惰性加载语言），有查找替换、保存、历史；JSON/YAML 语法错误在底部显示诊断，不阻止保存 |
| `.mmd .mermaid` | 源码 + 下方 Mermaid 预览（预览错误指向行号，不影响源码） |
| `.png .jpg .jpeg .gif .webp .svg` | 只读图片预览（缩放、适应窗口）；SVG 经消毒后以 `<img>` 显示 |
| `.pdf` | Chromium 内置 PDF 查看器（`<iframe>` 加载 Engine 资源路由，sandbox） |
| 其他或 > 10 MiB 的文本 | 元信息卡片：类型、大小、修改时间、“在文件管理器中显示”“用系统应用打开” |

## 5. 编辑器

实现：`packages/editor/src/MarkdownEditor.tsx`（R-21、R-22）。每个打开的文档一个 `EditorView`，模式切换只重配扩展（`Compartment`），不重建视图。

| 模式 | 内容 |
| --- | --- |
| 实时预览 | CM6 + inline-preview：非光标行渲染标题、强调、链接、图片、任务复选框、双链；光标所在行显示原始语法。行号 gutter（设置“显示行号”关闭时隐藏）。 |
| 源码 | CM6 原文，Markdown 语法高亮，行号 |
| 阅读 | MarkdownPreview（R-20）渲染，只读；复选框不可点击 |
| 双栏 | 左源码右预览，可开关同步滚动；只有左侧接受输入 |

- 正文布局：编辑区内容 `max-width` 取设置“正文宽度”，水平居中；两侧最小留白 24px（窗口 < 1200px 时 12px）；行号 gutter 紧贴正文左侧，不贴窗口边缘。字号与行高取编辑器设置。
- 工具栏命令作用于当前选区，一次点击 = 一个撤销步骤；阅读模式下工具栏禁用并提示“切换到编辑模式”。
- 撤销历史属于 EditorState，切换模式保留。外部内容替换（重新载入磁盘、恢复版本）通过一个带 `addToHistory: false` 的事务应用，并清空撤销栈，状态行提示“已载入外部修改，撤销历史已重置”。
- 输入法：组合输入期间不切换模式、不重配扩展、不触发保存（原型 `huhu-composition.ts` 保护，R-21）。
- 查找替换：CM search 面板（`Mod+F`、`Mod+H`），支持大小写、整词、正则。
- 双链补全：输入 `[[` 弹出笔记名补全（按 R-19 打分），回车插入 `[[文件名]]`；同名文件时插入带路径的 `[[目录/文件名]]`。
- 点击链接：`[[...]]` 打开目标笔记（多个同名时弹出选择对话框）；`http(s)` 经 `openExternal`；其他协议拒绝并提示。

### 保存

| 设置 | 行为 |
| --- | --- |
| 自动保存（默认开） | 停止输入 800ms 后 `notes.save({id, source, expectedVersion})`；状态行“保存中…/已保存/保存失败（重试）” |
| 手动保存 | `Mod+S` 保存；每 2 秒写草稿 `notes.draft.save`；标签显示圆点 |

保存回执只确认该次提交的内容：保存进行中继续输入时，回执到达后文档仍为未保存状态并再次提交。

### 关闭有未保存修改的文档

对话框“关闭时如何处理”：保存修改并关闭 / 保留草稿并关闭 / 放弃修改并关闭 / 取消。保存失败时不关闭并显示错误。

### 外部修改

文件监听收到非自写的变化（R-07、R-08）：

- 文档无未保存修改 → 直接载入新内容，状态行提示。
- 有未保存修改 → 文档顶部 Banner“磁盘上的文件已被修改”，操作：查看差异（DiffView：磁盘 vs 本地）、保留我的版本（以新磁盘版本为 base 再保存）、使用磁盘版本、合并（R-23 三方合并，冲突块以标记插入，由用户编辑后保存）。处理前任何保存都会因 `VERSION_CONFLICT` 被拒。
- 文件被外部删除 → Banner“文件已被删除”，操作：另存为（重新创建）、关闭。

## 6. 属性、大纲、关联

- 属性页签：显示 frontmatter 字段表（键、值），可增删改；保存走 `notes.updateProperties`（局部改写 frontmatter，R-10），与正文编辑共用版本检查。内置展示：标题（首个 H1 或文件名）、写作状态（`status`：草稿/待回顾/已整理）、创建与修改时间、关联档案（只读，来自档案的 `noteIds`）。
- 大纲：从标题生成，点击跳转；无标题时提示“在笔记中添加 Markdown 标题即可生成大纲”。
- 关联：反向链接（来源笔记 + 上下文片段）；关联任务（`resources` 指向本笔记或其上级文件夹的任务）；关联档案。

## 7. 批注

- 选中正文 → 选区旁出现“批注”气泡（R-25）→ 输入框（显示引用片段）→ 保存创建 `Comments/` 文件；空内容不能保存；取消不创建文件。
- 批注在正文中以淡色下划线装饰；详情面板“批注”页签按位置列出，点击滚动并高亮；可回复、标记解决、重新打开、删除（AlertDialog，正文不变）。
- 文件级批注：批注页签“添加文件批注”，无锚点。属性批注：属性行右侧批注按钮，锚定到键名。
- 重定位（R-24）：文档保存后对未解决批注运行 `refind`；不唯一或找不到 → `orphaned`，批注仍可读，显示“原文已变化”与“重新选择位置”（用户选中新范围后更新锚点）。
- 移动/重命名文档：批注 `documentPath` 在同一操作中更新；文档进入回收站时批注随之移入。

## 8. 验收

| ID | Given | When | Then |
| --- | --- | --- | --- |
| ACC-KN-01 | 一篇含 CRLF 换行、BOM、GFM 表格和未知 HTML 块的笔记 | 打开，在四种模式间切换，不编辑，关闭 | 文件字节与 mtime 不变 |
| ACC-KN-02 | 实时预览模式，输入法正在组合中文 | 点击“源码” | 组合结束后才切换；已输入文字完整保留；撤销可撤回该段输入 |
| ACC-KN-03 | 自动保存开启 | 输入 A，保存请求进行中再输入 B | 最终磁盘内容含 A 和 B；状态行最终为“已保存” |
| ACC-KN-04 | 手动保存模式下有修改 | 关闭标签并选“保留草稿并关闭”，再次打开 | 出现“恢复草稿”；恢复后内容与关闭前一致；磁盘文件仍为旧内容 |
| ACC-KN-05 | 笔记有未保存修改 | 外部编辑器修改同一文件 | 出现 Banner；选择“合并”后两边改动都在，冲突处有标记；未选择前保存被拒绝 |
| ACC-KN-06 | 笔记 X 被 3 篇笔记用 `[[X]]` 链接，其中一篇在代码块中写了 `[[X]]` | 将 X 重命名为 Y | 两处正文链接变为 `[[Y]]`，代码块中的文本不变；Y 的反向链接列出这 2 篇来源笔记 |
| ACC-KN-07 | 回收站中的笔记原路径已有同名文件 | 恢复 | 要求输入新名称；原有文件不变 |
| ACC-KN-08 | 一条批注锚定在一个在全文出现两次的句子上 | 删除锚定处的那一句并保存 | 批注变为 orphaned，未贴到另一句 |
| ACC-KN-09 | 正文含 `<script>` 与 `javascript:` 链接 | 阅读模式 | 脚本不执行，链接不可导航 |
| ACC-KN-10 | 一个 50 MiB 的日志文件 | 在文件树中打开 | 显示元信息卡片，不尝试作为文本加载 |
| ACC-KN-11 | 日记筛选 | 点“打开今天的日记” | 不存在时以每日模板创建 `日记/<今天> · 每日笔记.md` 并打开；存在时直接打开 |
