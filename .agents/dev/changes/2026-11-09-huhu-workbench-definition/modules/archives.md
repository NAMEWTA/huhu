# 档案

插件：`archives`。原型依据：`knowledge.jsx`（`ArchivesView`、`ArchiveDetail`、`ArchiveTypes`、`ArchiveRelations`）。复用：R-56。数据：[data-model](../data-model.md) §5 archive-type / archive。

## 1. 用户故事

| ID | 故事 |
| --- | --- |
| US-AR-01 | 我用档案保存长期信息（项目、联系人、书籍、资产或自定义类型），每种类型有自己的字段。 |
| US-AR-02 | 我以表格或卡片查看全部档案或某一类型，按名称、简介、字段搜索。 |
| US-AR-03 | 我在档案详情中查看字段、简介、关联档案、关联笔记与关联任务。 |
| US-AR-04 | 我在两个档案间建立关系，两边都能看到对方。 |
| US-AR-05 | 我创建、编辑、删除档案类型；删除仍有档案的类型前先把档案迁移到另一类型。 |
| US-AR-06 | 我改变一个档案的类型，原有字段值不会丢失。 |
| US-AR-07 | 我从档案详情直接新建一个关联到该档案的任务。 |
| US-AR-08 | 我把当前视图的档案导出为文件。 |

## 2. 界面

- **模块侧栏**：标题“档案”+ 设置图标（类型与字段）；副标题“按类型组织长期资料”；“所有档案”与每个类型一项（图标、名称、计数）；底部“类型与字段 · n 种类型”。
- **页头**：当前类型名 + 主按钮“新建档案”。工具条：搜索 + 视图分段（表格/卡片）。
- **表格**：名称（图标 + 名称 + 简介一行）、类型、关联数、更新日期、行菜单（编辑、更改类型、删除）。< 1024px 隐藏“关联”列。**卡片**：三列网格，卡片显示名称、简介两行、前 3 个字段值。底部“n 个档案 · m 种类型”与“导出当前视图”（Markdown 表格文件，经 `saveFile`）。
- **详情面板**：名称、类型徽标、编辑/更多（更改类型、删除）；字段列表（未填写显示“未填写”；类型中不存在但档案中保留的字段显示在“未定义字段”分区）；简介；关联档案（chips + “编辑关系”）；关联笔记（列表 + “关联已有笔记”+ 解除关联）；关联任务（`resources` 指向本档案文件的任务，含完成圆框）+ “新建关联任务”。
- **类型与字段对话框**：类型列表；编辑类型：名称、图标（lucide 选择）、用途说明、字段表（标签、类型 文本/日期/链接/数字、上下移动、删除）。删除字段时提示“已有 n 个档案填写了该字段；字段值将保留为未定义字段”。

## 3. 行为

- 新建/编辑档案：对话框字段由类型定义生成；日期字段用 DateTimePicker 日期模式；链接字段校验 http(s)。名称必填。
- 关系编辑（`archives.setRelations`）：搜索档案多选；保存时在一个操作中同时更新双方文件的 `relatedIds`（data-model §7）。对方文件不存在 → 关系保留在本方并显示“已失效”。
- 关联笔记：从笔记列表选择（排除已关联）；写入本档案 `noteIds`。
- 更改类型：选择新类型；`type` 改变，`fields` 原样保留；界面按新类型显示，旧字段进入“未定义字段”。
- 删除档案：AlertDialog“删除「名称」？此操作不可撤销，关联的笔记与任务会保留。”；同一操作清除其他档案 `relatedIds` 中的该 id；任务的 `resources` 中指向它的条目保留并显示“已失效”。
- 删除类型：无档案 → 直接删除；有档案 → 对话框选择迁移目标类型后“迁移并删除类型”（一个操作）；没有其他类型时提示先创建。
- 新建关联任务：打开任务编辑对话框，`resources` 预填本档案文件，`project` 预填档案名称（项目类型时）。

## 4. 验收

| ID | Given | When | Then |
| --- | --- | --- | --- |
| ACC-AR-01 | 档案 A、B | 在 A 中把 B 加为关联 | A、B 两个文件的 `relatedIds` 都包含对方；在 B 详情可见 A |
| ACC-AR-02 | 类型“项目”有字段 owner，档案 X 填了 owner | 把 X 改为“书籍”类型 | X 文件中 `fields.owner` 仍在；详情“未定义字段”显示 owner |
| ACC-AR-03 | 类型 T 下有 2 个档案 | 删除 T | 必须选择迁移目标；完成后 2 个档案 `type` 为目标类型，T 文件被删除 |
| ACC-AR-04 | 档案 A 与 B 相关，任务 K 关联 A | 删除 A | A 文件消失；B 的 `relatedIds` 不含 A；K 的资源显示“已失效” |
| ACC-AR-05 | 用文本编辑器向档案文件 frontmatter 加一个未知键 `rating: 5` | 在 HUHU 中修改该档案名称 | `rating: 5` 与原注释、键顺序保留 |
| ACC-AR-06 | 档案详情 | 点“新建关联任务”并保存 | 新任务 `resources` 含该档案文件；档案详情“关联任务”列出它 |
