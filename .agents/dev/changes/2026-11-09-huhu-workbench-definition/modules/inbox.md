# 收件箱

插件：`inbox`。原型依据：`knowledge.jsx`（`InboxView`）。复用：R-56。数据：[data-model](../data-model.md) §5 capture。

## 1. 用户故事

| ID | 故事 |
| --- | --- |
| US-IN-01 | 我随时把一个想法、链接或行动收进收件箱（快捷键、首页卡片、收件箱输入条、CLI、MCP、外部插件）。 |
| US-IN-02 | 我稍后把每条捕获转为任务、笔记或档案，原始记录保留并能跳到生成的内容。 |
| US-IN-03 | 暂时不处理的捕获我可以归档，之后再放回待处理。 |
| US-IN-04 | 处理错了我可以撤销，生成的内容不会被删除。 |
| US-IN-05 | 我按来源筛选和搜索捕获。 |

## 2. 界面

- **模块侧栏**：标题“收件箱 n”+“+”；分段（待处理/已整理/已归档）；搜索；来源下拉（全部来源、快速捕获、笔记摘录、Agent CLI、手动导入、插件）；捕获列表（复选框用于批量归档、来源、时间、标题、正文两行）；底部“保留来源 · 保留上下文”。
- **页头**：“收件箱”+“快速捕获”按钮；下方常驻输入条“此刻脑海里有什么？写下来，按 Enter 收好…”（Enter 提交，Shift+Enter 换行）。
- **详情区**（选中捕获）：状态徽标、来源、时间、编辑/删除；标题；原文块；待处理时显示“这条想法，接下来应该去哪里？”与三张卡片（转为任务/转为笔记/转为档案；对应插件停用时卡片禁用并提示“请先在插件中心启用该模块”）；“暂时没有后续行动？可以归档保留。”+“归档这条记录”。已整理时显示“这个想法已经开始行动”+ 关联内容卡片（被删除时提示“关联内容已被删除或移入回收站，原始记录仍然保留”）+“撤销处理”。已归档时显示“放回收件箱”。
- **空状态**：待处理为空 →“收件箱已清空 · 现在可以安心专注于真正重要的事情。”

## 3. 行为

- 捕获：`inbox.capture({title?, body, source})`；标题为空时取正文首行前 40 字。外部入口（CLI/MCP/插件）提交的 `source` 由调用者身份决定（`cli`、`mcp`、`http`、`plugin:<id>`；桌面调用可指定 `quick`、`note-excerpt`、`agent-cli`、`import`），不信任输入中的来源字段。
- 转换（`inbox.convert({id, target, fields})`）：对话框预填（任务：名称=标题、正文=原文、截止日期可选、执行方式默认手动；笔记：名称、保存文件夹、正文=原文；档案：名称、类型、简介=原文；无档案类型时提示先创建）。确认后在一个操作中：目标插件创建对象 → 捕获 `status: processed`、`processedAt`、`result`。中断后重启按操作日志处理，不会重复创建目标（data-model §7）。
- 撤销处理：AlertDialog“撤销这次处理？条目会返回待处理。原先关联的内容不会被删除。”→ `status: pending`，清空 `result`。
- 归档/放回：切换 `dismissed` / `pending`。
- 删除：AlertDialog“永久删除收集记录？只删除原始收集记录；此前转化生成的内容会保留。”→ 文件进入回收站。

## 4. 验收

| ID | Given | When | Then |
| --- | --- | --- | --- |
| ACC-IN-01 | 任意页面 | `Mod+Shift+N` 输入内容回车 | `Inbox/` 新增 capture 文件，`source: quick`，侧栏计数 +1 |
| ACC-IN-02 | 一条待处理捕获 | 转为任务并确认 | 新任务文件存在；捕获 `status: processed`、`result.kind: task`；点击关联卡片打开该任务 |
| ACC-IN-03 | 在转换操作写完任务文件后、更新捕获前强制结束 Engine | 重新打开 Vault | 捕获为 processed 且只有一个任务；或回滚为 pending 且无任务文件（不出现两个任务） |
| ACC-IN-04 | 已处理的捕获，生成的任务已被编辑 | 撤销处理 | 捕获回到待处理；任务文件不变 |
| ACC-IN-05 | MCP 客户端调用 `inbox.capture`，输入中携带 `source: quick` | — | 文件中 `source: mcp`；输入中的来源被忽略 |
| ACC-IN-06 | 停用 archives 插件 | 查看待处理捕获 | “转为档案”卡片禁用并提示启用 |
