# H10 SSH 设置的 Windows 验证

对照已确认的 SSH 原型及 H10.1–H10.3。复用 Motty `2daa9db582e16edf60a60b7ada26f47f808f973c` 的设置分组、字号区间与连接偏好，并接入 Huhu 现有 Settings 贡献、终端外观、Vault 文件修订和工具开放策略。

| 设置 | 所有者与生效时机 | 实际入口 |
| --- | --- | --- |
| 工作区标签方向、分栏工具栏位置 | 本机，本次保存后 | 工作区布局和活动分栏 |
| 上次工作区视图 | 本机按 Vault 标识记录，启用后进入工作区时读取 | 恢复已有运行，断线仍由用户发起重连 |
| 字体、字号 | 本机，在渲染器中应用；浏览器须支持 CSS `zoom` 才可配置字号 | 单主机 Shell 与工作区分栏。字号使用终端局部等比缩放，字体读取现有主题或本机等宽字体 |
| 连接超时、SSH 保活间隔和次数 | 当前 Vault，在新拨号链开始时取同一份快照。主机配置优先，0 秒保活间隔明确停用。导入缺省超时沿用导入契约的 20 秒 | 直连、已绑定工作区、转发与监控的新拨号 |
| 点文件、初始排序、双栏顺序 | 本机，在文件视图中应用。手工选列或交换双栏优先 | 同一 SSH 会话的附着及独立 SFTP 面板、本机文件表 |
| 展开分栏文件 | 本机，进入工作区时应用 | 工具栏可见的活动分栏准备好后自动打开附着文件视图 |
| 并发传输数 | 当前 Vault，保存后用于队列调度；降低上限后现有传输继续 | 文件传输中心。覆盖继续逐项确认，文件发布核验数据与修改时间 |
| MCP 与共享工具 | 能力网关的现有工具策略修订和当前端点状态 | SSH 设置读取目录和最近审计。两种客户端示例均可复制，Vault 路径与令牌保留为待填写值 |

保活字段留空沿用 ssh2 默认值。连接时间只覆盖网络及认证阶段，人工核对主机密钥继续沿用现有信任流程。共用终端固定保留 5000 行回滚，配色跟随 Huhu 外观。SSH 设置尚无独立行距、光标、选中即复制、本机 Shell、录制、独立原生文件窗口或 SCP 开关。已知主机使用现有信任记录，凭据和连接日志由原入口管理。

`plugins/ssh/test/preferences.engine.test.ts` 使用隔离 Vault 和接受 TCP 但不发送 SSH greeting 的回环夹具，实测继承超时、主机覆盖、显式 0、版本冲突、重开和 Vault 隔离。

`tests/e2e/ssh/settings.spec.ts` 启动 Windows 桌面版，检查搜索、取消、默认值、保存效应、真实 Shell、重进恢复、分栏 SFTP、双栏位置和传输队列。公共工具用例比较实际策略修订、复制后的剪贴板，以及本机 CLI、MCP stdio、MCP HTTP 的发现结果。当前清单没有可对外开放的 SSH 能力，验证使用可开放的测试 Vault 笔记能力推进同一修订，并检查 SSH 候选被拒绝、尝试留下网关审计、停用 SSH 后目录标记停用。所有网络夹具只绑定 `127.0.0.1`。
