# H9.3 分栏只读服务器状态

复用 Motty 固定源码 `internal/remotetools` 的系统探测、进程与 Docker 列表模式。Huhu 只提供进程 PID 和名称，以及容器 ID、名称、镜像和状态。请求枚举绑定已打开分栏，通过固定命令读取。结果区分缺少 Docker、权限不足及原分栏已关闭。窗口关闭或切换查询取消其请求，并保留终端和监控订阅。

执行 `vitest run --no-cache --pool forks --maxWorkers 1 plugins/ssh/test`，70 项通过。两条实际回环 SSH 连接返回不同的合成进程和容器结果。交叉使用别的分栏和额外命令参数被拒。测试覆盖 Docker 缺失、读取权限不足及原连接关闭后另一终端保持在线。

本切片是普通权限的只读摘要。完整独立窗口、镜像列表、日志、容器操作及进程修改另行实施。
