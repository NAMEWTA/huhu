# #7 SSH 客户端与开发工作区 · 行为规格

用户在 Huhu 中管理获准访问的主机，保存连接资料，打开终端、文件和监控，并能从其他已授权入口找到同一操作的真实结果。功能及信息结构对照本地 Motty 默认分支；旧版截图和固定提交保留历史出处。使用 Huhu 自有导航、主题、组件和文案。下列是产品目标。本分支现状和已查到的上游文件见[架构设计](design.md)，逐条原始要求和截图位置见[来源快照](source.md)。

## 进入 SSH 和管理主机

Huhu 外壳内保留“主机、工作区、监控、会话日志、密钥、跳板路由/代理、端口转发、已知主机、快捷命令”，可进入本地终端和 SSH 设置。从 Huhu 的主机目录可搜索或快速连接、导入或新建、按树形分组、切换列表/网格，并对明确选区使用右键或批量动作。会话页同时容纳分栏终端、附属文件面板和工具侧栏。键盘、按钮和菜单调用同一动作，加载、错误、取消及禁用原因均可观察。逐流程对照见来源 §4 的四张上游图。

| 原需求 | 场景与可观察结果 |
| --- | --- |
| H01–H03 | 新建、编辑、复制、删除、测试与连接可分开执行。测试用当前未保存输入，编辑后结果失效，区分成功、仅可达待认证、失败。按名称/用户/地址/标签检索，多级分组可建改移删、折叠/排序/置顶；行显示账户、地址端口、图标、标签和状态。右键选中行保留集合，未选行只操作该行。批量移动/关联/连接与从选中项建工作区或监控面板结果一致。 |
| H04、H09 | 导入 OpenSSH、PuTTY、Xshell、MobaXterm、WindTerm、Electerm、Netcatty、SecureCRT 时展示映射预览、冲突和不支持字段，不能承诺恢复 SecureCRT 加密口令。持续 OpenSSH 双向同步单列；稳定映射和变更指纹避免回写循环，导入命令字段只作数据。 |
| H05–H08、H10 | 主机表单维护账号、密码、身份文件、粘贴或保存的私钥/口令、agent、按需交互认证；保留 OpenSSH 用户证书、PPK v2/v3、OTP、多轮多问、IdentitiesOnly、身份文件列表及来源 §5 高级选项。密钥可导入/生成 Ed25519/复制公钥/删除。逐跳先验证主机密钥，再认证。首次信任、已知指纹/CA、changed-key、缺失本机凭据、等待输入、服务端拒绝、取消均可区分。changed-key 需经独立的已知主机管理。超时、协议 keepalive、终端输入保活分开，未设与显式 0 保留其含义。 |
| H01、H05、A21 | 同一保存操作原子关联主机与 SSH 私有认证，省略保留、显式替换或清空；掩码只用于显示。普通列表、日志、导出不含明文。临时回答不持久化。Safe 从未初始化、锁定和停用三个状态分别验证。账号/主机定义可恢复，本机身份文件、agent 和解密钥匙的可用性独立呈现。使用新格式及 SSH 独立认证，正常备份恢复只用新建的测试数据。真实旧数据不参与操作。 |

## 工作区、终端和文件

| 原需求 | 场景与可观察结果 |
| --- | --- |
| W01–W06 | 临时工作区可立即启动、运行后存模板；固定工作区可预览、编辑、重命名、删除及启动。模板保存有序且不重复的 hostId、布局及可选登录命令，最多 12 Pane。支持 1/2/3 列、左主右辅、上主下辅、内部标签及自定义分割树。先建立完整绑定并保存再拨号，结构失败整体回滚；单 Pane 连接失败保留其他成功项。移动/交换/缩放、换窗和重挂保留活会话；进程重启呈现重连。 |
| §6.2 | 真实 PTY 支持中文 IME、组合字符、ANSI、备用屏、鼠标、全屏程序和 resize。横/纵标签、锁定/重排/成组、分栏、导航/最大化、移至新窗口、工具栏移动/隐藏/恢复默认都绑定实际 Pane。单控制者与观察者分离；广播有可见目标集，建议插入和发送回车分开。搜索、链接、历史、高亮、补全、快捷命令分组/排序、显式录制/回放逐项对照。登录后命令只随新 shell 准备完成发送一次。独立本地 PTY 可选择已安装 Shell/WSL，停用 Agent CLI 后仍可用。 |
| F01–F04、F14 | 附属面板跟随活动 Pane；独立双栏（窗口或 Tab）固定来源会话，可由主机另开独立连接。本地/远端两栏可换位、分别导航。多选、属性、权限、时间/大小、书签、树、排序、列宽、历史导航与菜单可用。附属递归搜索有界可取消，结果仅定位；独立过滤限当前目录。文件及目录可创建、重命名、移动、删除、处理链接和权限；跨授权远端复制用流中转。 |
| F05–F06、F12–F13 | 文件/目录批量传输产生独立任务；显示有限并发、进度/速度、冲突、暂停、继续、取消、重试和终态。拒绝/覆盖/续传/跳过及目录合并有明确结果。续传验证目标前缀，完成后提交，断网/冲突保全旧目标。关闭视图仍可从中心回到来源。压缩/解压先查工具能力，保留时间戳；清历史只影响记录。 |
| F07–F11 | 远端文本编辑以 Motty 1 MiB UTF-8 为基线，支持查找替换、行号、定位、缩进和保存冲突；校验版本/哈希，保留权限。SFTP 缺失时明确 SCP 可做哪些事。特权文件后端、监控及工具特权状态按作用对象分离。Bash/Zsh 的目录跟随双向独立，反向默认关，只在已确认空闲提示符时生效；跳过的动作不补发。使用已安装外部编辑器时核对目标和路由可表达性。Web 使用浏览器传输或编辑入口，系统专属动作说明所在设备。 |

## 路由、转发与监控

| 原需求 | 场景与可观察结果 |
| --- | --- |
| R01–R07 | 路由页可看完整路径、按中枢分组、行内改动及批量启停/关联。目标仅有一个直接跳板，拒绝缺失、自指和环。全局出站代理与主机继承/直连/独立配置分别显示；主机测试、终端和文件使用同一已授权路由。每跳独立信任认证并报告失败位置。停用路由改变后续拨号，旧连接保留实际路径。ProxyCommand、ViaShell 及本地代理分享按来源限定的运行地点、支持模式和用户配置验收；复制辅助配置只复制文本。 |
| P01–P07 | Local、Remote、SOCKS5、HTTP CONNECT 四种回环规则分别展示监听端、出口和实际绑定。仅静态目的规则要求目标地址。保存规则只写配置；启动才监听。运行中编辑先停旧规则，删除先回收。实际 TCP 流量产生连接数/字节，拒绝、端口冲突、跳板断线可见。借用会话、共享专用连接和显式 Resume 分开；主动停止后不自动复活，最后持有者退出时释放专用连接。模式决定可用字段和受支持中继，非法组合不可保存。 |
| §10 | 活动 Pane 的监控侧栏可停靠、暂停/继续/重试，1/2/5 秒刷新。命名仪表盘可增改删、依分组选择主机并排序；保存后手动开始采样，各主机单独呈现连接/运行/失败/不支持。按来源使用 2/5/10/30/60 秒周期，15 分钟/1/6/24 小时有界内存历史；共享同一来源时用最快需要的周期。暂停/断线显示空隙。按系统显示 CPU、内存、磁盘、网络、负载等受支持指标。隐藏页停止重绘，关闭监控不杀终端。进程/Docker 工具窗口固定来源；支持项、权限及不可用原因取自实际主机。 |

## 设置与公共入口

设置按通用/布局、终端、连接、文件、MCP 分类，密钥、已知主机及快捷键可定位。每个字段以来源 §11 的默认值、生效时机与存储范围核对。设备布局、路径、Shell/编辑器选择留在本机，主机配置按可迁移性保存。Huhu 的语言、主题、窗口设置保持统一。已保存且待下次连接生效的字段须明确提示。

桌面/Web、MCP 两种传输及 CLI 经 [#6 共享契约](../2026-11-19-issue-6-unified-tools-web/design.md)调用 SSH 领域服务。按主机、连接/等待项、工作区、会话/作业、文件/传输、路由、转发、监控、设置/日志/密钥登记真实用户操作。目录能说明权限、scope/risk、schema、依赖和运行状态。SSH 设置呈现全局 MCP 的服务、客户端配置、脱敏预览、复制、最近活动和 SSH 筛选视图；各入口读取一份选择。Motty 窗口 HTTP 与独立 stdio 在会话 ID、可见输出、后台任务和文件能力上的差异见来源 §12.1，Huhu 统一对象语义。已授权操作不依赖预先打开一个桌面 Tab，作业有可查询的范围、输出游标、终态与取消结果。

HTML 原型的全部 SSH 行为仅由离线夹具驱动。实施验收在已授权测试主机上观察连接、交互 PTY、SFTP、转发和监控的实际结果；在对应平台构建桌面包并从产物启动。插件停用、切 Vault、重启和原生组件退出时核对资源回收。上游与 Huhu 差异逐条落在“功能 ID / 默认分支提交及文件 / 本地实现或公共合同 / 证据”中。VNC/RDP、Mosh、Telnet/串口等独立协议、上游完整 AI 产品和跨设备同步属于来源 §2 的扩展范围。SSH 相关本地终端和文件传输动作仍按原来源对照。验收编号 A01–A21 的交付归属见[计划](plan.md)。
