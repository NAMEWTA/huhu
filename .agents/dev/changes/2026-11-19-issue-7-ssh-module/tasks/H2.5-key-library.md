## 实施验收

在隔离的测试凭据目录内生成或导入测试密钥，使用专用测试 agent 或身份文件连接已授权测试主机，核对应用显示的来源和服务端接受的认证方式。

1. 用三类身份样例分别展示保存的加密私钥、设备文件、agent；已保存 key 可在主机表单选择，复制得到对应测试公钥。
2. 缺文件、缺 agent、错误口令与被引用的 key 状态可辨；普通列表、日志、模板和新格式导出均无私钥或口令。
