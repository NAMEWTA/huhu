## 实施验收

以当前 Huhu、Motty 与同级 Viva 检出为准，抽查来源路径、提交和采用文件的许可。

1. 从主机编辑、独立 SFTP、采样历史和转发状态四个场景各追到本地源码、测试及许可证，再逐项登记来源 §14；自有 UI 仅引用行为。
2. 某项依赖、素材或许可未核实即记录缺口与影响；历史 SHA 和截图不能充当当前实现或授权证明。

## 原型对照与确认范围

HTML 原型始终使用离线夹具，连接、终端、文件、转发和监控均为模拟。

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「主机、文件传输、监控、端口转发」对照「主机、文件、监控、转发／信息结构」。本片验证领域或接口结果，该场景用于对照结果在工作台的解释。可见效果的确认以[原型确认记录](../prototype-review.md)为准；后端合同可独立验证。
