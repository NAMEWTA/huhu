## 实施验收

在实际工作区库内，以测试 Vault 的主机记录保存模板；重开应用后核对持久化的布局和顺序。

1. 选择并重排主机，轮换 1/2/3 列、左主右辅、上主下辅、内部标签和自定义树；保存、重命名、重开、删除模板，核对顺序和布局。
2. 重复 hostId、超过 12 个或非法树显示错误；模板不含凭据、活动连接或输出。

HTML 原型始终使用离线夹具，连接、终端、文件、转发和监控均为模拟。

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「工作区」对照「工作区／选择主机、布局预览、固定模板」。待用户确认该场景的入口、状态反馈以及上述失败后能采取的动作。落地界面前按[原型确认记录](../prototype-review.md)核对具体版本和覆盖范围；演示未覆盖的细节单列待走查。
