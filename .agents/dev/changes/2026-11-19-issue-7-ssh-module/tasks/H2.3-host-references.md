## 实施验收

在测试 Vault 建立带引用与无引用的两台主机；从应用的删除入口检查引用清单和实际持久化结果。

1. 为测试主机建立三类引用，打开删除能辨认每个受影响对象；无引用项确认后只删除目标。
2. 有引用时按最终选择验证先解绑，或预览后原子解除；取消或提交失败保持主机和原引用，未定前不宣称级联获批。

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「主机」对照「主机／删除引用预览」。演示中的删除分支仍待 Q7-1 决定。待用户确认该场景的入口、状态反馈以及上述失败后能采取的动作。落地界面前按[原型确认记录](../prototype-review.md)核对具体版本和覆盖范围；演示未覆盖的细节单列待走查。
