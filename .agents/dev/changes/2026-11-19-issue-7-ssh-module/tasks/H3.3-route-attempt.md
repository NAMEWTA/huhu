## 实施验收

对预先指定的授权测试主机分别验证直连及三层测试跳板。记录每个 hop 的主机标识、阶段和结束原因，测试拓扑与账户归属随证据记录。

1. 分别在直连及三跳测试中对照拨号、信任、认证和成功的时间线；每跳显示身份、方式和结果，终端数与连接数可独立计数。
2. 中间节点拒绝信任、认证取消或代理超时，失败止于该 hop，后续节点没有事件；核对所选代理或中继的实际运行位置与界面状态。

## 原型对照与确认范围

HTML 原型始终使用离线夹具，连接、终端、文件、转发和监控均为模拟。

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「跳板路由／代理、主机」对照「连接详情／逐跳进度、代理来源与失败」。待用户确认该场景的入口、状态反馈以及上述失败后能采取的动作。落地界面前按[原型确认记录](../prototype-review.md)核对具体版本和覆盖范围；演示未覆盖的细节单列待走查。
