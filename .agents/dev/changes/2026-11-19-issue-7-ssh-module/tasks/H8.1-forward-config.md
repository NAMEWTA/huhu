## 实施验收

从产品规则编辑器新建四种测试规则，重新打开核对保存的字段与监听端。只保存时，对应测试端口应仍未监听。

1. 切换 Local、Remote、SOCKS5、HTTP CONNECT，对照监听端/出口，动态模式免填固定目标；保存后状态仍是已配置。
2. 无效端口、模式不支持的中继或目标组合不可保存；界面没有活动监听或流量的假成功。

## 原型对照与确认范围

HTML 原型始终使用离线夹具，连接、终端、文件、转发和监控均为模拟。

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「端口转发」对照「端口转发／四种模式与编辑预览」。待用户确认该场景的入口、状态反馈以及上述失败后能采取的动作。落地界面前按[原型确认记录](../prototype-review.md)核对具体版本和覆盖范围；演示未覆盖的细节单列待走查。
