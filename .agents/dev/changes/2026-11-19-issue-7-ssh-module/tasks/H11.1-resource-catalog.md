## 实施验收

从已启动应用读取已实现域的实际工具目录，逐项与 UI 动作、活动 handler 或声明的流合同对照。

1. 从主机、工作区、会话/作业、文件、路由、转发、监控、设置与日志逐一对照 UI 操作和公共 ID、scope/risk、schema、可用状态。
2. 旧名字、未登记资源和停用 handler 的工具不能标为可调用；无权时即使经通用代理也不取得资源。
