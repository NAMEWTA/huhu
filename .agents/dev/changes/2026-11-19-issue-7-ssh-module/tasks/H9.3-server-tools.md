## 实施验收

从两条已授权测试会话打开服务器工具，核对各自主机上的专用测试进程或容器、可用动作以及窗口归属。

1. 从 A、B 打开对应窗口，重开 A 聚焦原窗口；选择测试进程、容器、镜像和日志，结果始终标明来源。
2. 缺 Docker、无权限和会话关闭分别说明原因；关闭窗口只取消该来源的查询。
