**已有代码入口**　[plugins/ssh/src/ui/SshModule.tsx](../../../../../plugins/ssh/src/ui/SshModule.tsx)、[plugins/ssh/src/engine/hosts.ts](../../../../../plugins/ssh/src/engine/hosts.ts)。

## 实施验收

在桌面客户端的临时 Vault 建立测试主机记录，比较界面操作前后保存的 hostId 集合。

1. 用同名不同账户的夹具按名称、用户、标签、地址搜索；切列表/网格、置顶、排序、拖到子组，重新进入时顺序与选区作用域正确。
2. 右键未选行只作用该行；右键已选行保留集合；单目标动作在多选禁用，移动分组不能形成环。

## 原型对照与确认范围

HTML 原型始终使用离线夹具，连接、终端、文件、转发和监控均为模拟。

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「主机」对照「主机／搜索、分组树、网格、多选」。待用户确认该场景的入口、状态反馈以及上述失败后能采取的动作。落地界面前按[原型确认记录](../prototype-review.md)核对具体版本和覆盖范围；演示未覆盖的细节单列待走查。
