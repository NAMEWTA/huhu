## 实施验收

在授权测试主机的临时目录创建归档并解压至另一测试目录，核对源设备、成员路径、时间戳和文件摘要。

1. 查看测试文件的源设备，选择支持压缩的后端并预览归档，解压后核对时间戳与路径归属。
2. 不支持或工具缺失时提示具体原因，不安装程序；CLI/浏览器来源不能被当作 Engine 本地路径。

## 原型对照与确认范围

HTML 原型始终使用离线夹具，连接、终端、文件、转发和监控均为模拟。

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「文件传输」对照「SFTP／归档、时间戳和设备标签」。待用户确认该场景的入口、状态反馈以及上述失败后能采取的动作。落地界面前按[原型确认记录](../prototype-review.md)核对具体版本和覆盖范围；演示未覆盖的细节单列待走查。
