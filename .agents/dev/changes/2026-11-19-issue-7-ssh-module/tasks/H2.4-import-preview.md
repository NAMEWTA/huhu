**可见结果与边界**　八种第三方格式是主动导入入口；按本次选中的文件预览和写入测试 Vault。一次性导入不启动持续同步。

## 实施验收

通过客户端导入测试目录中的八种格式样本；保存后重新打开主机列表，按稳定 ID 与预览逐项比对。

1. 分别选择 OpenSSH、PuTTY、Xshell、MobaXterm、WindTerm、Electerm、Netcatty、SecureCRT 样例，核对目标字段、来源、冲突、跳过和接受项。
2. 不可解的 SecureCRT 口令、未支持字段和坏记录逐项提示；取消零写入，命令字段始终作为文字。

## 原型对照与确认范围

HTML 原型始终使用离线夹具，连接、终端、文件、转发和监控均为模拟。

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「主机」对照「主机／导入预览、冲突和跳过」。八格式映射另用合成导入样本逐项验收。待用户确认该场景的入口、状态反馈以及上述失败后能采取的动作。落地界面前按[原型确认记录](../prototype-review.md)核对具体版本和覆盖范围；演示未覆盖的细节单列待走查。

## Windows 后端验收

- OpenSSH 静态 Host、PuTTY Session 文件和注册表导出、Xshell `.xsh`、MobaXterm Bookmarks、WindTerm JSON、Electerm bookmarks JSON、Netcatty CSV 和 SecureCRT Session INI 各有合成夹具。逐行关联 Huhu 端点、分组、名称与端点冲突、以及跳过原因。SecureCRT UTF-16 和加密口令提示也已验证。Xshell `.xts` 归档当前返回具体的未支持变体提示。 [格式回归](../../../../../plugins/ssh/test/host-import.test.ts) · [上游台账](../../../../../docs/upstream/ledger.md)
- Engine HTTP 的 `ssh.hosts.import.preview` 从当前目录读冲突。测试逐字节比对主机文件，验证预览无写入、外部 CLI 被拒、停用插件后静态目录仍可读取能力说明。SSH 全项目在生产入口装配前 55 项通过，装配后导入和目录定向 13 项通过。 [工作台入口回归](../../../../../plugins/ssh/test/directory.test.ts)
- Windows Engine HTTP 的 `ssh.hosts.import.confirm` 复核原文件与主机目录的版本，只写用户选择的行。同名主机可重命名，已有端点冲突必须跳过。Netcatty 合成测试验证了版本过期、重复选择、只创建选中主机、两层分组、坏目录保留原文件、修复后按原主机 ID 重试，以及重开 Vault 后的持久化。导入只带主机字段，样本中的命令和密码未出现在预览或已保存配置中。格式、目录及独立认证组合共 17 项通过。 [工作台入口回归](../../../../../plugins/ssh/test/directory.test.ts)
