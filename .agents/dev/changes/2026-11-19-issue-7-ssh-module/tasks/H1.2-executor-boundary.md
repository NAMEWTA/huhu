## 实施验收

在开发机从本地 Motty 和同级 Viva 构建候选组件，从 Huhu 的 SSH 模块启动它。以平台、架构、组件版本和构建日志标识本次证据。

1. 检查构建实际解析了同级 Viva/leaks。通过授权测试主机验证候选组件的连接、PTY、SFTP 测试文件往返和测试端口转发，核对应用退出后组件释放资源。
2. 用隔离的打包输入分别遗漏候选资产、提供不匹配的版本，记录构建或启动阶段的明确失败。保存成功制品的架构和校验值，最终三平台安装包由 H12.2 验收。

## 原型对照与确认范围

HTML 原型始终使用离线夹具，连接、终端、文件、转发和监控均为模拟。

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「SSH 设置」对照「SSH 设置／执行组件可用性」。平台资产、许可与构建证据不属于 HTML。本片验证领域或接口结果，该场景用于对照结果在工作台的解释。可见效果的确认以[原型确认记录](../prototype-review.md)为准；后端合同可独立验证。
