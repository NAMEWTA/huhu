## 实施验收

在测试 Vault 同时打开 SSH 设置和公共权限页，使用本地 MCP/CLI 客户端核对相同 revision 与入口状态。

1. 更改 SSH 工具选择，在全局页看到同一 revision；查看两种传输、客户端模板和最近活动，复制预览不含真实 token。
2. 关工具、关 MCP、停插件显示不同原因；干净安装全部关闭，失效的入口不显示可用。

## 原型对照与确认范围

HTML 原型始终使用离线夹具，连接、终端、文件、转发和监控均为模拟。

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「SSH 设置」对照「SSH 设置／MCP 与共享工具权限」。待用户确认该场景的入口、状态反馈以及上述失败后能采取的动作。落地界面前按[原型确认记录](../prototype-review.md)核对具体版本和覆盖范围；演示未覆盖的细节单列待走查。
