## 实施验收

在测试 Vault 保存路由图，分别从主机编辑页和路由页读回。使用既有测试会话和下一次连接的实际路径核对启停的生效范围。

1. 用 A、B、C 与目标配置测试路线，检查全路径、目标筛选、启停和批量跳过/覆盖。停用后下次连接显示直连，旧会话显示原路径。
2. 自指、缺失、非 SSH 或有环候选不可提交；批量校验失败保留原图。无旧 jumpHostIds 迁入步骤。

## 原型对照与确认范围

HTML 原型始终使用离线夹具，连接、终端、文件、转发和监控均为模拟。

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「跳板路由／代理」对照「跳板路由／树、按中枢分组、批量覆盖」。待用户确认该场景的入口、状态反馈以及上述失败后能采取的动作。落地界面前按[原型确认记录](../prototype-review.md)核对具体版本和覆盖范围；演示未覆盖的细节单列待走查。
