## 实施验收

在开发机的桌面应用验证本机已安装的 Shell；Windows 上具备 WSL 时也验证指定发行版。核对真实 PTY、重连对象和退出后的进程状态。

1. 停用测试 Vault 的 Agent CLI 后选择本机 Shell 与 WSL，窗口分别标记来源；更换全局默认后旧 Tab 重连保留原选择。
2. 选定的测试发行版或 Shell 不可用时显示具体不可用原因，既不回退错误环境也不残留子进程。

## 原型对照与确认范围

HTML 原型始终使用离线夹具，连接、终端、文件、转发和监控均为模拟。

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「工作区」对照「本地终端／环境选择、不可用与重连」。本地 Shell／WSL 来自虚构设备清单。待用户确认该场景的入口、状态反馈以及上述失败后能采取的动作。落地界面前按[原型确认记录](../prototype-review.md)核对具体版本和覆盖范围；演示未覆盖的细节单列待走查。
