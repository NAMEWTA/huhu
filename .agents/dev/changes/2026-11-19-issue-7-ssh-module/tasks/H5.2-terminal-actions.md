## 实施验收

在隔离的测试工作区中使用无副作用的样本文本，通过真实终端输入与应用的广播控件，按各 Pane 的回显核对选中范围。

1. 建立三个测试 Pane，在两个目标间预览多行建议，分别点击插入/发送；核对接收标识。切标签方向，移动与恢复工具栏。
2. 锁定或失去控制的 Pane 不接收输入，隐藏工作区无输入事件；无效拖动或 Escape 恢复位置。

## 原型对照与确认范围

HTML 原型始终使用离线夹具，连接、终端、文件、转发和监控均为模拟。

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「工作区、快捷操作」对照「工作区 Shell／目标选择、广播、快捷命令与工具栏」。待用户确认该场景的入口、状态反馈以及上述失败后能采取的动作。落地界面前按[原型确认记录](../prototype-review.md)核对具体版本和覆盖范围；演示未覆盖的细节单列待走查。
