## 实施验收

在授权测试主机编辑临时 UTF-8 文件，从另一测试会话更改同一文件以触发冲突，读回实际内容与权限。

1. 打开 1 MiB 以内 UTF-8 夹具，查找替换、跳行、缩进后保存，核对新版本、权限与原会话；关闭知识库仍可编辑。用可表达的测试目标打开已安装的编辑器，核对实际文件与来源。
2. 超限、非 UTF-8、并发变化分别提示；不可表达的私有路由标记外部编辑器不可用，不打开外部程序。

## 原型对照与确认范围

HTML 原型始终使用离线夹具，连接、终端、文件、转发和监控均为模拟。

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「文件传输」对照「SFTP／文本编辑、保存冲突与外部编辑器」。待用户确认该场景的入口、状态反馈以及上述失败后能采取的动作。落地界面前按[原型确认记录](../prototype-review.md)核对具体版本和覆盖范围；演示未覆盖的细节单列待走查。
