## 实施验收

在授权测试主机查看监控侧栏，选取系统支持的指标与同一时间窗口内的主机观测对照，记录采样时刻和支持状态。

1. 切换两个不同系统的测试 Pane，分别展示支持的 CPU、内存、磁盘、网络等指标；暂停后留空隙，恢复继续采样。
2. 无权限、未采样、GPU 不支持显示对应状态；关闭侧栏停止订阅而不关闭终端。

## 原型对照与确认范围

HTML 原型始终使用离线夹具，连接、终端、文件、转发和监控均为模拟。

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「监控、工作区」对照「监控／会话侧栏、暂停、不可用指标」。待用户确认该场景的入口、状态反馈以及上述失败后能采取的动作。落地界面前按[原型确认记录](../prototype-review.md)核对具体版本和覆盖范围；演示未覆盖的细节单列待走查。
