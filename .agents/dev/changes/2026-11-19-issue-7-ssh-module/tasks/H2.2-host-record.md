## 实施验收

在新建测试 Vault 使用专用测试账户和凭据，经客户端保存、重新打开并从授权测试主机验证配置可用；证据只记版本、认证方式和结果。

1. 保存测试主机并重开，核对账户/端口、分组/标签及高级字段；依次省略、替换、清空测试口令，摘要反映状态；显式 0 与未配置可区分。
2. 两个编辑者持同版提交，迟到者收到冲突；模拟受保护存储写失败，旧版本与旧引用保持。Safe 未初始化、锁定、停用三个样例结果一致。

HTML 原型始终使用离线夹具，连接、终端、文件、转发和监控均为模拟。
