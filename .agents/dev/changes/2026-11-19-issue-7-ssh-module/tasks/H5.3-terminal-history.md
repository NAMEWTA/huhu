## 实施验收

显式录制授权测试会话中的非敏感样例输出，通过客户端日志入口查找并回放，记录会话标识、片段范围和停止点。

1. 启动录制、产生带多字节字符的样例输出、停止；从日志找到对应片段并回放，筛选另一会话后结果独立。
2. 未录制区间或截断历史展示边界；禁用录制时无新条目，临时认证回答不出现在常规日志。

## 原型对照与确认范围

HTML 原型始终使用离线夹具，连接、终端、文件、转发和监控均为模拟。

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「会话日志」对照「会话日志／搜索及回放」。待用户确认该场景的入口、状态反馈以及上述失败后能采取的动作。落地界面前按[原型确认记录](../prototype-review.md)核对具体版本和覆盖范围；演示未覆盖的细节单列待走查。
