## 实施验收

在客户端的两个已授权测试会话之间调整分栏，记录操作前后的 connectionId、shellId、焦点和连接次数。

1. 在双 Pane 间交换、分割、缩放、最大化并还原，移动到另一工作台窗口后核对绑定 ID、焦点和历史。
2. 无效落点或取消拖动保持原树；关闭一个 Pane 仅回收它持有的资源，其他会话不重连。

HTML 原型始终使用离线夹具，连接、终端、文件、转发和监控均为模拟。
