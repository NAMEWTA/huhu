## 实施验收

以已授权测试主体分别通过本地 MCP 客户端和 CLI 操作同一专用测试主机。记录域对象 ID、输出摘要及终态，分别留存两个入口的结果。

1. 分别通过 MCP 和 CLI 完成主机认证更新、信任待答、查会话、读作业、传文件、停止；读回同一域状态，独立于桌面 Tab 和 Safe。
2. 重放旧提示或撤销前的缓存能力拒绝，重复意图不增加作业/传输；撤销后按旧凭据继续访问受保护资源应收到明确错误。
