## 实施验收

在对应平台用本地桌面打包入口生成制品，从产物启动应用并对已授权测试主机做最小连接与文件往返。每个平台单列实际构建和运行记录。

1. 从仓库根运行 `pnpm --filter @huhu/desktop run build`、`pnpm --filter @huhu/desktop run dist`，核对本机目标架构、包内组件路径、版本和校验值。将 `HUHU_PACKAGED_EXE` 指向打包应用并运行 `pnpm e2e:packaged`；另在该应用用授权测试账号打开 SSH、读回测试文件并退出，核对资源回收。
2. 用独立打包副本移除目标所需资产，再打包应在制品生成前报告具体缺件。Windows x64、macOS arm64、Linux x64 分别记录本地制品、启动结果和实测范围，暂缺的平台标为待验。
