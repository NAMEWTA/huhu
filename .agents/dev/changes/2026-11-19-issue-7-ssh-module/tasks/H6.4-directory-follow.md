## 实施验收

在授权测试主机的 Bash/Zsh 会话比较真实 prompt、活动目录与文件面板；分别在空闲、全屏和交互提示状态操作。

1. 在 Bash/Zsh 空闲提示符下更改目录，再从面板选择另一目录，检查只给原会话一次同步；另一方向关闭时无反馈循环。
2. 全屏、口令提示、忙碌或未知 shell 时跳过，恢复空闲也不补发；重连须有新代次的空闲信号。

## 原型对照与确认范围

HTML 原型始终使用离线夹具，连接、终端、文件、转发和监控均为模拟。

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「文件传输、工作区」对照「SFTP／目录跟随与暂停原因」。待用户确认该场景的入口、状态反馈以及上述失败后能采取的动作。落地界面前按[原型确认记录](../prototype-review.md)核对具体版本和覆盖范围；演示未覆盖的细节单列待走查。
