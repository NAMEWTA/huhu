## 实施验收

从授权测试会话打开 SFTP，使用带有不同标记文件的两个测试目录确认附属面板和独立窗口的实际来源。

1. 从会话 A 打开独立双栏后切 B，让附属面板跟随 B；双栏仍指 A，可交换两侧、返回、排序、书签、显示属性或筛选当前目录。
2. 递归名称搜索有界、可取消、遇链接不跟随；结果只定位。关独立面板不结束原会话。

## 原型对照与确认范围

HTML 原型始终使用离线夹具，连接、终端、文件、转发和监控均为模拟。

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「文件传输、工作区」对照「SFTP／附属面板、独立双栏、导航搜索」。待用户确认该场景的入口、状态反馈以及上述失败后能采取的动作。落地界面前按[原型确认记录](../prototype-review.md)核对具体版本和覆盖范围；演示未覆盖的细节单列待走查。
