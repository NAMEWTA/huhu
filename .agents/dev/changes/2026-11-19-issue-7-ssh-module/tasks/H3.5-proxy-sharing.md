## 实施验收

在授权测试环境内，从模块的代理分享界面选择测试代理及测试主机，核对启停前后显示的状态与该测试服务的实际可达性。

1. 选择测试代理后依次检测、开始、测试、查看状态与停止；复制预览中的样例配置，并核对剪贴板文本。
2. 无代理、测试失败或停止后，旧成功状态清除；复制不改变测试主机的 Shell 或 Docker 配置。

## 原型对照与确认范围

HTML 原型始终使用离线夹具，连接、终端、文件、转发和监控均为模拟。

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「跳板路由／代理」对照「路由与代理／辅助分享」。待用户确认该场景的入口、状态反馈以及上述失败后能采取的动作。落地界面前按[原型确认记录](../prototype-review.md)核对具体版本和覆盖范围；演示未覆盖的细节单列待走查。
