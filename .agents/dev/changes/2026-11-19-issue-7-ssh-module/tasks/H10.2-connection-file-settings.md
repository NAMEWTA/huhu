## 实施验收

在桌面应用比较授权测试主机的活动连接、新连接及实际文件视图。记录字段变化、生效时机、所属设备或 Vault。

1. 修改超时和独立文件窗口模式，比较现有测试会话、新连接和新文件视图；重进后回读并以字段清单逐项定位消费者。
2. 非法值不能保存，显式 0 与未设置不混淆；不支持的宿主功能说明原因，另一 Vault 的可迁移设置保持隔离。
