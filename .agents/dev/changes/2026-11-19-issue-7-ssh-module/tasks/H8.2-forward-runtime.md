## 实施验收

使用专用回环测试服务和已授权 SSH 测试主机，逐模式通过实际请求验证可达性、流量统计以及停止后的端口释放。

1. 让两条规则共享同一专用测试连接，传送已知大小的数据并核对计数和字节，停一条另一条继续；最后一个持有者退出后资源计数归零。
2. 端口冲突、拒绝和跳板失联各有原因，重复启动只有一实例；主动停止不复活，运行中编辑/删除先结束旧实例。
