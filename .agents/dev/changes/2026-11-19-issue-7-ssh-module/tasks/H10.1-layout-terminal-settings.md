## 实施验收

在桌面工作台修改设置，检查它在实际工作区和终端上的显示效果以及重启后的持久化值。

1. 按来源字段表检查每项默认值、设备/Vault 归属及生效时机；更改字号、标签方向与工具栏后观察相应活动 Pane，恢复默认可回读。
2. 搜索无匹配提示；取消编辑保留原值，设备路径和布局不写到另一设备，全局主题/语言复用 Huhu。

## 原型对照与确认范围

HTML 原型始终使用离线夹具，连接、终端、文件、转发和监控均为模拟。

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「SSH 设置」对照「SSH 设置／通用、布局、终端和恢复默认」。待用户确认该场景的入口、状态反馈以及上述失败后能采取的动作。落地界面前按[原型确认记录](../prototype-review.md)核对具体版本和覆盖范围；演示未覆盖的细节单列待走查。
