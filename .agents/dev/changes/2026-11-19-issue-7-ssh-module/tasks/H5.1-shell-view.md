## 实施验收

从桌面终端打开授权测试主机的真实 PTY。以中文输入法、宽字符、全屏应用、resize 和第二个只读视图验证实际显示及控制归属。

1. 在两窗选择同一测试会话，给一方控制，检查观察者标记与回放文本；输入中文组合和宽字符，切换全屏并调整窗口大小。
2. 观察者输入/resize 或晚到控制事件被拒；重挂不再触发登录动作，图像或键盘协议无实测的项标待验证。

## 原型对照与确认范围

HTML 原型始终使用离线夹具，连接、终端、文件、转发和监控均为模拟。

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「工作区」对照「工作区 Shell／输入焦点、只读观察、全屏」。待用户确认该场景的入口、状态反馈以及上述失败后能采取的动作。落地界面前按[原型确认记录](../prototype-review.md)核对具体版本和覆盖范围；演示未覆盖的细节单列待走查。
