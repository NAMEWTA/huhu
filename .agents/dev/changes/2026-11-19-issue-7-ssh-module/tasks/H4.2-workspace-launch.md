## 实施验收

在桌面工作区使用授权环境中可达与有意不可达的测试主机，按 Pane 对照实际连接、失败位置和保存的模板。

1. 启动三个 Pane，一个失败，其余两个可切换且仍已连接；从临时工作区存模板，重开产生新的运行标识。
2. 模拟绑定保存失败时运行和拨号事件数为零；重挂视图保持会话 ID，应用重启后重连显示新代次。

## 原型对照与确认范围

HTML 原型始终使用离线夹具，连接、终端、文件、转发和监控均为模拟。

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「工作区」对照「工作区／临时启动、部分连接失败、重开」。待用户确认该场景的入口、状态反馈以及上述失败后能采取的动作。落地界面前按[原型确认记录](../prototype-review.md)核对具体版本和覆盖范围；演示未覆盖的细节单列待走查。
