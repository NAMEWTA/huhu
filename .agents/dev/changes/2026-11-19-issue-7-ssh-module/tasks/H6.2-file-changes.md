## 实施验收

在授权测试主机的临时目录操作自建文件，对照 SFTP 返回的目录条目、权限、链接目标和错误。特权分支使用具备相应测试权限的账户。

1. 在 A 的临时目录建文件并修改名称与权限，回读列表；开启文件会话的测试特权，仅 A 的相应文件会话变化。
2. 无 SFTP 只显示 SCP 后端支持项，缺权限或目标变化保留原记录；监控与终端不随文件特权改变。

## 原型对照与确认范围

HTML 原型始终使用离线夹具，连接、终端、文件、转发和监控均为模拟。

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「文件传输」对照「SFTP／属性、文件操作、后端能力」。待用户确认该场景的入口、状态反馈以及上述失败后能采取的动作。落地界面前按[原型确认记录](../prototype-review.md)核对具体版本和覆盖范围；演示未覆盖的细节单列待走查。
