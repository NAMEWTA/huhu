## 实施验收

授权测试主机分别提供认证成功、可达但仍需交互、连接失败三种条件。通过客户端主机表单测试，记录连接结果及结束后的活动会话数。

1. 在未保存表单改变地址/身份后点测试，依次展示三态；更改输入后旧测试标记清除，目录及会话数保持。
2. 等待中取消或收到上一版表单的晚响应，结果不覆盖新输入，测试结束后目录无新增主机，无隐藏终端或仍占用的测试连接。

## 原型对照与确认范围

HTML 原型始终使用离线夹具，连接、终端、文件、转发和监控均为模拟。

打开[本地原型](../prototype/index.html)，从[侧栏导航](../prototype/prototype.js)的「主机」对照「主机／测试未保存配置」。待用户确认该场景的入口、状态反馈以及上述失败后能采取的动作。落地界面前按[原型确认记录](../prototype-review.md)核对具体版本和覆盖范围；演示未覆盖的细节单列待走查。
