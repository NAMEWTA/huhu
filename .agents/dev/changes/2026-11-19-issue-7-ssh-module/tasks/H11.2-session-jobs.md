## 实施验收

在授权测试主机提交一次输出已知非敏感文本的测试作业，通过 SSH 模块查询原作业的状态、输出与终态。

1. 从已接受的测试作业按 UTF-8 字节游标翻页，核对 skipped/truncated、退出原因或空退出码；以同一意图重试返回同一 job。
2. 另一主体不能仅凭 ID 查看或取消；关闭观察连接只断观察，保留有界历史，过载/过期给出可读结果。
