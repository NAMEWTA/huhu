# H7.1–2 批量目录 Windows 验收

Windows Electron Workbench、临时 Vault、两台回环 SFTP。实际主进程接收本机目录选取 IPC，测试替换系统对话框的返回目录。执行 `playwright test tests/e2e/workflows/ssh-workspaces.spec.ts --workers=1 -g 批量目录逐项`。

- 从本机双栏勾选一个目录和一个独立文件，创建一组父任务及逐项目记录。对已有父目录确认合并，对已有子目录和同名文件分别拒绝。回读新增文件、远端原文件、原子目录和跳过的子文件，父任务显示部分完成。
- 用实际表格拖放将远端目录下载到本机另一栏，回读嵌套文件。Windows junction 及 SFTP 链接均未被递归遍历，目标没有越界条目。
- 从绑定的回环端点甲选定子目录，复制到独立端点乙，读回乙上的真实 SFTP 字节。

复用原有全局并发上限和任务容量。每个目录任务只有在目标目录新建或用户确认当前目录合并后才释放子项。原生系统拖入仍需宿主提供可信文件路径，本版支持在已绑定双栏中拖放，保留勾选及按钮供键盘操作。参考 Motty 固定版本的 `worker.go` 与 `local_name.go`。
