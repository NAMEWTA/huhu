# H11.2 Linux SSH Exec 作业验收

代码提交 `6269093e49c415019a28beb9451268c003218415`，从原 WIP `c23a8258e3ba0d68022cea45f6b52332b9ff0ec2` 接续。用 Node 24.21.0、pnpm 12.10.1、独立临时 Vault 和 `127.0.0.1` 上的 ssh2 夹具。命令由夹具按文本选择预定响应。Linux 测试在 SSH 包内为真实 Engine 注入作业存储参数和进程内合成密钥保护器。

## 可观察合同

| 能力 | scope / risk | 行为 |
| --- | --- | --- |
| `ssh.jobs.prepare` | execute / high | 当前外部主体的相同 `intentKey` 和规范化输入重取原 `jobId`。异参返回 `IDEMPOTENCY_MISMATCH`。首次受理校验主机和路由修订，独立拨号。 |
| `ssh.jobs.start` | execute / high | 核对原 `jobId`、已认证 `sessionId`、`hostId` 和 `routeRevision`。按作业提交一次 SSH Exec。 |
| `ssh.jobs.get` | read / normal | 查询归属当前主体的原连接、输出位置和终态。重启后已完成回执仍可查。 |
| `ssh.jobs.output.read` | read / normal | 独立的 stdout 和 stderr UTF-8 字节游标。返回 `fromCursor`、`nextCursor`、`endCursor`、`skippedBytes`、`truncated` 和 `text`。 |
| `ssh.jobs.cancel` | execute / high | 作业提交前关闭原连接。已提交时向原 channel 请求 INT，随后查询服务端退出事实。 |

五项默认关闭，沿用 Dispatcher 的工具选择。首次指纹查询与应答沿用 H11.1 的 `ssh.resources.connection.get` 和 `ssh.resources.trust.decide`。准备返回的作业及其拨号、认证会话分别有独立 ID，原路由修订在就绪、运行和已保存终态中保留。短命 H11.1 探针通过独立连接核验后关闭。

- 每主体最多 4 个活跃作业，全局最多 16 个。运行内存最多 32 个作业。结束输出最多保留 10 分钟，达到数目上限时清理已结束记录。每流 64 KiB，单次读取 4 至 16,384 字节，默认 4,096；在 UTF-8 字符边界切页。无效序列会规范化成 U+FFFD，游标以规范化后的 UTF-8 字节计数。
- 就绪 60 秒内可启动。提交等待 SSH 应答超过 5 秒时返回 `unknown / dispatch-timeout`。运行超时或取消请求发送 INT 后等待最多 1.5 秒。收到退出码或退出信号保存实际终态，缺少退出事实时保留空退出码和待核实原因。
- 机器本地回执保存输入摘要、主体摘要和可公开的终态元数据。命令、密码、意图原文和输出字节未写入回执。进程只留下受理记录时，重开返回同一作业及 `engine-interrupted`，已知信息只有 `jobId`。回执沿用通用 `OperationReceipts` 的追加保留策略，输出按上限和有效期清理。

## 实得

| 场景 | 观察 |
| --- | --- |
| CLI | 通过 CLI 主程序 `run` 和实际 Engine HTTP 入口调用准备、指纹应答、启动、读状态及输出。相同意图并发准备返回同一 ID，并发提交只产生一次 Exec。重启读回同一终态和游标跳过标记。 |
| HTTP MCP | 两个独立 Gateway 令牌调用同一 Engine 的真实 `/mcp`。查到工具、准备、指纹应答、启动、并发读取和取消均走 `tools/call`。错主体查、读、启动和取消均拒绝。同一主体的两条命令各提交一次，取消第一条只终结第一条，第二条仍在运行。观察请求结束后继续轮询同一作业。 |
| 默认关闭及撤权 | 默认目录选择为关闭，首次调用返回 `CAPABILITY_NOT_EXPOSED`；停用启动后同一已就绪绑定也拒绝，服务端收到零 Exec；撤销 Gateway 令牌后 HTTP 返回 401。共享 MCP 默认令牌调用作业返回 `PERMISSION_DENIED`。 |
| 主机、路由及 Vault | 就绪前先验旧路由，未拨号即返回 `VERSION_CONFLICT`；已就绪后改主机版本，旧绑定启动返回同一错误并关闭连接；使用另一作业的会话、未知作业 ID 或另一入口主体均拒绝。复制回执到第二个 Vault 后，读取、启动和取消仍返回 `NOT_FOUND`。 |
| UTF-8 和保留界限 | 将「中」字的 3 个字节拆到两个包，首包只返回 `A`。完整后取得 `A中`、`文`、`🙂`，独立 stderr 返回「错误」。stdout 总计 75,011 字节，旧游标跳过 9,476 字节，剩余 65,535 字节可完整翻页。越过末尾的游标被拒绝。 |
| 退出与中断 | 观测到远端 exit 7、`SIGTERM`、响应 INT 后 exit 130、SSH 拒绝、认证失败、缺少退出状态和无接收应答。运行超时且服务端忽略停止请求后得到 `timeout-unconfirmed`。这些 Exec 终态下重交或轮询均无重复执行，已结束连接由夹具计数确认回收。 |
| 仅有持久受理 | 重开只剩 accepted 行的原账本，查询明确返回待核实。相同意图返回原 ID，启动被拒，取消返回未请求。夹具仍累计一次拨号和一次 Exec。 |
