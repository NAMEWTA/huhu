本项实现只采用本地源码作行为对照。未复制 Motty/Viva 文件、品牌或二进制。ConPTY 单独受 Motty `internal/localshell/conpty/NOTICE.md` 和 `LICENSE.txt` 约束，只有选择分发资产时才登记实际版本、哈希和适用条款。H1.2 还需核对现有 ssh2 的实际功能、候选 Go 组件构建、包内版本及授权测试主机的连接和退出回收。

在 Windows amd64 从上述 Motty 检出执行 `go test -mod=readonly ./internal/monitoring ./internal/sshconfig ./internal/workspace`。安装的 Go 1.26.7 启动后按 go.mod 取得 Go 1.26.11。三组分别在 0.935、1.722、0.695 秒通过，Core `t1j` 退出码 0。

同机执行 `go test -mod=readonly ./internal/sftpclient ./internal/portforward`。文件子通道和本机回环转发测试分别在 4.198、0.703 秒通过，Core `t2d` 退出码 0。两份原始日志已保存，应用内执行器、实际授权主机与安装资产还需 H1.2 验证。

文件路径与行为映射对应原 Issue §14。路径和许可检查仅为 H1.1 的源码证据。实际采用项由整合者登记到 [上游台账](../../../../../docs/upstream/ledger.md)。
