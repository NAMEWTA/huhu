# H4.1 工作区模板 Windows 验收

Windows Electron Workbench 通过「远程连接」进入「工作区」。测试在临时 Vault 创建 13 条本机地址目录记录，全程未发起 SSH 连接。使用有用户登录环境的本地桌面构建运行 `playwright test tests/e2e/workflows/ssh-workspaces.spec.ts --workers=1 -g H4.1`。

- 新建模板后拒绝空宿主集，已选主机禁用。实际选入 3 台并重排为 1、3、2，遍历六个预设和自定义布局。保存首分割为上下、70%，保留首个 Pane 的可选登录命令。
- 回读模板文件和能力输出，核查顺序、布局及不含认证字段、活会话或终端输出。重复主机、13 台主机、叶数失配与额外认证字段均被能力拒绝。
- 删除被引用的主机时显示模板名。重命名后旧修订删除冲突。关闭 Windows Electron 后以同一 Vault 重启，确认新名称和原顺序、比例，再从 Workbench 删除模板，原主机随即可以单独删除。

六个预设、主辅布局 60% 首区、按读取顺序绑定自定义树叶参考本地 Motty `main@2daa9db582e16edf60a60b7ada26f47f808f973c` 的 `internal/workspace/spec.go`。采用 Huhu 的本地 Vault 文件和 UI。主机引用采用明确解除后再删除，覆盖两条已有删除能力中的模板依赖。Q7-1 涉及路由、转发及统一依赖预览的最终选择仍由所属切片核对。
