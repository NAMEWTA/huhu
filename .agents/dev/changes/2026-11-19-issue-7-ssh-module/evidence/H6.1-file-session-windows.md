# H6.1 SSH 绑定文件会话 Windows 验收

Windows Electron 44.9.1。以临时 Vault、两个仅监听 `127.0.0.1` 的 SSH/SFTP 服务和两侧各自的标记文件运行 `playwright test tests/e2e/workflows/ssh-workspaces.spec.ts --workers=1 -g H6.1`，1 项通过。

- 从工作区分栏甲打开附属文件，再打开独立双栏。切换至乙后，附属栏显示乙的标记，独立双栏继续显示甲的原 Shell 和原远端目录。本机选取通过 Electron preload 和主进程 `openDirectory` 执行，测试只替换系统对话框的返回值。改变本机目录、交换两列、远端排序及当前目录筛选时，另一侧保留自己的目录。
- 从甲递归搜索实际 SFTP 子目录，结果定位到行，未打开文件预览。原生 SFTP 夹具暂停 READDIR 时，Workbench 取消命令使搜索结束。远端书签、返回和权限列均使用真实目录数据。
- 断开甲后，独立双栏保留原目标并禁用远端动作。同一主机重连产生不同连接 ID，旧文件会话调用返回 SSH_DISCONNECTED。从乙关闭独立双栏后，原 Shell 仍为 running。

对照已确认 #7 原型的 `attachedFiles`、`fileView` 和 Motty `main@2daa9db582e16edf60a60b7ada26f47f808f973c` 的 `internal/sftpclient/walk.go`。复用 Huhu 既有 SFTP 和 Electron 文件选取。远端搜索按路径与协议属性排除链接遍历，每个搜索限制访问 128 个目录、2000 个目录项、6 层及 100 条命中。独立双栏采用同一桌面 Workbench 内的独立视图。文件会话随 Engine 生命周期结束。
