# S7.3 查看占用并清理可重建邮件缓存

所属交付 S7。本项承接 [Issue M-08、§7、§8.2、§9.3](../source.md)，行为规则见[网络与数据契约](../spec.md#durability)，设计见[数据与提交顺序](../design.md#storage)。

## 交付与依赖

Mail 设置说明缓存范围与大小，确认后清远端副本、搜索索引及对应游标；持久草稿、附件、本地覆盖和投递状态仍可用。

**前置产物**　[S1b.2](S1b.2-managed-attachments.md)、[S1b.4](S1b.4-outbox-reconcile.md)、[S2.2](S2.2-search-locate.md)、[S2.4](S2.4-read-state.md)。

**代码入口**　[packages/vault/src/write.ts](../../../../../packages/vault/src/write.ts)、[packages/workbench/src/engine-client/query.ts](../../../../../packages/workbench/src/engine-client/query.ts)。拟在 `plugins/mail` 的设置流程落地。

## 原型与确认范围

[Mail 原型](../prototype/index.html)的待确认场景为「设置 → 缓存占用 → 取消/确认清理 → 重建」。此项界面实施前，在记录中核对该场景对应的用户确认、版本及范围。尚未演示的状态须另列，模拟操作仅作体验依据。 [版本与用户确认范围](../prototype-review.md)

定位到[邮件演示区域](../prototype/index.html#main)，核对设置中的可重建缓存统计和清理范围。

## 验收

- [ ] 准备有草稿附件、本地标记及未知投递的模拟库，清后重启逐项比对持久记录；同步后能重新搜索远端邮件。
- [ ] 只读时拒绝清理；取消后统计与持久状态不变，清理期间的迟到索引结果不能恢复被清查询。

使用合成邮箱、消息、附件和模拟交付结果，记录测试 Vault、输入、操作前后结果及实际调用次数。实际结果回填本任务。
