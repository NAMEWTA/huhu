## 原型与确认范围

[Mail 原型](../prototype/index.html)的待确认场景为「设置 → AI → 测试连接/保存/清除」。此项界面实施前，在记录中核对该场景对应的用户确认、版本及范围。尚未演示的状态须另列，模拟操作仅作体验依据。 [版本与用户确认范围](../prototype-review.md)

定位到[邮件演示区域](../prototype/index.html#fault)，核对「邮件设置」中 AI 配置和「AI 服务暂不可用」。

## 验收

- [ ] 用模拟 HTTPS 目的地测试并保存，重开仅显示已配置状态；本机回环 HTTP 仅接受无 Key，关闭时邮件内容零请求。
- [ ] 测试失败、钥匙不可用或远端 HTTP 携 Key 时显示修复方式，原配置未被覆盖；切 Vault 后读不到另一实例的绑定。

使用合成邮箱、消息、附件和模拟交付结果，记录测试 Vault、输入、操作前后结果及实际调用次数。实际结果回填本任务。
