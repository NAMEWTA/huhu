# S8.2 从 Web 工作台传送草稿附件

所属交付 S8。本项承接 [Issue §5.4、§7.1、§8.2](../source.md)，行为规则见[添加与维护账号](../spec.md#accounts)，设计见[两端宿主约束](../design.md#hosts)。

## 交付与依赖

客户端选取的文件通过绑定 Vault、调用者和用途的流登记附件。公共 JSON 请求只传受限句柄。

**前置产物**　[#6](../../2026-11-19-issue-6-unified-tools-web/plan.md) Web 会话与授权文件流、[S1b.2](S1b.2-managed-attachments.md)。

**代码入口**　[apps/desktop/src/preload/index.ts](../../../../../apps/desktop/src/preload/index.ts)、[packages/kernel/src/server/ingress.ts](../../../../../packages/kernel/src/server/ingress.ts)、[apps/cli/src/commands/call.ts](../../../../../apps/cli/src/commands/call.ts)。拟在 `plugins/mail` 的能力适配流程落地。

## 原型与确认范围

[Mail 原型](../prototype/index.html)的待确认场景为「窄屏写信 → 上传附件/取消 → 草稿重开」。此项界面实施前，在记录中核对该场景对应的用户确认、版本及范围。尚未演示的状态须另列，模拟操作仅作体验依据。 [版本与用户确认范围](../prototype-review.md)

定位到[邮件演示区域](../prototype/index.html#composer)，核对窄屏写信附件区；大文件的实际受权传输由 Web 环境验证。

## 验收

- [ ] 在第二台受控设备的 Web 工作台上传大于 8 MiB JSON 限制的合成附件，按流登记、重开草稿并核对字节数与哈希。
- [ ] 取消、超限、过期或跨 Vault 句柄不能产生可用附件，临时资源回收；伪造路径不触发 Engine 主机文件读取。

使用合成邮箱、消息、附件和模拟交付结果，记录测试 Vault、输入、操作前后结果及实际调用次数。实际结果回填本任务。
