## 原型与确认范围

[Mail 原型](../prototype/index.html)的待确认场景为「今天 → 跨账号搜索 → 键盘选旧信 → 切账号并高亮」。此项界面实施前，在记录中核对该场景对应的用户确认、版本及范围。尚未演示的状态须另列，模拟操作仅作体验依据。 [版本与用户确认范围](../prototype-review.md)

定位到[邮件演示区域](../prototype/index.html#main)，核对搜索与对话定位，比较窄屏返回后的选中项。

## 验收

- [ ] 从账号 A 的今天视图搜账号 B 的旧邮件，250ms 防抖后翻页，用上下键与回车选择；时间切到全部，读区显示目标。
- [ ] Esc 取消回到原焦点；连续改词令旧响应失效，缓存未覆盖/无匹配明确区分，过滤全部/昨天/近三天可复核。

使用合成邮箱、消息、附件和模拟交付结果，记录测试 Vault、输入、操作前后结果及实际调用次数。实际结果回填本任务。
