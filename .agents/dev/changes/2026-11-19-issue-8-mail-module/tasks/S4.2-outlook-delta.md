## 原型与确认范围

[Mail 原型](../prototype/index.html)的待确认场景为「Outlook → 实际同步方式 → 打开邮件/权限受限 → 回复」。此项界面实施前，在记录中核对该场景对应的用户确认、版本及范围。尚未演示的状态须另列，模拟操作仅作体验依据。 [版本与用户确认范围](../prototype-review.md)

定位到[邮件演示区域](../prototype/index.html#main)，核对Outlook 的实际传输说明；Graph delta 与受众用受控协议夹具验证。
