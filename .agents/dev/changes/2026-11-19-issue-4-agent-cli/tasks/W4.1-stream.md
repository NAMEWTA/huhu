# W4.1 让慢 pane 输出时其他终端仍可用

用户同时打开慢输出和交互 pane，中文输出完整，快 pane 的输入、尺寸与 RPC 仍及时响应。

归属 W4，对应 [Issue #4 验收矩阵](../source.md) C06、C07、C08、E05、E07。[行为规格 · 启动、断线与持久化](../spec.md#启动断线与持久化) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　[W0.2](W0.2-core-capabilities.md) 的握手、流控和自动回复协商；[W1.1](W1.1-launch.md) 提供实机终端。
- **职责与边界**　客户端拥有多路通道，桥按 xterm 实际消费返回 CREDIT。前置输入缓存有界；自动回复需要明确标记。
- **现有代码入口**　[client.ts](../../../../../packages/herdr-client/src/client.ts) · [frames.ts](../../../../../packages/herdr-client/src/frames.ts) · [agent-cli/engine/terminal-bridge.ts](../../../../../plugins/agent-cli/src/engine/terminal-bridge.ts) · [components/TerminalView.tsx](../../../../../packages/ui/src/components/TerminalView.tsx)。
- **原型走查**　[终端现场 → 连续输出与输入](../prototype/index.html#terminal-panel)。流控和协议数据不在 HTML 中演示。原型仅展示场景，字节与流控用隔离 Core 验收。本片的协议或来源核验可先执行。涉及状态呈现时按同一版本的[确认记录](../prototype-review.md)核对。

## 验收与取证

1. 注入半帧、合包、hello 换行后紧邻二进制、早到 channel 与拆分 UTF-8；在真实 TUI 记录消费字节、队列上界及另一 pane 的 RPC。
2. 慢消费者、attach 取消及断开时排队输入有明确回执；核对 FOCUS/FACTS/RESIZE 和协商后的自动回复无抢焦点或尺寸。

在仓库根用 `pnpm exec vitest run` 加下方对应的 `.test.ts` 路径执行领域回归，再按上面的实际入口补齐行为证据。 [packages/herdr-client/test/frames.test.ts](../../../../../packages/herdr-client/test/frames.test.ts) · [plugins/agent-cli/test/terminal-bridge.test.ts](../../../../../plugins/agent-cli/test/terminal-bridge.test.ts) · [packages/herdr-client/test/attach.live.test.ts](../../../../../packages/herdr-client/test/attach.live.test.ts)
