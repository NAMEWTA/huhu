# W6.1 派遣到有证据支持的目标并仲裁输入

Tasks 可枚举可执行目标并向新建、指定已有或显式原生恢复的实例提交同一轮输入。

归属 W6，对应 [Issue #4 验收矩阵](../source.md) C04、C10、F01、F02。[行为规格 · 启动、断线与持久化](../spec.md#启动断线与持久化) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　[W1.2](W1.2-launch-reconcile.md) 的长期启动凭据；existing/resume 路径另需可验证的 provider 绑定与原生资格。
- **职责与边界**　#4 独占 session 输入权与发送凭据，按设计的 agent.targets.list、agent.runs.dispatch/inspect 合同供 #5 使用。
- **现有代码入口**　[agent-cli/engine/index.ts](../../../../../plugins/agent-cli/src/engine/index.ts) · [agent-cli/engine/sessions.ts](../../../../../plugins/agent-cli/src/engine/sessions.ts) · [agent-cli/engine/launch.ts](../../../../../plugins/agent-cli/src/engine/launch.ts) · [agent-cli/engine/terminal-bridge.ts](../../../../../plugins/agent-cli/src/engine/terminal-bridge.ts) · [agent-cli/engine/waiting.ts](../../../../../plugins/agent-cli/src/engine/waiting.ts)。
- **原型走查**　[后台派遣 → 指定实例忙或等待](../prototype/index.html#agents)。占用和任务绑定的 UI 也可在 #5 的后台演示控制走查。原型标识投影，合同用真实 CLI 或标明能力缺口。本片的协议或来源核验可先执行。涉及状态呈现时按同一版本的[确认记录](../prototype-review.md)核对。

## 验收与取证

1. 通过受权合同调用者分别走支持的目标，用同 dispatchId 重传并对照 accepted、已写入、provider 接受三个事实；核对一次输入。
2. 两个任务、人工、评审同时请求或同键异载荷、跨 Vault、地址复用；返回 busy/conflict/unknown 或拒绝，原 owner 仍明确。

在仓库根用 `pnpm exec vitest run` 加下方对应的 `.test.ts` 路径执行领域回归，再按上面的实际入口补齐行为证据。 [plugins/agent-cli/test/sessions.test.ts](../../../../../plugins/agent-cli/test/sessions.test.ts) · [plugins/agent-cli/test/waiting.test.ts](../../../../../plugins/agent-cli/test/waiting.test.ts)
