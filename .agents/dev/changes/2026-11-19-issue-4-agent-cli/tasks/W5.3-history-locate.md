# W5.3 从活跃历史行返回原终端

历史中点「回到原现场」可定位另一工作区已开的会话，整个过程不创建进程。

归属 W5，对应 [Issue #4 验收矩阵](../source.md) D02、D06、D08、B07。[行为规格 · 历史、文件与完整界面](../spec.md#历史文件与完整界面) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　[W5.1](W5.1-history-browse.md) 的稳定历史身份及 [W2.3](W2.3-agents-list.md) 的会话到 Space/Tab/leaf 映射。
- **职责与边界**　先核对机器、来源、原生身份和当前绑定。只读时遵守 viewer 权限；已经结束的会话按 [W5.2](W5.2-history-restore.md) 的资格规则展示恢复。
- **现有代码入口**　[history/HistoryPanel.tsx](../../../../../plugins/agent-cli/src/ui/history/HistoryPanel.tsx) · [history/scanner.ts](../../../../../plugins/agent-cli/src/engine/history/scanner.ts) · [ui/AgentCliModule.tsx](../../../../../plugins/agent-cli/src/ui/AgentCliModule.tsx) · [engine/sessions.ts](../../../../../plugins/agent-cli/src/engine/sessions.ts)。
- **原型走查**　[历史列表 → 活跃行 → 回到原现场](../prototype/index.html#inspect-body)。确认跨 Space 的导航和失效提示。对应体验待用户按[原型确认记录](../prototype-review.md)的指纹和范围确认。

## 验收与取证

1. 让不同机器的样本拥有相同名称和原生标识；在全范围搜索中选本机活跃行，核对只激活原叶、焦点及原进程数。
2. 查询后原 pane 被关闭或绑定换代，点击过期行返回失效原因，禁止通过新建或 latest 自动替代。

在仓库根用 `pnpm exec vitest run` 加下方对应的 `.test.ts` 路径执行领域回归，再按上面的实际入口补齐行为证据。 [plugins/agent-cli/test/history.test.ts](../../../../../plugins/agent-cli/test/history.test.ts) · [plugins/agent-cli/test/transcript.test.ts](../../../../../plugins/agent-cli/test/transcript.test.ts)
