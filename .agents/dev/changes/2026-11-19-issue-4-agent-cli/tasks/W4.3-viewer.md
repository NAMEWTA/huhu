# W4.3 授予只读观察或交互查看

用户可以打开可交互 peek；只有观察权限的用户可以看同一画面，不能输入或控制网格尺寸。

归属 W4，对应 [Issue #4 验收矩阵](../source.md) B07、C08、E04、E05、E06、E08、F02、F03。[行为规格 · 启动、断线与持久化](../spec.md#启动断线与持久化) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　[W4.1](W4.1-stream.md) 的 viewer/流控，现有 Engine 鉴权；#6/#7 的真实浏览器与 SSH 接入在整合验。
- **职责与边界**　终端桥验证每次 attach、输入和 resize 的当前授权。UI、终端快捷键和多视图焦点跟随实际控制者。
- **现有代码入口**　[agent-cli/engine/terminal-bridge.ts](../../../../../plugins/agent-cli/src/engine/terminal-bridge.ts) · [components/TerminalView.tsx](../../../../../packages/ui/src/components/TerminalView.tsx) · [apps/engine/src/boot.ts](../../../../../apps/engine/src/boot.ts) · [plugins/ssh/src/engine/manager.ts](../../../../../plugins/ssh/src/engine/manager.ts)。
- **原型走查**　[Agent 现场 → 可交互查看/只读观察](../prototype/index.html#agent-inspector)。确认控制归属、尺寸和无权限反馈。该界面范围待用户按版本确认，实施前核对[原型确认记录](../prototype-review.md)中的资源指纹、场景与实际确认范围；未演示的分支单列。

## 验收与取证

1. 两个 viewer 以不同权限打开同一 TUI；在可写端用中文/宽字符、复制粘贴、鼠标与 alternate screen，改字体/DPI，核对只读端重绘。
2. 直接向只读连接发送输入/尺寸、撤权或用别的 Vault 句柄，请求被拒；窗口关闭只释放 viewer，进程存活。 使用 #6 的 LAN 入口联验时，撤销某邀请应断开其已有浏览器会话，独立邀请的观察者仍可看自己的终端。

在仓库根用 `pnpm exec vitest run` 加下方对应的 `.test.ts` 路径执行领域回归，再按上面的实际入口补齐行为证据。 [packages/herdr-client/test/frames.test.ts](../../../../../packages/herdr-client/test/frames.test.ts) · [plugins/agent-cli/test/terminal-bridge.test.ts](../../../../../plugins/agent-cli/test/terminal-bridge.test.ts) · [packages/herdr-client/test/attach.live.test.ts](../../../../../packages/herdr-client/test/attach.live.test.ts)
