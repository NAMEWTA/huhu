# W8.2 用同一安装版本验收完整工作区

从多 Space 新建、四向分栏，经任务定位、断线重连、历史恢复到关闭的整条旅程有可复查的真实记录。

归属 W8，对应 [Issue #4 验收矩阵](../source.md) E01、E03、E04、E05、E06、E07、E08、F01、F02、F03、F04、F05、F06。[行为规格 · 历史、文件与完整界面](../spec.md#历史文件与完整界面) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　[W8.3](W8.3-acceptance-package.md) 的可安装候选包、包 SHA、受支持的 Core/provider 及可独立复制的工作区输入。验收所用平台提供 #6 Web/MCP、#7 SSH 和 #9 环境入口。
- **联验证据**　按候选包 SHA 和实际 session 标记工作区录制。如两组使用同一现场，其片段也可作为共同证据。
- **职责与边界**　#4 在该版本签收布局、统一执行与共享 viewer，记录包 SHA 及所测入口。使用自己的临时 Vault，按 Issue §17 保存上游同操作对照、门禁、平台差异与性能样本。
- **现有代码入口**　[package.json](../../../../../package.json) · [src/boot.ts](../../../../../apps/engine/src/boot.ts) · [engine/manager.ts](../../../../../plugins/ssh/src/engine/manager.ts) · [upstream/ledger.md](../../../../../docs/upstream/ledger.md) · [THIRD_PARTY_NOTICES.md](../../../../../THIRD_PARTY_NOTICES.md)。
- **原型走查**　[工作区 → 新建、分栏、断线、历史返回、关闭](../prototype/index.html#agent-workarea)。确认同一指纹覆盖的连续交互与窄窗。对应体验待用户按[原型确认记录](../prototype-review.md)的指纹和范围确认。

## 验收与取证

1. 对同一测试输入走多 Space、新建、四向分栏、任务定位、断线重连、历史恢复和关闭。用任务派遣、waiting、任务评论和评审核对同一真实 session，确认 pane 关闭后任务仍可由用户处理。桌面/Web/SSH 核对主题明暗、compact、reduced-motion、100/125/150/200% DPI 和高输出下的输入、首屏及资源数。
2. 在临时测试 Vault 切换/撤权，干净安装确认外部工具默认均关闭，再逐项或明确批量启用；独立内部回执继续。按 §17 运行门禁、对照性能与平台 SHA，未测平台逐项列出。
