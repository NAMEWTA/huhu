# W6.2 接管或停止精确绑定的运行

用户接管、归还或停止指定轮次；过期的取消请求能查到结果，当前控制者的输入保持安全。

归属 W6，对应 [Issue #4 验收矩阵](../source.md) B05、C11、C12、F01。[行为规格 · 启动、断线与持久化](../spec.md#启动断线与持久化) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　[W6.1](W6.1-bound-input.md) 的 owner、绑定、代次与 inspect。
- **职责与边界**　中断和归还按原 run/attempt/binding 与取消意图串行核实，真实停止后释放；任务业务状态由 Tasks 管。
- **现有代码入口**　[agent-cli/engine/sessions.ts](../../../../../plugins/agent-cli/src/engine/sessions.ts) · [agent-cli/engine/terminal-bridge.ts](../../../../../plugins/agent-cli/src/engine/terminal-bridge.ts) · [agent-cli/engine/waiting.ts](../../../../../plugins/agent-cli/src/engine/waiting.ts) · [agent-cli/ui/AgentCliModule.tsx](../../../../../plugins/agent-cli/src/ui/AgentCliModule.tsx)。
- **原型走查**　[运行现场 → 接管、只读、停止、未知](../prototype/index.html#inspect-body)。从「现场」的查看与互动对照；精确的接管/归还/停止竞争需实机及对应界面确认。确认影响说明和归还入口。该界面范围待用户按版本确认，实施前核对[原型确认记录](../prototype-review.md)中的资源指纹、场景与实际确认范围；未演示的分支单列。

## 验收与取证

1. 派一轮、人工接管、归还再停止，分别核对 UI 控制权、原生输出、终态及重复 cancel 的结果。
2. 接管后迟到取消、取消与完成同时返回、同地址出现新 shell，分别记录不能中断或原终态，新实例收到零次中断。

在仓库根用 `pnpm exec vitest run` 加下方对应的 `.test.ts` 路径执行领域回归，再按上面的实际入口补齐行为证据。 [plugins/agent-cli/test/sessions.test.ts](../../../../../plugins/agent-cli/test/sessions.test.ts) · [plugins/agent-cli/test/waiting.test.ts](../../../../../plugins/agent-cli/test/waiting.test.ts)
