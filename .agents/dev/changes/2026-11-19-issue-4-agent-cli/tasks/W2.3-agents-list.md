# W2.3 从 Agents 找到后台实例和待处理轮次

Agents 按所属 Space、父子和关注优先级列出真实实例，点一行定位原叶子。

归属 W2，对应 [Issue #4 验收矩阵](../source.md) A01、A02、B07、C09、E01、F01。[行为规格 · 工作区中的操作](../spec.md#工作区中的操作) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　[W2.1](W2.1-space-document.md) 提供 Space、Tab 和叶子映射。既有 Core 事件足以核对列表归属和当前状态。
- **职责与边界**　列表消费 blocked、done、working、idle、未上报及来源；后台注册不切前台。前台实际可见 turn 才写共享 seen，Core pin 和历史 pin 各有归属。
- **现有代码入口**　[agent-cli/ui/AgentCliModule.tsx](../../../../../plugins/agent-cli/src/ui/AgentCliModule.tsx) · [agent-cli/engine/waiting.ts](../../../../../plugins/agent-cli/src/engine/waiting.ts) · [agent-cli/engine/sessions.ts](../../../../../plugins/agent-cli/src/engine/sessions.ts) · [agent-cli/engine/herdr-core.ts](../../../../../plugins/agent-cli/src/engine/herdr-core.ts)。
- **原型走查**　[Spaces / Agents → 等待、后台、前往现场](../prototype/index.html#agents)。确认排序、来源、计数和未上报状态。该界面范围待用户按版本确认，实施前核对[原型确认记录](../prototype-review.md)中的资源指纹、场景与实际确认范围；未演示的分支单列。

## 验收与取证

1. 后台启动一个绑定任务的实例和一个未上报实例，在另一 Space 查看计数，再点待处理项，核对原地址、父子列表和共享标签变化。
2. 在隐藏窗收到事件、另窗先看或取消 pin、同名会话来自其他 Vault 时，验证无误读、误定位或跨域收编。

在仓库根用 `pnpm exec vitest run` 加下方对应的 `.test.ts` 路径执行领域回归，再按上面的实际入口补齐行为证据。 [plugins/agent-cli/test/sessions.test.ts](../../../../../plugins/agent-cli/test/sessions.test.ts) · [tests/e2e](../../../../../tests/e2e)
