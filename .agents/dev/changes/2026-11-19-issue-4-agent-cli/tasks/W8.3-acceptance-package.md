# W8.3 联编工作区与任务的共同验收包

交付一个可安装的候选版本。工作区和任务旅程的验收者可凭同一个构建标识、包 SHA、Core/provider 版本和测试 Vault 配置，分别复现用户入口。

归属 W8，对应 [Issue #4 验收矩阵](../source.md) F01、F03、F05、F06。[行为规格 · 历史与完整界面](../spec.md#历史文件与完整界面) · [设计与状态所有权](../design.md) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　W0–W7 各子项提供 #4 的生产实现和平台能力证据，[W8.1](W8.1-new-format.md)提供新格式边界，[T7.1](../../2026-11-19-issue-5-task-automation/tasks/T7.1-cutover.md)提供已切换的 Tasks/Automations 工具与调用方。按包声明接入 #6 的授权、#7 的 SSH viewer、#9 的模块环境。
- **职责与边界**　#4 在候选版本中统一切换工作区消费者，清理 fixed grid/picks、静态菜单、旧 Space 写者、以 !active 判断恢复和旧 envRefs。Tasks 与 Automations 的内部迁移由其现有交付项负责。随包记录可复现的测试输入，两个验收者各自使用独立的临时 Vault。
- **现有代码入口**　[根构建脚本](../../../../../package.json) · [Engine 组装](../../../../../apps/engine/src/boot.ts) · [Core 产物锁](../../../../../scripts/herdr.lock.json) · [来源台账](../../../../../docs/upstream/ledger.md) · [安装包测试](../../../../../tests/e2e/packaged)。
- **原型走查**　[工作区入口](../prototype/index.html#agent-workarea)及[确认记录](../prototype-review.md)用于安装后的界面比对。本片交付构建与冒烟记录。

## 验收与取证

1. 在干净的临时 Vault 安装候选包，记录 OS、构建提交、安装包 SHA、Core 与实际 provider 版本。从任务页人工派遣，核对 run 绑定，并从工作区定位同一 session；将复现输入、预期身份关系与包摘要交给两个验收入口。
2. 断开受控目标或停用 Agent CLI 时，包内调用者报告不可用，任务保留原凭据。复核所有实际调用者和公开入口，发现旧写入路径、错误包摘要或缺少承诺的能力时，将构建标为待修并用新的包摘要重新取证。
