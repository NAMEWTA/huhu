# W6.0 定义可由两端独立验证的回执契约

Agent CLI 和 Tasks 可以用相同的回执样例验证身份、去重与确认时机。交付物是共享契约包中的回执类型、校验入口以及带预期结论的固定样例。

归属 W6，对应 [Issue #4 验收矩阵](../source.md) F01、F02、C12。[行为规格 · 启动、断线与持久化](../spec.md#启动断线与持久化) · [设计中的受控回执合同](../design.md#两个-issue-共用的执行合同拟议) · [计划索引](../plan.md)

## 实施范围

- **前置条件**　现有执行合同已给出运行绑定与两次 ACK 的语义。可用固定的 Vault、任务、run、attempt 和 session 身份独立开工。
- **职责与边界**　#4 维护一份版本化回执与 ACK 契约。适配器取得 Agent 的持久接收确认后可释放本地副本。Agent 取得 Tasks 的持久消费确认后可释放待交回执。后者要求保存原 payload，并能重建 delivery。两次确认都绑定收到的 receiptId 与执行身份。
- **现有代码入口**　从[公共契约导出](../../../../../packages/contracts/src/index.ts)、[运行模型](../../../../../packages/contracts/src/kinds/task-run.ts)和[现有契约测试](../../../../../packages/contracts/test/sample.test.ts)定位。拟在该包提供两端可导入的类型及同版契约样例。
- **原型走查**　[现场中的等待与结果](../prototype/index.html#inspect-body)可对照投影，界面范围见[确认记录](../prototype-review.md)。本片的验收入口是公共契约包。

## 验收与取证

1. 在契约测试中使用绑定一致的 result 和 question 样例。相同回执重交时，生产端与消费端的样例驱动器得到同一规范化身份；逐步核对两个 ACK 各自允许释放的记录。
2. 用同 ID 异 payload、跨 Vault/attempt/绑定、错版本及无持久接收依据的 ACK 验证拒绝或保持待交的预期。保留样例输入、两端预期与测试命令，供生产实现直接复用。
