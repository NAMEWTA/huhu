# #3 桌面标题栏、应用菜单与关闭保存

用户安装 HUHU 后，应从第一次选择 Vault 开始就看到一条属于工作台的顶部，并能按本机习惯操作窗口。在文档仍有未落盘的最后一次输入时，点击系统关闭按钮和选择菜单退出都要给出可信的保存结果。

[Issue 完整正文与评论快照](source.md) 是范围依据，未附用户截图，无后续评论。以下契约补全 TB-01～18。产品尚未发布，所有调用方在同一整合点改用新窗口接口，旧接口兼容层不在交付范围。采用 HUHU 的品牌、导航、组件和文案。[批次决定](../../../system/herdr-core/2026-11-19-huhu-prototypes-and-slices/topic.md)。状态、接口和取舍见[设计](design.md)，证据入口见[计划](plan.md)。当前尚无用户确认的交互原型或三平台安装体验结论。

## 可观察行为

| 情境 | 用户应看到或能完成的动作 | 对应验收 |
| --- | --- | --- |
| 冷启动、无 Vault、切换、Engine 启动或崩溃 | 一条品牌顶部。可用的 Vault/重启入口随阶段显示。窗口始终有移动和关闭路径。Renderer 主页面加载失败时，内置错误页和原生控件仍可用。预览子框架失败仅影响预览。 | TB-01、TB-02、TB-11 |
| 正常工作台与模块切换 | BrandMark、当前 Vault、产品菜单及已有搜索/命令入口各有一个位置。版本取应用版本，可在关于中查看。帮助指向 HUHU。系统任务切换器显示 HUHU，可附 Vault 显示名。不包含绝对路径或凭据。模块标签、文档标签和编辑工具维持各自职责。 | TB-02、TB-03、TB-17、TB-18 |
| 四主题 Claude、Apple、Notion、Vercel，浅/深/跟随系统 | 首帧、打开 Vault 恢复外观、运行中切换均以同一几何与颜色定义驱动窗口控制区和内容区。最小窗、长中文/emoji 名、DPI/显示器切换时优先保住系统控件、菜单与搜索，次要标题省略。 | TB-04、TB-05 |
| macOS | 红黄绿位置符合系统习惯，可拖动、缩放/最小化、原生全屏，双击标题空区服从系统偏好。屏幕顶端系统菜单保留服务、隐藏、窗口、关于与退出等角色。关最后一个窗口后仍可激活应用。 | TB-06、TB-10、TB-12 |
| Windows | 顶部显示一组系统按钮。最小化、最大化、还原、边缘缩放、系统窗口菜单、Alt+F4 均可用。支持的 Win11 上验证悬停最大化按钮的 Snap Layouts、DPI 和跨显示器移动。菜单按钮、Alt/F10 可到达 HUHU 菜单。 | TB-05、TB-07、TB-12 |
| Linux | 记录发行版、桌面环境、窗口管理器/合成器、X11 或 Wayland、缩放和安装版本。每个承诺的组合均可拖动、缩放、最大化、全屏和键盘关闭。菜单按钮及键盘可操作产品菜单。 | TB-08、TB-12 |
| 拖动、专注、失焦与全屏 | 空白带是拖动区。按钮、搜索、Vault、弹层、可选文字和重排标签接受自己的指针事件。系统拖动区的双击、右键由宿主处理。非全屏专注仍能移动、最小化、关闭。进出系统全屏及失焦恢复后按钮名称、状态与占位对应真实窗口。 | TB-09、TB-10、TB-12 |
| 菜单、命令面板、快捷键 | 产品菜单按平台组织 HUHU、文件、编辑、视图、窗口、帮助。每次激活只执行一次。打开系统菜单前聚焦笔记 A，再保存，只改 A。普通输入框的撤销/复制作用于该选区。关闭文档、关闭窗口、退出应用各有明确对象与结果。禁用项有原因。无 Vault、只读、无活动文档、Engine 离线或插件停用不能触发相应写入。安装版无开发模板重载、开发者工具及 Electron 帮助项。 | TB-03、TB-12、TB-13、TB-17 |
| 自动保存、手动模式、保存冲突 | 在编辑器防抖期间关窗，重开后可找到最后一次输入。自动保存区分文件写入和冲突，手动模式按既有约定保留可恢复草稿。超时、写失败、Renderer 崩溃或保存与草稿都失败，窗口保持或出现独立宿主提示，可重试、取消、明确放弃。提示区分已写文件、只保存草稿和无法确认。取消保留会话。成功退出按现有顺序停 Engine。 | TB-14、TB-15 |
| Host 调用与脱离桌面运行 | 只允许可信顶层 frame 对所属窗口执行受支持动作。预览、无效参数、迟到回执均无窗口副作用。卸载后订阅归零。共享工作台无桌面宿主时仍可导航、打开命令面板。系统窗口操作只在桌面出现。 | TB-16、TB-17、TB-18 |
