# 欢迎使用 HUHU

这是一个示例 Vault，所有内容都是普通文件，保存在这个文件夹里。

- 用 [[双链示例]] 把笔记连起来
- 在 [[示例文件夹/项目计划]] 里看看带待办的笔记
- 按 `Mod+K` 打开命令面板，`Mod+Shift+N` 快速捕获想法到收件箱

## 编辑器

- 输入 `/` 插入标题、列表、表格、代码块等块；选中文字出现格式菜单。
- 顶部的“属性”区编辑这篇笔记的 YAML 元数据（标题、标签、日期……）。
- 在工具栏切换 **富文本 / 源码 / 阅读** 三种视图，它们读写的是同一份文件。
- 选中一段文字可以添加评论。

## 文件

文件树里能看到 Vault 的所有文件：`示例文件夹/` 里有一个 JSON 和一个 TXT，可以直接编辑；PDF 与 HTML 可以查看。右键菜单里的“在资源管理器中隐藏”只影响文件树，隐藏的项目仍能被搜索和 `@` 引用到。
